## 👻 Part 1. `1귀신` 전담 영역 — `1. 👻 귀신비서` (PC·폰 손보기 · 휴지통 안전핀 · 복원 기록 · 백신 · 스마트 압축 · 사양 상담)

### Q1-1. "은행·관공서 보안프로그램을 정리하면 나중에 인터넷뱅킹이나 홈택스 들어갈 때 다시 깔아야 하는 거 아냐?"
- **핵심 정답 (원본)**:
  - **다시 설치하실 필요가 없습니다!** 귀신비서의 기본 **`⚡ 보안프로그램 자동 절전·기상`** 기능은 은행·관공서 보안 모듈(`AhnLab Safe Transaction`, `nProtect`, `TouchEn`, `AnySign`, `Veraport` 등)을 무조건 삭제하지 않고, 평소에 CPU·메모리를 잡아먹지 못하도록 **잠재워(절전 전환)** 두었다가 은행이나 홈택스에 접속하실 때 다시 깨워드리는 방식으로 작동합니다.
  - 만약 오랫동안 전혀 쓰지 않는 보안프로그램을 아예 지우고 싶으실 때만 **`심층 완전 제거`**를 직접 선택하실 수 있습니다.

### Q1-2. "귀신비서한테 컴퓨터나 사진을 정리해 달라고 하면 내 중요한 파일을 멋대로 지우지는 않아?"
- **핵심 정답 (원본)**:
  - **귀신같이는 사용자의 허락 없이 파일이나 프로그램을 임의로 자동 삭제하는 일이 0%입니다.**
  - 바탕화면·다운로드 정리, 시작프로그램 점검, 사진 4대 탭(`중복·연사` / `주차·영수증` / `스크린샷` / `흔들린 사진`) 정리 모두 반드시 **대상 파일 목록과 확보 용량을 미리보기 카드로 먼저 보여드리고**, 사용자가 직접 버튼을 누르거나 채팅창에 **`"응 진행해"`**라고 승인했을 때만 실행됩니다. 또한 사업자등록증·계약서·신분증 같은 중요 보관 서류 사진은 정리 대상에서 자동으로 보호됩니다.

### Q1-3. "사진이나 파일을 정리했는데 왜 C드라이브 남은 용량이 바로 안 늘어나? 완전히 비우려면 어떻게 해?"
- **핵심 정답 (원본)**:
  - 실수로 중요한 파일을 지웠을 때 언제든 되살리실 수 있도록, 귀신비서가 정리한 파일은 곧바로 영구 삭제하지 않고 **윈도우 기본 `[휴지통]`(스마트폰은 시스템 `휴지통` / 아이폰 `최근 삭제된 항목`)으로 안전하게 이동**시키기 때문입니다.
  - 휴지통에 들어 있는 동안에는 원본 복구가 가능한 대신 디스크 용량을 차지하므로, 확인을 마치고 **실제 C드라이브 여유 용량을 즉시 확보하고 싶으실 때는 귀신비서 채팅창에 직접 `"휴지통 비워줘"`라고 입력(안전핀 승인)**하시면 최종 비우기가 진행됩니다.

### Q1-4. "방금 정리한 사진이나 컴퓨터 설정을 원래대로 되돌릴 수 있어? (`[복원 기록]` 타임머신)"
- **핵심 정답 (원본)**:
  - **네, 1초 만에 원래 자리와 원래 설정으로 되돌리실 수 있습니다!**
  - 귀신비서가 수행한 모든 파일 정리와 시스템 설정 변경은 로컬 감사 원장(`ghosti_blackbox_audit.jsonl` 및 `restore_points.json`)에 스냅샷으로 자동 기록됩니다.
  - 채팅창에 **`"원래대로 돌려줘"`**, **`"복원 기록 보여줘"`**라고 말씀하시거나 왼쪽 정리 화면 아래의 **`[복원 찾기]` / `[전체 복원]`** 버튼을 누르시면, 1장씩 골라서 살리거나 방금 지운 수십 장을 한 번에 원래 폴더로 되살릴 수 있습니다.

### Q1-5. "알약이나 V3 같은 무료 백신을 안 깔아도 귀신비서가 바이러스 검사를 해줘?"
- **핵심 정답 (원본)**:
  - **네! 광고 팝업이 뜨고 PC를 무겁게 만드는 사설 무료 백신을 따로 까실 필요가 없습니다.**
  - 귀신비서는 윈도우에 기본 내장된 마이크로소프트 공식 순정 백신(**`Windows Defender`**)을 통합 관제하여 실시간 보호 상태 점검과 빠른 검사를 수행하며, 인터넷에서 새로 내려받는 설치파일(`.exe`, `.msi`, `.zip`)을 백그라운드에서 무소음으로 자동 경호해 드립니다.

### Q1-6. "알집 없이도 압축 파일(`ZIP`, `7Z`)을 풀거나 암호 걸어서 압축할 수 있어?"
- **핵심 정답 (원본)**:
  - **네, 광고창 하나 없는 `📦 1초 스마트 압축·해제` 기능이 무료로 기본 내장되어 있습니다.**
  - 탐색기에서 압축 파일을 더블클릭하거나 우클릭 메뉴를 누르면 폴더 지저분해짐 없이 깔끔하게 압축을 풀어주며, 여러 파일을 묶어 일반 `ZIP` 압축이나 비밀번호가 걸린 암호 압축 파일도 즉시 만드실 수 있습니다.

### Q1-7. "한글(HWP)이나 엑셀, 워드 문서를 저장 못 하고 컴퓨터가 꺼졌는데 살릴 수 있어?"
- **핵심 정답 (원본)**:
  - **채팅창에 `"저장 못 한 문서 찾아줘"` 또는 `"어제 보던 파일이 사라졌는데 찾아줘"`라고 말씀해 보세요!**
  - 귀신비서의 **`🛟 미저장 문서·실종 파일 3초 구출`** 엔진이 윈도우 깊숙한 임시 자동저장 폴더(`AppData` 내 한글·엑셀·워드 임시본)와 최근 이동 경로, 휴지통을 3초 만에 전수 추적해 살아있는 최신 복구본을 찾아 보여드립니다.

### Q1-8. "내 컴퓨터가 너무 느린데 부품을 바꿔야 할까? 램(RAM)이나 SSD 최저가 구매 링크 좀 알려줘!"
- **핵심 정답 (원본)**:
  - 채팅창에 **`"내 컴퓨터 사양 진단해줘"`**라고 말씀하시면 CPU 세대, 메모리 용량·빈 슬롯, 저장장치(SSD/HDD) 상태를 실측해 프로그램 정리만으로 충분한지, 아니면 메모리 1개 추가가 필요한지 솔직하게 진단해 드립니다.
  - 단, **귀신같이는 부품 장사나 쇼핑몰 제휴 광고를 절대 하지 않으므로 구매 링크는 드리지 않습니다.** 대신 내 메인보드에 딱 맞는 **정확한 부품 규격 이름(예: `DDR4 PC4-25600 8GB`)만 클립보드에 복사**해 드리고 외부 쇼핑몰이나 단골 AI에서 직접 검색해 보시도록 안내해 드립니다.

### Q1-9. "스마트폰에 깔린 이상한 청소앱·광고앱도 잡아줘? 아이폰에서도 돼?"
- **핵심 정답 (원본)**:
  - **안드로이드 정식 앱**에서는 배터리를 갉아먹고 전면 광고를 띄우는 악성 클리너·유사 청소앱을 찾아내어 안전하게 삭제할 수 있도록 3단계 구출 가이드를 제공합니다.
  - **아이폰(iOS)**은 애플 운영체제 보안 정책상 외부 악성 청소앱이 자동 설치될 수 없으므로 청소앱 삭제 메뉴가 노출되지 않으며, 아이폰 정기구독 내역 확인이 필요하실 때는 **`[아이폰 설정 > 내 이름(Apple 계정) > 구독]`**에서 관리하실 수 있습니다.

### Q1-10. "C드라이브 용량이 꽉 찼는데, 안 쓰는 앱 여러 개를 골라서 한 번에 지우거나 큰 폴더를 D드라이브로 옮길 수도 있어?"
- **핵심 정답 (원본)**:
  - **네! 채팅창에 `"C드라이브 용량 도둑 스캔해줘"`, `"안 쓰는 프로그램이랑 애드웨어 다 조사해줘"`, `"바탕화면 상세 분석해줘"`라고 편하게 말씀해 보세요!**
  - 귀신비서가 3초 만에 크롬·엣지·웨일 캐시(로그인·쿠키 100% 보호), `npm`/`pip` 개발 캐시, `CapCut` 렌더링 캐시, 데스크톱 미사용 최대절전 파일(`hiberfil.sys`), 악성 애드웨어·그리드, 바탕화면 대용량 폴더까지 한눈에 뽑아드립니다.
  - 목록을 보시고 마우스로 체크박스를 고르시거나 채팅창에 **`"오캠이랑 4번은 빼고 나머지 다 지워줘"`**, **`"다운로드 큰 폴더는 D드라이브로 옮겨줘"`**처럼 자유롭게 말씀하시면, 보존 항목과 실행 항목을 한 번 더 보여드린 뒤 **영구 삭제 0%(Windows 휴지통 안전 이동 + `[복원 기록]` 1초 원복)**로 한 번에 정리해 드립니다. (바탕화면에 뜬 `WD` 같은 사용자 계정 폴더 아이콘도 파일 손실 없이 아이콘만 안전하게 숨겨드립니다!)

### Q1-11. "컴퓨터 뒤에서 몰래 도는 이상한 프로그램(신종 애드웨어·예스파일 같은 서비스)도 다 찾아줘? 내가 쓰는 프로그램은 안 지우고 평소에만 못 돌게 할 수 있어?"
- **핵심 정답 (원본)**:
  - **네! 채팅창에 `"뒤에서 몰래 도는 쥐새끼 다 찾아줘"`, `"이상한 거 자꾸 떠"`, `"컴퓨터가 왜 이렇게 무거워?"`처럼 일상 말투로만 말씀하셔도 됩니다!**
  - 귀신비서가 윈도우 기본 시스템이 아닌 **숨은 예약 실행(작업 스케줄러), 상주 서비스, 부팅 자동실행, 메모리 과점유 프로세스**를 싹 전수 수색한 뒤, 처음 보는 생소한 이름도 AI가 실행 경로와 제작사를 분석해 **초보자 눈높이 1줄 설명**과 **`🔴 차단·제거 권장` / `🟡 수동전환(앱 유지)` / `🔎 확인 후 선택`** 신호등 배지로 알기 쉽게 번역해 드립니다. (궁금한 항목은 옆의 **`[이게 뭐예요?]`** 버튼만 누르시면 바로 설명해 드려요!)
  - 특히 `예스파일(Yesfile)`이나 자주 쓰는 유틸리티처럼 **앱을 지우면 안 되는 경우**에는 앱 삭제 없이 **평소 백그라운드 상주만 끄는 `수동(Manual)` 전환**으로 안전하게 잠재워드리고, 모든 설정은 `[복원 기록]`에서 1초 만에 원래대로 되돌릴 수 있습니다.

## 🔍 Part 2. `2귀신` 전담 영역 — `2. 👻 귀신검색` · `Ctrl+0` 소환 · 사진/표 OCR · 라벨러 · 자매 `귀신키` · 인물 여권

### Q2-1. "`Ctrl + 0`(또는 `Ctrl + 우클릭`)을 누르면 어떤 창이 열려? 3가지 창은 어떻게 달라?"
- **핵심 정답 (원본)**:
  - 윈도우 어디서나(카톡·엑셀·브라우저·탐색기) **`Ctrl + 0`** 또는 **`Ctrl + 마우스 우클릭`**을 누르면 귀신이 소환됩니다:
    1. **기본 소환 (`👻 귀신검색창` — `[⤡ 작게]` / `[⤢ 크게]` 2모드 반응형)**: 어느 화면에서 부르든 `0.05초` 만에 열려 작업 흐름을 끊지 않고 사진·동영상·문서를 1초 만에 찾아 바로 열거나 첨부할 수 있으며, 검색 결과가 많아지면 우측 미리보기 패널이 스르륵 펼쳐집니다.
    2. **별도 독립 `📝 사진·표 OCR 창` (`내 기기 통합 Pro` / 30일 무료체험)**: 사진·영수증·캡처 이미지 속 글자와 표, 계좌번호, 사업자번호를 추출해 클릭 한 번으로 복사합니다.
    3. **자매 입력기 `귀신키(GhostKey)` 연동 시 (`① 기본 귀신창`)**: 별도 입력기 `귀신키`를 함께 쓰시는 경우 텍스트 입력칸 안에서는 순차 붙여넣기·서식 정리·`F1~F6` 상용구 창이 열리고, 바탕화면·탐색기 빈 공간에서는 `👻 귀신검색창`이 열립니다.

### Q2-2. "파일 제목이 기억 안 나는데 문서 본문이나 사진·동영상 속 글자로도 검색이 돼?"
- **핵심 정답 (원본)**:
  - **네, 파일 제목을 전혀 몰라도 파일 안의 내용으로 1초 만에 찾아냅니다!**
    1. **오피스·한글 문서 본문(`50,000자`)**: 한글(`HWP`/`HWPX`), 엑셀(`XLSX`/`CSV`), 워드(`DOCX`), `PDF`, 텍스트 파일의 본문·표 속 단어(예: `"보증금"`, `"미수금"`, 거래처명)는 물론 영문 복합 파일명(`bankTest` 등)까지 정밀 검색됩니다.
    2. **사진 장면 의미 + 사진 속 한글(OCR)**: `"바닷가에서 웃는 사진"` 같은 장면 묘사 검색과 영수증·서류 사진 속 글자 검색이 동시에 작동합니다.

### Q4-2. "클라우드에 있는 파일인데 어떻게 귀신같이가 본문 내용까지 검색(인덱싱)할 수 있어?"

### Q4-3. "구글 스프레드시트(`.gsheet`)나 구글 문서(`.gdoc`) 안의 글자도 검색돼?"

    1. **팀·사내 공유 시트 (`'링크가 있는 모든 사용자 보기 가능'`으로 설정된 `.gsheet` / `.gdoc`)**: 별도 로그인 팝업 없이도 구글 공식 내보내기 경로를 통해 **시트 안의 표(행·열)와 본문 글자까지 일반 엑셀(`.xlsx`)과 똑같이 100% 본문 검색**됩니다!
    2. **나 혼자 보는 비공개 시트**: **파일 제목으로 1초 검색**되며, 클릭 시 우측 미리보기의 **`[Google 문서·시트 웹에서 열기 ↗]`** 버튼으로 즉시 구글 웹 시트를 열어줍니다. 만약 비공개 시트도 셀 안의 글자까지 검색하고 싶으시다면 공유 설정을 `'링크가 있는 사용자 보기'`로 열어주시거나 엑셀(`.xlsx`) 파일로 폴더에 저장해 두시면 됩니다.

### Q4-4. "우리 회사는 이미 사내 NAS(시놀로지 등)를 쓰고 있는데 귀신같이 업무 공유가 필요해?"
- **핵심 정답 (원본)**:
  - **NAS는 사무실에 사다 놓는 물리 장비(하드디스크 서버 기계)**인데, 실제 중소기업에서 NAS를 쓰실 때 겪는 4가지 큰 불편을 귀신같이가 해결해 드립니다:
    1. **외근·현장·스마트폰 LTE 1초 접속**: NAS는 사내 와이파이를 벗어나면 VPN·포트포워딩 설정이 복잡하거나 끊기지만, 귀신같이는 설정 없이 스마트폰 LTE나 외부 PC에서 대장 PC `S:`에 1초 만에 직결됩니다.
    2. **문서 ‘본문 속 단어’ 1초 검색 (`Ctrl+0`)**: NAS 탐색기는 파일 제목만 느리게 찾지만, 귀신같이는 파일 제목을 몰라도 한글(`HWP`)·엑셀 표·스캔 PDF 본문 속 거래처명·단가·보증금을 1초 만에 찾아냅니다.
    3. **동시 수정 덮어쓰기 방지**: 누가 엑셀·한글 파일을 열어놨는지 실시간으로 **`[🔒 현재 OOO님이 사용 중]`** 배지로 알려주어 팀원끼리 덮어쓰는 사고를 막아줍니다.
    4. **기존 NAS와 동시 병행 가능**: 기존 NAS를 버릴 필요 없이 병행하거나, 수백만 원짜리 노후 NAS 교체 비용 없이 사무실 일반 PC 1대로 대체할 수 있습니다.

### Q4-5. "업무 공유 폴더는 여러 개 지정할 수 있어, 아니면 하나만 정해야 해?"
