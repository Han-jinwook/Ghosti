# [팀 공유 및 협의용] 『투시검색 (Ghosti)』 브랜드 간판 전환 및 상표권 선점 전략안

> 상태: **협의 중 (미확정)** — 2026-10-27 멀린님 원안 접수. 하단 §5에 Ghosti 에이전트 레드팀 검토 의견 첨부.

## 1. 추진 배경 및 취지 (Why Now?)

- **자본 없는 스타트업의 '브랜드 인지 교육 비용' 한계:** 대기업은 수백억 원의 광고비로 추상적인 영어 이름(Ghosti)의 뜻을 대중에게 학습시킬 수 있으나, 소규모 마케팅 예산으로 승부해야 하는 우리 입장에서는 `귀신같이 = 동영상·문서·사진 속을 꿰뚫어 보는 투시검색`이라는 공식을 사람들 뇌리에 연결시키는 데만 수년의 시간과 막대한 비용이 소요됨.
  - 실제 과거 '고클린' 사례처럼, 소비자는 추상적 브랜드명을 쉽게 잊어버리고 결국 5~6년이 지나도 "컴퓨터 청소 프로그램", "파일 내용 검색 프로그램"처럼 기능 자체를 검색창에 쳐서 찾는 경향이 뚜렷함.
- **카피캣(Copycat)의 '키워드 가로채기' 원천 봉쇄 필요:** 우리가 숏폼과 커뮤니티, 유튜버를 통해 "투시검색"이라는 신조어와 개념을 유행시켜 놓았을 때, 후발 카피캣이 앱 이름을 아예 『투시검색』으로 지어 스토어에 등록해 버리면 우리가 만든 마케팅 트래픽과 인지도를 송두리째 빼앗길 위험이 있음.
- **8글자 나열의 피로도 탈피 ➔ '4글자 직관 간판' 확립:** `귀신같이 투시검색` 8글자를 나열하면 부르기 어렵고 길어 보임. 실제 대중의 눈과 입에 꽂히는 전면 간판(Hero Brand)은 한글 4글자 『투시검색』으로 단일화하고, 귀신같이(Ghosti)는 로고 심볼과 결합된 글로벌 엔진 시그니처(법적·기술적 식별 표지)로 이원화하는 것이 가장 강력함.

## 2. 핵심 목적 (Core Objectives)

- **인지 시간 '0초' 달성:** 유저가 이름을 듣거나 화면을 보는 순간 "아! 파일 제목 몰라도 영상 장면이나 엑셀 속 글자까지 꿰뚫어 찾아주는 앱이구나!"라고 설명 없이 0.1초 만에 이해하고 평생 까먹지 않게 함 (직방·번개장터·알약 모델).
- **검색 유입(SEO/ASO) 100% 독점:** 나중에 유저가 앱 이름을 까먹고 네이버·구글·앱스토어에 본능적으로 "투시검색"이라고만 쳐도 우리 앱이 최상단 1위로 직결되게 함.
- **스토어 카피캣 즉결 처형 무장:** 특허(Patent)만으로는 앱스토어/플레이스토어에서 카피캣을 즉시 삭제할 수 없으므로, 상표권(Trademark)으로 『투시검색』과 『투시검색 Ghosti』를 동시 선점하여 카피캣의 이름 도용을 법적·실무적으로 원천 차단함.

## 3. 실무 실행 방향 (3대 영역별 액션 플랜)

### ① [법무 · 상표 출원 방향] "투트랙(Two-Track) 상표 출원으로 등록률과 독점력 동시 확보"

내일모레 진행할 특허청 상표 출원(제9류 다운로드형 SW / 제42류 IT·클라우드·SaaS 서비스업) 시, 상표법상 '기술적 표장(기능 설명어) 거절 리스크'를 방어하기 위해 아래 2건을 동시 출원.

| 구분 | 출원 상표명 | 출원 목적 및 실무적 방어 논리 |
|---|---|---|
| 출원 1호 (단독어 알박기용) | 『투시검색』 (문자상표 단독) | • 목적: 카피캣이 '투시검색'이라는 단어를 상표나 앱 이름으로 등록하는 것을 선출원주의로 원천 봉쇄.<br>• 대응 논리: '투시'와 '검색'의 결합은 국어사전에 없는 당사 창작 조어(신조어)임을 주장. 설령 심사 과정에서 식별력 보정 요구가 나오더라도 출원 일자를 선점해 후발 주자의 진입을 막는 방패 역할 수행. |
| 출원 2호 (100% 안전 등록용) | 『투시검색 Ghosti』 (또는 『투시검색 귀신같이』 + Z렌즈 로고 결합) | • 목적: 고유 식별력이 강한 조어(Ghosti / 귀신같이)와 도형 로고를 결합하여 심사관 거절(OA) 확률 0%, 확실한 상표 등록증 확보.<br>• 활용: 등록 즉시 구글 플레이·애플 앱스토어의 공식 앱 타이틀로 등재하여 유사 상표 카피캣을 스토어에서 즉각 퇴출(Take-down)시키는 실탄으로 사용. |

## 4. 타 팀(비서/레드팀) 협의 핵심 안건 3가지

1. **[네이밍 직관성 vs 확장성]:** 전면 간판 『투시검색』 + 서브 각인 Ghosti 구조가 3대 기능(투시검색 · 클린몬스터 · 설정몬스터)과 공유방(사진방 · 업무방 S: 드라이브)을 아우르는 대표 간판으로 손색이 없는가?
2. **[상표 출원 전략 점검]:** ① 투시검색 단독 출원 + ② 투시검색 귀신같이(Ghosti) 결합 출원 투트랙 전략에 법적·실무적 빈틈은 없는가?
3. **[UI/UX 레이아웃 최종 확인]:** 좌측 상단 헤더 `[🖼️ Z로고] 투시검색 / Ghosti` 상하 밀착형 구조가 디자인 완성도가 가장 높은가?

## 5. Ghosti 에이전트 레드팀 검토 의견 (2026-10-27)

> 법률 자문이 아닌 실무 검토 의견. 최종 출원 전 변리사 확인 필요.

### 5-1. 상표 (안건 2)
- **출원 1호 『투시검색』 단독은 거절 가능성 높음:** 상표법 제33조 제1항 제3호(성질표시)는 "사전에 없는 조합"이어도 의미가 기능을 직감시키면 거절. '투시+검색' = "속을 꿰뚫어 보는 검색"으로 지정상품(검색 SW)의 기능을 직접 설명.
- **"출원일 선점 = 방패" 논리의 빈틈:** 거절 확정된 출원은 후출원을 막지 못함. 성질표시어는 누구도 독점할 수 없으므로 카피캣의 **앱 이름 사용 자체**는 막지 못함(등록도 못 하지만 사용도 못 막음).
- **출원 2호 결합상표의 한계:** 등록돼도 요부(식별력 있는 부분)는 `Ghosti/귀신같이/도형`이 되고 '투시검색' 부분에는 권리가 미치지 않을 가능성 큼 → 카피캣이 `투시검색 프로`처럼 이름 지으면 테이크다운 근거가 약함.
- **실무 권고:**
  1. 출원 전 KIPRIS에서 `Z-EYE / 귀신같이 / ZEYE` 제9·42류 선행상표 검색 필수 (CCTV·카메라류에 Z-EYE 계열 선등록 가능성).
  2. 1호는 '알박기'보다 **사용에 의한 식별력(제33조 제2항) 증거 축적용 출발점**으로 위치시키고, 숏폼·커뮤니티 노출 기록(날짜·조회수)을 처음부터 아카이빙.
  3. 2호는 `투시검색 귀신같이`(한글)와 `Ghosti`(영문 단독+도형)를 분리 출원하는 안도 검토 — 영문 단독 표장이 독점력의 실질 근거가 됨.

### 5-2. 네이밍 (안건 1)
- **'투시' 단어 연상 리스크:** 앱스토어·네이버에서 "투시 앱"은 '옷 투시 카메라' 등 장난/기만 앱 이미지가 강함. 스토어 심사(기만적 기능 오인) 및 검색결과 오염, 그리고 공유방 사용자에게 "내 파일을 들여다본다"는 프라이버시 오해 소지. → 카피에 `내 파일 속` 수식을 항상 붙이는 가이드 필요.
- **기능명 = 앱명 충돌:** 현재 사이드바 서브메뉴가 `🎯 AI 투시검색 / 🩺 클린몬스터 / 🛠️ 설정몬스터`. 앱 간판이 '투시검색'이 되면 "투시검색 앱 안의 투시검색 메뉴"가 되어 클린몬스터·설정몬스터가 하위 부속처럼 보임. 서브메뉴명 재정의 필요(예: `🎯 찾기`).
- **전사 생태계 연동:** 허브 앱 스위처(`HubAppSwitcher`) 라벨·로고는 MerlinFamilyOS 관할 → 확정 시 우체국 제안서로 요청(직접 수정 금지).

### 5-3. UI/스토어 표기 (안건 3)
- 레이아웃 자체는 현재 [GhostiBrandLogo.tsx](../src/components/GhostiBrandLogo.tsx) 구조(36px 심볼 + 2단 텍스트, 알약/눈알 이모지 이미 삭제됨)에서 **1단 `Ghosti` ↔ 2단 문구만 교체**하면 되므로 작업량 작음. 한글 22px font-black + 영문 10~11px 조합 높이 약 33px로 36px 심볼과 정렬 가능.
- **스토어 타이틀 길이 초과:** `투시검색 (Ghosti) - 영상·문서·사진 1초 AI 검색 & 라운지`는 약 38자 → Google Play·App Store 앱 이름 한도 30자 초과. 예: `투시검색 Ghosti: 사진·영상·문서 AI검색`(약 25자).
- **'1초' 등 수치 표현:** 스토어 타이틀에 검증 어려운 성능 수치는 심사 리젝 사유가 될 수 있어 설명란으로 이동 권장. 스토어 등록정보에 '구글포토' 등 타사 상표 언급 금지(바이럴 문구에서만 사용).
- **부수 발견:** `index.html` meta description에 폐기된 워딩 `AI 주치의`가 잔존 → 간판 전환 작업 시 함께 정리 필요.
