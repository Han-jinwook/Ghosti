## 0. 글로벌 공식 브랜드 체계 확정 (`제트아이 Z-Eye`) & 5대 무기 라인업

- **공식 브랜드명:** **`제트아이 (Z-Eye / Zeye)`**
  - **마케팅 핵심 브랜드 서사 (`Zero-Cloud` + `A to Z`):** **`"Zero-Cloud (클라우드 월세 0원, 해킹 위험 0%)"`** + **`"A to Z (내 기기의 모든 파일과 문제를 처음부터 끝까지 꿰뚫어 보는 눈)"`**으로 풀어내어 브랜드 스토리텔링을 완성합니다.
  - **초월적 상징성 (Ultimate Z + Zero-Cloud):** 알파벳의 끝판왕 `Z(Ultimate)`와 `Zero-Cloud(클라우드 비용 Zero, 서버 유출 Zero)`의 앞 글자 `Z`, 만물을 꿰뚫어 보는 눈(`Eye`)을 결합. 서구권의 `Xen-(제노포비아)` 부정적 어감을 원천 배제하고 국내외 산업용 X-ray·안과 AI·기존 B2B 앱과의 상표권/SEO 충돌을 단번에 해결.
  - **글로벌 발음 유연성:** 한국·일본·유럽에서는 묵직한 어감의 **`제트아이(Z-Eye)`**, 미국 본토에서는 직관적인 **`지아이(Z-Eye)`**로 소통.
- **핵심 슬로건:** **`“The Ultimate All-Seeing AI & Zero-Cloud Lounge”`** *(만물을 꿰뚫어 보는 궁극의 AI 투시 엔진 & 무클라우드 시크릿 라운지)*
- **5대 무기 라인업:**
  1. **👁️ Z-Eye 투시검색:** 동영상 1초 구간·문서 본문·얼굴을 꿰뚫어 보는 최종 진화형 현미안 엔진
  2. **🛂 Z-Eye 여권 (Face Passport):** 이메일 계정에 귀속되어 어느 방에 가든 1초 만에 자동 연동·진화하는 만국공통 안면 시드
  3. **🔒 Z-Eye 라운지:** 개인 / 패밀리 / 클럽 / 💼 업무 라운지
  4. **🩺 Z-Eye 클린 몬스터:** PC·폰 속 숨은 쓰레기와 유령 프로세스를 투시 검진하는 AI 주치의 (`OS 기본 [휴지통]` 직행 + `[↩️ 1초 실행 취소(Undo)]`)
  5. **🛠️ Z-Eye 설정 몬스터:** 복잡한 기기 설정을 AI 음성으로 1:1 안내하고 오프라인 서버 릴레이를 해결하는 해결사

### 1.3 노션(Notion) 스타일 좌측 접이식 사이드바 & 백지 도화지(Zen Canvas) UI/UX 아키텍처 (`DesktopDashboard.tsx`, `VoiceHeroStage.tsx`, `LoungeView.tsx`, `FaceMemberRegistryModal.tsx`)
1. **노션형 좌측 접이식 사이드바 (`lg+` 244px 고정·접기 지원 + 모바일 `☰` 슬라이드 드로어 + 모바일 상단 1줄 5대 라운지 바):**
   - 기존의 답답한 상단 2층 헤더를 걷어내고, 5대 시크릿 라운지(`개인` / `패밀리` / `클럽` / `스쿨` / `업무`), 패밀리 방 트리(`🏠 우리집` / `🏡 본가` / `🌸 처가`), 각 라운지별 서브메뉴, 그리고 하단 **`[F 멀린 패밀리 앱]`** 생태계 런처를 좌측 사이드바 트리로 통합했습니다.
   - 상단 헤더는 초슬림 1줄로 압축되어 좌측에는 노션 스타일 경로 브레드크럼(`패밀리 라운지 / 우리집 / 앨범`)이, 우측 끝에는 멀린 패밀리 앱 공통 불변 앵커(**`[👑 문패] [🛠️ 설정 몬스터] [🪙 크레딧] [☀️/🌙 테마 토글]`**)가 동일한 위치에 고정됩니다.
   - 모바일(`360px` 이상 `< lg`)에서는 상단 1줄에 5대 라운지 단축 알약(`개인 / 패밀리 / 클럽 / 스쿨 / 업무`)을 노출하고, 좌상단 `☰` 버튼 터치 시 전체 사이드바 드로어가 슬라이드 오픈됩니다.
2. **백지 도화지 모드 (`Zero-State Zen Canvas` ➔ 사용자 액션 시 점진적 채움):**

   - 사용자가 검색어를 입력하거나 추천 칩·인물 알약·탭을 클릭하는 순간(`showCanvasResults = hasExecutedUserSearch || hasUserSelectedSearchTab || isCanvasExpanded`) 도화지 아래로 결과 카드가 펼쳐지며, 상단 **`[▲ 백지 도화지로 접기]`** 버튼으로 언제든 다시 깨끗한 도화지 상태로 접을 수 있습니다.
3. **1줄 노션 콜아웃(`Callout`) 접기 & 업무 라운지 우측 '사이드 피크(`Side Peek`)' 드로어:**

   - **업무 라운지 (`WorkLoungeB2BHub`) 데이터베이스 리스트 + 우측 사이드 피크:** 기존의 상시 7:5 화면 분할을 제거하고, 평소에는 폴더 필터 알약(`💽 전체`, `📄 S:\ 최상단`, `📁 계약서` 등)과 1줄 문서 행(Row) 리스트만 시원하게 보여주다가 특정 문서 행(실물 `1줄빛러M.gif` 포함)이나 추천 질의를 클릭할 때만 우측에서 **사이드 피크(`Side Peek`) 프리뷰 패널**이 열립니다.

## 2. 코어 검색 엔진 & 검색 탭 UX 규칙 (`vite.config.ts`, `aiEngine.ts`, `useSaySeeStore.ts`, `VoiceHeroStage.tsx`)

### 2.1 첫 검색 시 '🎬 동영상' 기본 노출 & 재검색 시 '마지막 선택 탭 유지' (`useSaySeeStore.ts`)
1. **첫 검색 시 임팩트 중심 자동 포커스 (`!hasExecutedUserSearch && !hasUserSelectedSearchTab`):**
   - 사용자가 처음 검색어를 입력하면 3개 탭에 각각의 검색 결과 숫자를 배지로 동시에 표시하되(`🎬 동영상 (2)` · `🖼️ 사진 (7)` · `📁 문서 (1)`), 가장 시각적 임팩트가 큰 **`🎬 동영상` 탭을 기본(Default)으로 오픈**하여 타임라인 구간 점프 재생의 기술력을 즉시 체감하게 합니다.
2. **탭 수동 선택 후 재검색 시 마지막 탭 유지 (`hasUserSelectedSearchTab === true`):**
   - 사용자가 특정 탭(예: `🖼️ 사진` 또는 `📁 문서`)을 클릭해 열람하다가 새로운 검색어로 다시 검색하면, 각 탭의 결과 건수 배지는 실시간으로 업데이트하되 **사용자가 마지막으로 선택했던 탭이 그대로 열린 상태로 유지**됩니다.

### 2.2 검색 파이프라인 구조 (768차원 벡터 엑셀 + 온톨로지/지명 브레이크 하이브리드)
1. **한국어 토크나이저 및 조사/어미 분리 (`stripKoParticle`):**
   - `바닷가`, `창가`, `물가`, `휴가`, `아이`, `어린이`, `고양이`, `멍멍이`, `물놀이`, `목걸이`, `귀걸이`, `종로`, `을지로`, `다리`, `나무다리`, `선풍기`, `비행기` 등 끝글자가 조사와 겹치는 명사(`KEEP_NOUNS`)를 보호한 뒤 한국어 조사를 제거하여 어근 토큰을 추출합니다.
2. **동영상 전 구간 타임라인 엄격 프레임 매칭 (`searchVideoSceneItems`):**
   - 최신 동영상 3개(`20240719_105706.mp4`, `20240720_134808.mp4`, `20240722_052422.mp4`)의 **전 구간(`00:00`~끝, 총 20개 타임라인 프레임)**과 대조하여, ① 실제 타임라인 프레임 적중, ② 필수 핵심 토큰 충족, ③ 1순위 대비 최소 점수 임계치(`totalScore >= topScore * 0.55`) 3중 브레이크를 통과한 정답 영상만 노출합니다.
   - 포착된 카드는 `<video src="...#t=matchedSeekSec">` 프리뷰와 HTTP `206 Partial Content` Byte-Range 스트리밍을 통해 클릭 즉시 해당 초(Sec)부터 재생됩니다.

## 3. 만국공통 'Z-Eye 여권(Z-Eye Face Passport)' & 인물별 고유 타임라인 바구니 & 화면 정화(UI Diet) (`poc/build_face_clusters_index.mjs`, `useSaySeeStore.ts`, `FaceMemberRegistryModal.tsx`, `LoungeView.tsx`)

### 3.1 다년도·다각도(정면·측면·야외·선글라스·야간) 5대 스타일 슬롯 자동 선별 알고리즘
- 동일 인물의 대표 시드를 추출할 때 매년 천편일률적인 정면 컷만 뽑지 않고, 연도를 분산함과 동시에 촬영 조건과 각도가 최대한 다른 **5대 스타일 슬롯(`정면·선명`, `측면·미소`, `야외·노을`, `선글라스·역광`, `야간·실내`)** 베스트 컷을 내부에서 하나의 **‘멀티-조건 시드 패키지’**로 자동 결합합니다.

### 3.2 인물별 고유 타임라인 바구니 (Person-Bound Timeline Bucket) & 미래 바구니 자동 확장
1. **방(Room)이 아닌 '각 인물(Person ID)의 최초 생성 연도'에 귀속:**
   - 성인(10년 주기) / 미성년자(5년 주기) 바구니의 기준 연도는 각 인물의 시드가 최초 생성된 연도에 고정됩니다.
   - 한 라운지 안에 **2026년에 최초 세팅된 기존 가족(`2026~2017` 바구니)**과 **2029년에 새로 합류한 처가 식구(`2029~2020` 바구니)**가 함께 있더라도, 검색 및 역스캔 시 각 인물은 본인의 고유 연도 바구니를 독립적으로 유지합니다.
2. **미래 바구니(Forward Bucket) 자동 생성:**
   - 시간이 흘러 2027년 이후의 신작 사진이 들어오면 기존 `2026~2017` 바구니를 밀어내지 않고, 그 위에 **`2027~2036`(성인 10년) 또는 `2027~2031`(아동 5년) 미래 바구니**를 자동으로 신설하여 세월의 기록을 보존합니다.

### 3.3 무질문 0.1초 자동 장착 & 방별 별명(Room Persona) 독립 매핑 (`getActivePersonaForCluster`)
1. **"시드를 가져올까요?" 질문 팝업 제로 — 이메일 여권 자동 연동:**
   - 새 라운지(처가방, 본가방, 클럽방, 스쿨방 등)를 개설하거나 입장할 때 번거로운 확인 창 없이 이메일 계정(`passportEmail`)에 귀속된 Z-Eye 여권 시드가 0.1초 만에 자동 장착됩니다 (`[🛂 Z-Eye 여권 자동 연동됨]`).

### 5.10 No-Cloud P2P 하이브리드 폴백 아키텍처(특허 제2호) & 초경량 Supabase DB 스키마 (`src/services/p2pHybridBridge.ts`, `supabase/z_eye_zero_cloud_schema.sql`, `vite.config.ts`)
1. **성공률 99.9% + 중계 서버비 0원 P2P 2단계 하이브리드 폴백 (`p2pHybridBridge.ts`):**
   - **Stage 0 — DB 저장 0 Byte 시그널링 (`SUPABASE_REALTIME_BROADCAST_ZERO_DB`):** Supabase Realtime Broadcast 메모리 패스스루 채널(`zeye-p2p-room:{roomId}`)만 사용하여 SDP Offer/Answer, ICE Candidate, 아웃바운드 터널 엔드포인트를 중매하므로 DB 테이블 Write 비용이 0 Byte입니다.
   - **Stage 1 — 1순위 `WebRTC DataChannel` 다이렉트 P2P (`WEBRTC_DATACHANNEL_DIRECT`):** 일반 NAT/동일 망 환경에서 중계 서버 없이 13KB WebP 썸네일, 30KB 오프라인 문서 요약, 5MB 무손실 원본을 직접 송수신합니다.

### 8.6 📜 [출시 전 이용약관(ToS) 필수 삽입] 제트아이 표준 면책 2대 조항 & 법적 방어 삼각 편대

- **이용약관(ToS) 필수 삽입 2대 문구:**
  1. **데이터 비보관(`Non-Custodial`) 원칙:** *"회사는 사용자의 원본 미디어 및 문서를 중앙 서버에 수집·보관하지 않으며, 모든 원본 데이터는 사용자가 지정한 로컬 단말기에 저장됩니다. 사용자 단말기의 물리적 파손, 분실, 또는 사용자 부주의로 인한 외부 악성코드 감염 등에 따른 책임은 사용자에게 있습니다."*
