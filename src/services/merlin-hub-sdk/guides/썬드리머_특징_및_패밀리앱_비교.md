# 🥇 썬드리머(SunDreamer) 정의·성격 및 SDK 6대 모듈 1:1 비교분석

본 문서는 멀린 패밀리 OS 생태계의 **1호 서비스 앱 '썬드리머(SunDreamer)'**의 공식 정의, 비즈니스 성격, 물리적 디렉토리 구조를 명확히 하고, **Merlin Hub SDK 6대 핵심 모듈별 1:1 정밀 비교**를 체계적으로 정리한 공식 규격서입니다.

---

## 🏛️ 제1부. 앱 정의 및 기본 성격 비교

| 구분 항목 | 멀린 패밀리 일반 앱 (어그로필터, 볼트, 뭐먹지, 리얼픽 등) | 🥇 1호 앱 썬드리머 (SunDreamer) |
| :--- | :--- | :--- |
| **1. 공식 앱 ID / 명칭** | `AggroFilter`(어그로필터), `Vaulter`(금고지기), `WhatEat`(뭐먹지) 등 | **`SunDreamer` (썬드리머)** |
| **2. 앱의 기본 성격** | 순수 온라인 AI 소프트웨어 / 디지털 콘텐츠 비서 | **실물 헬스케어 기기(자외선조사기) 서포트 PWA 웹앱** |
| **3. 타겟 유저 & 배경** | 온라인 신규 일반 대중 유저 | **11년간 네이버에서만 직접 운영 중인 2개 전문 질환 카페(2.5천 명 회원, '썬드림' & '자외선요법' 카페) 및 실구매자 5천 명**<br>*(※ '썬드림'은 자외선조사기 제품/브랜드명)* |
| **4. 비즈니스 모델 (BM)** | **광고형, 코인형, 혼합형으로 다양**<br>- 코인형(`Vaulter`), 혼합형(`AggroFilter`), 광고형(`RealPick`, `WhatEat`) | **코인 없고 광고 없음**<br>(오프라인 실구매 회원을 위한 순수 서포트 & 케어) |
| **5. 재화 및 보상 체계** | - 앱 유형에 따라 코인(C) 차감/충전 또는 광고 노출<br>- 유료앱 가입 시 500C / 추천 시 200C 허브 코인 보상 | - 코인 결제, 코인 차감 및 광고 노출 없음<br>- 오프라인 기기/소모품 구매에 활용 가능한 **자체 5,000P 지급** |
| **6. 물리적 디렉토리 구조** | 독립 단일 레포지토리 | **상하위 물리적 격리 구조**<br>- **루트 (`D:\LumiNote\`)**: 멀린님/스탭 전용 5천 고객 관리 CRM **'루미노트'** (`docs/기능명세서.md`)<br>- **하위 (`D:\LumiNote\sundream\`)**: 일반 회원용 1호 웹앱 **'썬드리머'** (`sundream/docs/기능명세.md`) |

## 🧩 제2부. Merlin Hub SDK 6대 모듈별 1:1 정밀 비교

| SDK 모듈 | 모듈 핵심 역할 | 일반 패밀리 앱 적용 방식 | 🥇 썬드리머 적용 방식 | 공유 여부 |
| :--- | :--- | :--- | :--- | :---: |
| **1. Auth (인증)** | 허브 이메일 6자리 OTP 인증 및 SSOT UUID 발급 | - 이메일 OTP 검증 및 JWT 발급<br>- 가입 즉시 500C 웰컴 배지 (유료앱) | - 이메일 OTP 검증 및 SSOT UUID 매핑<br>- **5,000 포인트 배지 표시** (`rewardType="point"`) | **⭕ 100% 공유**<br>(보상 배지만 포인트로 특화) |
| **2. Session & Profile (세션/프로필)** | 30일 롤링 세션 유지 및 패밀리 공통 프로필/설정 UI | - 30일 세션 갱신 (`newToken`)<br>- `HubProfileWidget`<br>- `HubProfileCard`<br>- `HubNotificationCard`<br>- `HubLogoutCard` | - 30일 세션 갱신 및 SSO 연속성 유지<br>- 프로필 위젯, 프로필/알림 카드, 로그아웃 등 **허브 표준 UI 전면 동일 적용** | **⭕ 100% 공유** |
| **3. Wallet / Billing (과금/지갑)** | 중앙 코인(C) 잔액 추적, 결제 위젯, AI 리소스 동적 차감 | - `family_wallet_*` 연동<br>- `chargeDynamic()` 실시간 차감<br>- `HubPurchaseWidget` 충전창<br>- 가불금(Pending Fee) 정산 | 🚨 **완전 제외 (미사용)**<br>- **코인 결제 및 차감 모듈 사용 안 함**<br>- 오프라인 CRM의 `customers.points` 원장으로 자체 포인트 독립 운영 | **❌ 제외 (코인 없음)** |
| **4. Referral (추천/초대)** | 추천인 코드 생성, 공유 버튼 및 초대 실적 집계 | - `HubReferralWidget`<br>- `HubHistoryList`<br>- 카카오톡/링크 복사 공유<br>- 추천 성공 시 200C 지급 (유료앱) | - `HubReferralWidget`, `HubHistoryList`, `HubShareButton` **UI 컴포넌트 공유**<br>- 코인 대신 썬드림 자체 포인트/이벤트 연동 | **⭕ UI/기능 공유**<br>(보상 재화만 분리) |
| **5. Notification (알림)** | 전역 시스템 토스트 팝업 및 메시지 노출 | - `<HubNotifier />`<br>- `useHubNotifier()` 훅 | - `<HubNotifier />` 및 `useHubNotifier()` **동일 모듈 100% 사용** | **⭕ 100% 공유** |
| **6. Navigation & Ads/UI (네비/광고/UI)** | 패밀리 앱 스위처, PWA 설치 유도 및 반응형 레이아웃 | - `HubAppSwitcher` (패밀리 간 이동)<br>- `HubPWAInstallPrompt` (설치 유도)<br>- 애드센스 광고 컴포넌트 탑재 | - `HubAppSwitcher`, `HubPWAInstallPrompt` **동일 모듈 100% 사용**<br>- 🚨 **광고 없음 (애드센스 미탑재)** | **⭕ UI 인프라 공유**<br>(광고 모듈 제외) |

## 🗄️ 제3부. 데이터베이스 & 특화 기능 비교

| 구분 항목 | 멀린 패밀리 일반 앱 (어그로필터, 볼트, 뭐먹지 등) | 🥇 1호 앱 썬드리머 (SunDreamer) |
| :--- | :--- | :--- |
| **1. DB 아키텍처 구조** | **2단계 구조**<br>① Hub DB (`family_users`, `family_wallet_*`)<br>② 앱 전용 서비스 DB | **3대 원장 물리적 격리 구조**<br>① **Hub DB (`family_users`)**: 인증 및 SSOT UUID<br>② **LumiNote DB (`customers`)**: 고객 원장 (포인트, 구매이력, 치료 기록)<br>③ **LumiNote DB (`admins`)**: 사내 스탭 전용 관리자 권한 |
| **2. 기존 고객 CRM 매핑** | 해당 없음 (온라인 신규 가입) | **네이버 이메일 자동 매핑**<br>- 11년 기존 회원이 네이버 이메일로 로그인 시, 루미노트에 저장된 11년 치 구매이력/수리 이력 및 잔여 포인트가 즉시 자동 동기화 |
| **3. 온보딩 화면 (비로그인)** | 서비스 기능 설명 및 무료 체험(가불) 유도 | **11년 네이버 전문 카페 실제 회원 치유 후기 (30개 엄선 링크) 바로가기 배너** |
| **4. 고유 특화 기능** | AI 영상 어그로 분석, 기밀 문서 OCR/암호화 등 | ① **1,600시간 램프 수명/조사시간 계산기 (`LampCheck`)**<br>② **매일 자외선 조사기 치유 기록 타임라인 (`Records`)**<br>③ **상세 구매이력 및 포인트 사용 내역 (`MyInfo`)** |

## 📌 핵심 요약 (Three-Point Summary)

1. **인프라 공유 (Auth, Session, Referral, Notification, Navigation)**: 허브 표준 SDK를 공유하여 패밀리 간 일체감 있는 SSO 및 UI 경험을 보장합니다.
2. **과금 & 광고 제외 (`Wallet ❌`, `Ads ❌`)**: 썬드리머는 **'코인 없고 광고 없는'** 순수 고객 케어 앱으로, 오프라인 실구매 회원을 위한 **자체 5,000P 포인트 제도**로 운영됩니다.
3. **독자적 본진 연동 (`LumiNote CRM`)**: 11년간 운영된 네이버 2개 질환 카페(2.5천 명) 및 5천 실구매자 관리 본진 프로그램인 '루미노트'와 1:1 매핑되어 구매이력 조회, 램프 수명 계산 및 치료 활동을 보조합니다.
