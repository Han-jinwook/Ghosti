## 2. 검색 탭 UX 원칙: 첫 검색 시 '동영상' 기본 오픈 & 재검색 시 '마지막 선택 탭 유지'

1. **첫 검색 시 임팩트 중심 자동 포커스:**
   - 처음 검색을 실행하면 3개 탭에 찾은 건수를 모두 배지로 표시하되(`🎬 동영상` · `🖼️ 사진` · `📁 문서`), 가장 시각적 임팩트가 큰 **`🎬 동영상` 탭을 기본(Default)으로 오픈**합니다.
2. **재검색 시 마지막 선택 탭 유지:**
   - 유저가 특정 탭(예: `🖼️ 사진` 또는 `📁 문서`)을 클릭해 보다가 다시 검색을 실행하면, **유저가 마지막으로 선택했던 탭이 그대로 열린 상태를 유지**합니다.
3. **검색 엔진 코어 Fix 보존 ("768차원 벡터 엑셀 + 온톨로지/지명 브레이크"):**
   - `runHybridCorpusSearch` 하이브리드 구조 및 복합 명사/지명 엄격 `AND` 교집합 원칙(일치 사진 없을 시 정직하게 `0장` 반환)을 철저히 유지합니다.

## 3. 만국공통 'Z-Eye 여권(Z-Eye Face Passport)' & 인물별 고유 타임라인 바구니 원칙

1. **다년도·다각도(`정면·측면·야외·선글라스·야간` 5대 슬롯) 최대 변별력 자동 추출:**
   - 동일 인물의 대표 시드를 뽑을 때 연도를 분산함과 동시에 촬영 조건과 각도가 최대한 다른 베스트 컷 5대 슬롯을 내부에서 자동 결합합니다.
2. **바구니 기준 연도는 '방(Room)'이 아닌 '각 인물(Person ID)의 최초 생성 연도'에 귀속:**
   - 10년(성인) / 5년(미성년자) 바구니의 기준 연도는 '각 인물의 시드가 최초 생성된 연도'로 고정하며, 미래 연도 사진이 들어오면 위로 **미래 바구니(`2027~2036` / `2027~2031`)를 자동 확장(Forward Bucket)**합니다.
3. **무질문 0.1초 자동 장착 & 방별 별명(Room Persona) 독립 매핑:**
   - 새 공유방 개설/입장 시 질문 팝업 없이 이메일 계정에 귀속된 여권 시드가 0.1초 만에 자동 장착됩니다 (`[🛂 Z-Eye 여권 자동 연동됨]`).
   - 시드(768차원 벡터 + 연도 바구니)는 100% 공유하되, 방마다 부르는 호칭(`우리집: 👑 멀린` ↔ `처가방: 👑 둘째사위` ↔ `본가방: 👑 큰아들(진욱)` ↔ `동호·동창회방: 멀린프로`)만 독립 매핑됩니다.

## 4. 화면 정화(UI Diet) 4대 규칙 & `👑 방장` 호칭 통일 원칙

1. **`💻 내 기기` 및 `💼 업무 공유`에서 얼굴/여권 박스 100% 비노출:**
   - `내 기기`와 `업무 공유`에서는 얼굴 여권 등록 박스를 렌더링하지 않으며, 오직 `📸 사진 공유(패밀리·동호회·동창회)`에서만 인물 여권 바가 작동합니다.
2. **가로 6열 미니 아바타 나열 폐기 ➔ '1장씩 스무스 사각형 카드 (등록 완료 시 Auto-Hide 완전 소멸)':**
   - 이미 등록된 멤버는 상단 바의 깔끔한 별명 알약 버튼으로만 노출하고, 확인이 필요한 항목이 있을 때만 **큼직한 사각형 사진(`rounded-2xl`) 1장씩** 카드로 띄워 `[⭕ 맞아요! 등록]` 완료 시 화면에서 완전히 소멸(`Auto-Hide`)시킵니다.
3. **어르신·가족 친화적 문구 정돈:**
   - 기계적인 개발자 용어를 배제하고 **`✨ 얼굴 자동 매칭 도우미`**와 **`⚡ 확인 건너뛰고 사진만 바로 올리기 (방장이 나중에 정리)`**로 다정하게 표기합니다.
4. **`호스트 ➔ 👑 방장` 교체 및 왕관(`👑`) 계급장 표시:**
   - 모든 `'호스트'` 표기를 **`👑 방장`**으로 통일하고, 방 개설자의 별명 알약 앞에 항상 **`👑` 왕관 아이콘**을 표시합니다.

## 5. 공유방 데이터 흐름 · 동기화 · 권한 · 탈퇴 6대 확정 규칙

1. **방 개설 시 설정 옵션 (`24시간 내 올린 본인 삭제` + `방장 상시 숨기기 권한 보유 여부 선택`):**
   - 업로드 후 **24시간 내에는 올린 원본 주인이 언제나 직접 삭제 가능**하며, 멤버가 잘못된 사진을 올리는 것을 항상 감시·정리할 수 있도록 **방장이 올라오는 처음부터 상시 `[숨기기]` 권한을 가질지** 방 개설 시 설정 옵션으로 직접 선택합니다.
2. **`64-bit dHash` 진짜 원본 검증 안전핀:**
   - 중복 사진 감지 시 단순 바이트 용량 비교가 아니라 **`EXIF 촬영 원본 메타데이터`가 살아있고 `실제 픽셀 해상도(width × height)`가 더 큰 진짜 원본일 때만 자동 교체(댓글·좋아요 유지)**합니다.
3. **평소 숨김 썸네일 DB & `[🔄 원본 동기화]` 경로 지정 자체 해결:**
   - 평소 멤버 기기에는 보이지 않는 시스템 영역(`%LOCALAPPDATA%\Merlin\thumb_db`)에 **13KB 썸네일 DB만 보관**하다가, Wi-Fi 및 여유 공간이 넉넉할 때 **`[🔄 원본 동기화]`**를 켜면 저장 경로를 지정·안내받고 내 기기에 원본을 복제하여 방장 PC 호출 없이 **내 기기에서 100% 자체 해결**합니다.
4. **업무 공유(`S:`) 동시 편집 안내 단순화:**
   - 윈도우 탐색기(`S:`)에서 열 때는 엑셀·오피스 기본 읽기 전용 규칙대로 작동하며, 웹/앱 검색에서 사용 중인 문서를 열 때는 **`"🔒 현재 [OOO]님이 사용 중입니다. 읽기 모드로 열립니다."`**로 안내합니다.
5. **구형 보관함 폐기 ➔ `OS 기본 [휴지통]` 일원화 + 랜섬웨어 서킷 브레이커:**
   - 별도 중간 보관함 없이 **OS 기본 `[휴지통]`(`Win32 FOF_ALLOWUNDO` + `[↩️ 1초 실행 취소]`)**으로 직행하며, **1분 내 30개 이상 삭제·변조 또는 미끼 파일(`_000_zeye_guard.docx`) 훼손 시 백업 PC 1·2호 미러링을 즉시 차단(Freeze)**합니다.
6. **탈퇴(`자퇴` · `강퇴` 동일) 시 데이터 처리 기준 (내 개인 여권 100% 보존):**
   - 자진 탈퇴나 강퇴 시 즉시 해당 방 계정 아웃 처리되며, 기기 내 숨김 영역의 **그 공유방 썸네일 DB · 공유방 검색 인덱스 · 탈퇴하는 그 공유방 내부 타 멤버 여권 목록만 0.1초 만에 자동 삭제**됩니다.
   - **유저가 자기 PC에 인덱싱해 둔 ‘나 자신의 Z-Eye 여권’ 및 ‘내 기기 개인 인덱스’는 절대 삭제되지 않고 100% 그대로 보존**되며, 기동기화된 로컬 원본 폴더도 반납 없이 각자 자율 관리합니다.
