## 1. 💡 왜 ‘모바일 웹 전용 브릿지 + 1초 프리뷰’ 구조인가? (도입 배경 · Why)

귀신같이는 **엔진이 설치된 PC와 양대 스토어에 설치된 정식 `모바일 앱(Android/iOS)`만 실사용 기기로 취급**하며(`2026-11-24` 멀린님 확정), 모바일 웹 브라우저는 **온보딩 쇼룸 및 QR·공유방 초대 링크를 설치된 앱으로 넘겨주는 전용 다리(브릿지)** 역할에 집중합니다.

- **❌ 실패 방식 A (모바일 웹에 영구 체류시키거나 웹을 실사용 기기로 등록하는 방식):**
  - 이미 `귀신같이` `모바일 앱`이 설치된 가족·회원이 링크를 눌렀는데도 답답한 카톡 인앱 브라우저에 갇히고, 모바일 웹 세션이 기기 목록에 중복 등록되거나 갤러리 전체 연동·APNs/FCM 백그라운드 푸시·원본 동기화 같은 네이티브 초능력을 쓰지 못합니다.
- **❌ 실패 방식 B (닫기 선택지조차 없이 무조건 강제 납치하는 방식):**
  - 아직 사진 한 장도 못 본 미설치 수신자가 브릿지를 닫고 미리 구경할 여지가 없으면 이탈률이 높아집니다.
- **⭕ 정답 확정: 『앱 직행 + 모바일 웹 전용 브릿지(`MobileShareInviteBridgeOverlay`) + 선택적 1초 웹 구경』:**
  1. **이미 `모바일 앱`이 깔린 사람**은 `App Links` / `Universal Links` 또는 브릿지의 `[앱으로 바로 열기]`로 **0.1초 만에 네이티브 `모바일 앱`의 그 공유방으로 직행**합니다.
  2. **모바일 웹으로 열린 수신자**에게는 먼저 전용 브릿지 창(`MobileShareInviteBridgeOverlay`)이 떠서 **설치된 앱 열기 / Google Play·App Store 설치 / 설치 후 초대방 자동 유지(`Deferred Deep Link`)**를 안내하며, 브릿지를 닫으면 **카톡 인앱 웹 화면에서 로그인 없이 1초 만에 공유 사진 바둑판을 구경**할 수 있습니다.
  3. 사진 구경 중 **`3대 본능 스위치`(사진 올리기 / 원본 저장 / 새 사진 알림)**를 누르면 다시 양대 스토어 무료 `모바일 앱` 설치로 연결되고, **설치 후 앱을 열자마자 아까 보던 바로 그 공유방으로 자동 입장(`Deferred Deep Link`)**합니다!

## 2. 🚀 유저 눈앞에서 벌어지는 『모바일 초대링크 3단계 흐름』 상세 시나리오

### ▶ Step 1. [이미 `모바일 앱`이 설치된 폰] — 0.1초 만에 네이티브 `모바일 앱` 해당 공유방 직행!
- 스마트폰에 이미 `귀신같이` `모바일 앱`(`안드로이드 앱` 또는 `아이폰 앱`)이 설치된 상태에서 카톡·문자 초대 링크(`https://ghosti.sundreamer.app/?invite=...&inviteToken=...`)를 터치하면:
  1. **공식 딥링크 & 안전한 앱 호출 라우팅 (`App Links` / `Universal Links` + `ghosti://invite?...` + Android `intent://` 무납치 폴백):**
     - `public/.well-known/assetlinks.json`(Android SHA-256 서명 지문 검증) 및 `public/.well-known/apple-app-site-association`(iOS `7K5PPQDZ5L.app.sundreamer.ghosti`) 정식 매니페스트와 네이티브 커스텀 스킴(`ghosti://invite?...`)이 연동됩니다.
     - 외부 App Links 자동 전환을 제한하는 카카오톡 등 인앱 웹뷰 환경에서는 전용 브릿지(`MobileShareInviteBridgeOverlay`)의 **`[앱으로 열기]`** 클릭 시 안드로이드는 `intent://invite?...#Intent;scheme=ghosti;package=app.sundreamer.ghosti;S.browser_fallback_url=...;end`, 아이폰(`iOS`)은 `ghosti://invite?...`로 네이티브 `모바일 앱`을 즉시 호출합니다.
  2. **해당 공유방 정확 매핑 입장 (`applyShareInviteDeepLink`):**
     - 앱이 열릴 때 빈 첫 화면이나 엉뚱한 탭이 아니라 초대 링크에 담긴 공유방(`🏠 우리집` / `🏡 본가(친가)` / `🌸 처가(친정)` / `⛰️ 동호회·모임` / `🎓 동창회`)의 사진 피드(`mobileTab: 'search'`)로 정확히 직행하여 즉시 사진 올리기·원본 저장·검색을 이용할 수 있습니다.

### ▶ Step 2. [모바일 웹 진입 시] — 전용 앱 이동 브릿지 안내 & 닫기 시 카톡 인앱 `웹 화면` 1초 구경! (`Read-Only Preview`)
- 모바일 웹 브라우저에서 초대 링크(`?invite=...&inviteToken=...`)로 진입하면 최상단에 **`MobileShareInviteBridgeOverlay`** 전용 브릿지가 열려 **앱 열기 / OS 맞춤 스토어 설치**를 최우선 안내하며, 사용자가 브릿지를 닫으면 **카톡 인앱 브라우저 안에서 로그인·가입 창 없이 1초 만에 해당 공유방 사진 그리드를 그대로 구경**할 수 있습니다.
- **다정한 초대장 헤더 & 방장 별명 단일 진실(SSOT) 무깜빡임 보장 (개발자 내부 용어 100% 배제 · 타 계정/타 방 별명 혼입 `0%`):**
  - 기존의 딱딱한 개발 용어(`무가입 프리뷰 모드 ON`, `13KB 썸네일` 등)를 전수 제거하고, 수신자가 누구의 어떤 방에 초대받았는지 한눈에 안심할 수 있도록 **`💌 [방장 이름]님이 초대한 [🏠 우리집 가족 사진방] · 로그인 없이 구경 중`** 배너와 공유 사진 바둑판을 깔끔하게 표시합니다.
  - 특히 초대 URL 파라미터를 허브 SSO(`?token=`)와 충돌하지 않는 **`?invite=...&inviteToken=...`**(기설치 구버전 모바일 앱 `v1.0.41` 이하 `App Links`/`Universal Links` 하위호환용 `token` 병기 + 웹 마운트 전 `main.tsx` 자동 정화 포함)로 완전 분리하고, 미검증 URL `?host=`나 전역 `sessionStorage` 대신 오직 해당 `inviteToken`에 대해 서버 DB(`ghosti_get_guest_preview_room` · `photo_resolve_accessible_rooms`)에서 검증된 방장 별명만 토큰 격리 캐시(`ghosti_verified_invite_v2::<inviteToken>`)로 표시하여, 다른 계정이나 다른 공유방의 별명이 0.1초라도 잠깐 떴다가 바뀌는 깜빡임·혼동과 새로고침(`F5`) 시 세션/사진 유실을 원천 차단합니다.
- **설치·가입 없이 즉시 허용하는 범위 (`Read-Only Sandbox` · 『방식 A』 14일 초대 마중물 버퍼 24시간 무중단 열람):**
  1. **방장 PC·폰 전원 무관 14일(2주) 초대 골든타임 24시간 즉시 열람 (`방식 A` + `14일 TTL` 확정)**: 초경량 `13KB` WebP 썸네일·검색 인덱스·메타데이터를 초대 골든타임인 **14일(2주) 동안 서버 마중물 버퍼(`ghosti_room_shared_photos`)에 유지**하여, 방장이 PC를 끄거나 폰 화면이 잠겨 있어도 카톡 초대 링크 클릭 즉시 **해당 공유방 전체 사진 그리드, 상단 인물 동그란 문패(얼굴 모아보기), 친근한 촬영 날짜·대표 지역명(예: `2024년 8월 · 강릉 경포대`)**이 0.3~0.8초 내에 전부 표시됩니다 *(비로그인 게스트는 브라우저 `IndexedDB` 저장 0 Byte로 창 종료 시 흔적이 남지 않으며, 14일 경과 마중물은 서버에서 자동 소거되고 정식 합류 멤버는 본인 기기 로컬 금고(`${email}::${roomId}`)에 영구 캐싱되어 평생 열람·검색하고 재초대 `[💌 초대 링크 복사]` 시 1초 만에 서버 마중물로 자동 재장전됨)*.
  2. **0.04초 초고속 검색 & 인물별 모아보기 체험**: 공유방 내 키워드(`"바다"`, `"수학여행"`, `"가족"` 등) 검색 및 인물 문패 클릭 필터링을 로그인 없이 그대로 체험합니다.

### ▶ Step 3. [자연스러운 앱 설치 전환] — ‘3대 본능 스위치’ 클릭 시 양대 스토어 무료 앱 설치 & 해당 방 자동 입장 (`Deferred Deep Link`)
- 눈으로 사진을 충분히 구경해 마음이 열린 수신자가 아래 **3대 본능 스위치** 중 하나를 터치하는 순간, **`[📱 무료 『귀신같이』 모바일 앱으로 이 사진방 바로 입장]`** 브릿지 모달이 스르륵 열립니다:

  2. **스위치 ② `[💾 고화질 원본 내 폰에 일괄 저장]`**: *"카톡처럼 화질 안 깨지는 진짜 원본으로 내 폰에 다 받아야지!"*

- **OS 자동 판별 스토어 직결 & 설치 후 해당 공유방 자동 입장 (`Deferred Deep Link`):**
  - 브릿지 모달에서 수신자의 스마트폰 OS를 자동 판별하여 **안드로이드 폰은 Google Play(`app.sundreamer.ghosti`)**, **아이폰은 Apple TestFlight / App Store(`id6836307976`)** 설치 화면으로 연결하며, 이미 앱을 설치한 사용자를 위한 **`[📱 이미 모바일 앱이 깔려 있어요 ➔ 앱으로 이 방 즉시 열기]`** 버튼도 함께 제공합니다.

    - **iOS & 공통 보조 경로**: 스토어 이동 버튼 클릭 시 초대방 토큰(`GHOSTI_INVITE_V1:...`)을 클립보드에 안전 백업하며, 앱 설치 후 원래 카톡 초대 링크를 다시 누르거나 공유방의 **`[💌 받은 카톡 초대 링크로 방 바로 열기]`** 버튼을 원터치하면 즉시 해당 공유방으로 입장합니다.
  - **PC 데스크톱 `웹 화면` 및 비로그인 업로드 원천 차단 원칙**: 비로그인 상태에서는 모바일·PC 어느 경로로도 공유방 사진 업로드가 원천 차단되며, PC 브라우저(또는 앱 설치 후 비로그인 상태)에서 `[📸 내 사진도 이 방에 추가하기]` 클릭 시 정식 **이메일 10초 인증 로그인(`HubAuthModal`)** 완료 후 해당 방 멤버(`ghosti_accept_room_invite`)로 합류하여, `PC 엔진`(`Z코어`) 연결 유무와 무관하게 파일 탐색기 직접 선택(`📂 파일 탐색기에서 직접 사진 고르기`) 또는 로컬 갤러리에서 즉시 사진을 올릴 수 있습니다.

## 3. 🛡️ 보안 및 프라이버시 안전장치 ("링크만 알면 외부인이 원본을 다 가져가는 것 아닌가?")

1. **전용 초대 링크(`?invite=...&inviteToken=...`) vs 일반 탭 주소(`/?lounge=...`) 엄격 분리 · 타 방 `0장` 격리 · 초대방 왕복/새로고침(`F5`) 불변 보존 · 재장전 타 계정 중복 방지:**
   - 공유방 초대는 일반 브라우저 주소창의 탭 주소(`/?lounge=family&tab=dashboard&room=본가(친가)`)가 아니라, 반드시 **`[💌 가족방/모임방/동창회 초대 링크 복사]` 버튼으로 생성되는 전용 보안 초대 링크(`?invite=...&inviteToken=...`)**로만 이루어집니다. 방장이 사진 공유 메뉴에 진입하는 즉시 서버 브릿지(`photo_resolve_accessible_rooms`)가 5대 표준 방(`우리집`·`본가(친가)`·`처가(친정)`·`동호회`·`동창회`)의 DB 방과 14일 초대 토큰(`roomTokensByKey`)을 일괄 선행 예열하여, 방 이동 직후 `[💌 초대 링크 복사]`를 연속 클릭하고 카톡 창으로 즉시 화면을 전환하더라도 비동기 시차나 브라우저 포커스 상실로 직전 방(예: `본가`) 링크가 클립보드에 잔류하는 현상 없이 클릭 즉시 `0.00ms` 동기 복사를 보장합니다. 또한 로그인한 사용자가 초대 링크로 접속해 정식 멤버(`ghosti_lounge_members`) 편입이 완료된 직후에는 브라우저 주소창에서 초대 파라미터를 즉시 정리(`stripConsumedInviteParamsFromLoggedInUrl`)하며, 초대 파라미터(`?invite`·`?inviteToken`)가 없는 일반 경로 접속 시에는 이전 방문 방의 `sessionStorage` 초대 잔재를 즉시 소거하여 이전 초대방(`본가` 등)으로 강제 이동되는 현상을 차단하고 일반 탭 주소를 복사해 초대받지 않은 새 계정·시크릿 창에서 열었을 때는 항상 **`0장`(빈 방)**으로 엄격 격리합니다 *(단, 이미 전용 초대 링크를 눌러 해당 방의 정식 멤버로 합류한 계정은 이후 일반 탭 진입 시에도 합류한 공유방 사진을 계속 열람 가능)*.
   - 비로그인 초대 링크 수신자가 초대받지 않은 다른 방 탭(`본가`·`처가`·`동호회`·`동창회`)을 눌러 `0장`(빈 방)을 확인한 뒤 다시 원래 초대받은 공유방(예: `우리집`)으로 돌아오거나 브라우저 새로고침(`F5`)을 눌러도, 탭 범위별 메모리 병합(`freePhotoShareSlice.ts`)과 서버 검증 토큰 메타(`resolveInvitedHostLoungeAndRoom` ➔ `ghosti_verified_invite_v2::<inviteToken>`) 및 비로그인 URL 파라미터 보존(`App.tsx:buildNavUrl`)을 통해 초대받은 공유방 사진이 단 1장도 유실되지 않고 `0.00초` 즉시 유지되며, `[💌 초대 링크 복사]` 재장전(`reseedRoomPhotosForInvite`)은 오직 해당 `room_id`의 로컬 금고 원본 사진만 대상(원 업로더 별명 보존)으로 동작하여 사진을 올리지 않은 새 계정 이름으로 기존 사진이 중복 등록되는 현상을 원천 차단합니다.
2. **비로그인 웹 구경 단계에서의 원본 · 정밀 GPS 좌표 보호 및 쓰기 액션 분리:**
   - 카톡 인앱 웹 구경 단계(`isGuestPreviewMode = true`)에서는 가벼운 `13KB` 화면 확인용 썸네일 그리드, 친근한 촬영 연월일·대표 지역명, 그리고 기존 댓글·하트 **열람(`읽기`)**까지만 개방하여 구경의 재미와 가입 동기를 살립니다.
   - 반면 주거지(아파트 동·호수 등) 특정 위험이 있는 **소수점 정밀 GPS 위경도 좌표 원문**은 비노출로 원천 보호하며, **무압축 고화질 원본(`5~20MB`, P2P 직결) 다운로드 · 내 사진 업로드 · 하트 누르기/댓글 작성(`쓰기`) · 새 사진 알림 받기** 등 실제 참여 액션은 정식 `모바일 앱` 입장(또는 PC 멤버 합류) 이후에만 허용됩니다.
3. **방장의 상시 `[숨기기]` 및 멤버 내보내기(`Veto`) 권한:**
   - 업로드 후 24시간 내 본인 삭제 권한과 방장의 상시 `[숨기기]` 및 `[✕ 멤버 내보내기]` 권한이 결합되어 실수 업로드나 외부인 혼입을 즉시 차단합니다.
