## 1. 체험판 온보딩 프레임 대전환: "내 PC 직접 구동(권장) + QR 모바일 연결" vs "모바일 단독 시 클라우드 서버 무료 대여" (`OnboardingModal.tsx`, `VoiceHeroStage.tsx`, `DesktopDashboard.tsx`)

### 1.1 2-Track 온보딩 아키텍처 (`onboardingTrackMode: 'pc_local' | 'cloud_rental'`)
- **Track A. `[💻 PC/노트북 앞일 때 — 강력 추천 (외부 서버 전송 0%)]` (`pc_local` 기본값):**
  - 비로그인 상태라도 웹에서 **`[💻 내 PC로 1분 안심 체험하기 (권장)]`**를 누르면, MS EV 코드사이닝 인증서가 서명된 `SaySee_PC_Agent.exe`가 실행되어 파일이 **외부로 단 1바이트도 나가지 않고 100% 내 PC 내부에서만** 초고속 분석됩니다.
  - **📱 실시간 QR 코드 모바일 동시 페어링 UI (`PairingQrCodeSvg` & 헤더 QR 드롭다운):**
    - PC 에이전트가 실행되는 동안 온보딩 모달 우측 및 데스크톱 상단 헤더에 큼직한 **'모바일 연결 QR 코드'**를 노출합니다.
    - 안내 문구: *"스마트폰 카메라로 이 QR을 스캔해 1MB 앱을 실행하면, 번거로운 로그인이나 6자리 코드 입력 없이 내 폰과 PC가 그 자리에서 하나로 연결됩니다!"*
- **Track B. `[📱 밖에서 스마트폰만 들고 있을 때 — 세이씨 초고속 GPU 서버 무료 대여]` (`cloud_rental`):**
  - 안내 문구: *"현재 PC 앞이 아니신가요? 스마트폰 발열과 배터리 소모를 막기 위해 세이씨의 초고속 클라우드 PC(GPU 서버)를 잠시 무료로 빌려드립니다! (무거운 원본 미전송 / 서버 RAM에서 0.1초 연산 후 즉시 자동 소각되므로 안심하셔도 됩니다)"*

### 1.2 스캔 전 `[검진 구역 직접 허용]` 3대 안전 폴더 체크박스 (`trialScanPermissions`)
- 스캔 시작 전 온보딩 모달(`OnboardingModal.tsx`)에서 기본 3대 안전 폴더만 체크된 상태로 유저가 직접 허용하고 시작합니다:
  1. **`☑️ 사진첩 (갤러리)`** — 중복·연사(dHash) 진단 + 최신 동영상 3개 전 구간 해부 + 촬영 서류 8장 스캔
  2. **`☑️ 다운로드 폴더`** — 최근 다운로드된 영수증·바우처·청구서·건강검진 PDF 문서 역추적
  3. **`☑️ 바탕화면 폴더`** — 보험증권·계약서·조립설명서 PDF/DOCX/TXT 역추적 색인

### 1.3 체험판 1분 컷 3대 집중 타겟팅 (`[청소 진단 + 최신 서류 20건 + 최신 동영상 3개 전 구간(Full-Timeline) 완전 해부]`)
일반 사진 수백 장을 스캔하느라 시간을 허비하지 않고, 삼성 기본 갤러리가 절대 따라올 수 없는 **3대 핵심 타겟**만 1분 이내에 정밀 분석합니다:
1. **🧹 [기기 자체 연산] 중복·연사(dHash) 및 흔들림 진단:** 사진첩 전체의 파일명 다른 중복 사본/연사 그룹과 흔들린 사진 개수는 에이전트 자체에서 초고속 산출합니다.
2. **📄 [Gemma 2 정밀 인덱싱 ①] 최신 서류/문서 20건 역추적 (`LOCAL_DOCUMENT_FILES` 12건 + 갤러리 서류 촬영본 8장 = 총 20건):** 오늘 날짜부터 역순으로 허용된 폴더(다운로드/바탕화면/사진첩)를 뒤져 로컬 문서 파일(`PDF, TXT, DOCX` 12건)과 사진첩 속 서류 형태 이미지(영수증, 계약서, 조립 설명서, 여권·신분증 등 8장) **딱 20건**을 찾아내어 텍스트와 의미를 768차원으로 인덱싱합니다.
3. **🎬 [Full-Timeline 완전 해부 ②] 최신 동영상 딱 3개 선정 후 `00:00`부터 끝까지 전 구간 완전 해부 (`VIDEO_SCENE_ITEMS` 3개 영상 · 총 20개 타임라인 구간):**
   - 10개 동영상을 썸네일 1장씩만 수박 겉핥기로 스캔하던 방식을 폐기하고, 최신 동영상 **딱 3개**를 선정해 **영상의 처음(`00:00`)부터 끝까지 1~3초 단위로 촘촘하게 프레임을 쪼개어(총 20개 구간) 영상 안에 스쳐 지나가는 모든 사물·배경·행동을 100% 해부(Full-Timeline Indexing)**했습니다:
     1. **`20240719_105706.mp4` (`00:21`, 7구간 해부):** `00:00`(상공 활공·보트 난간·하얀 물보라) ➔ `00:03`(견인 로프·마누칸섬 능선) ➔ `00:06`(태양 역광 렌즈 플레어) ➔ `00:11`(윈치 로프 감기며 중간 고도 하강) ➔ `00:15`(키나발루산 배경 갑판 근접) ➔ `00:18`(두 다리 뻗으며 보트 갑판 착지 직전 클라이맥스) ➔ `00:20`(굵은 밧줄 매듭 옆 갑판 바닥 안착 완료).
     2. **`20240720_134808.mp4` (`00:19`, 7구간 해부):** `00:00`(야자수 데크 밀짚모자·선글라스·흰 민소매·꽃무늬 반바지 남성 라탄 소파 착석) ➔ `00:02`(핫핑크 래시가드·검은 반바지 여성 걸어가는 뒷모습) ➔ `00:04`(소파에 나란히 앉아 손가락 브이(V) 포즈) ➔ `00:08`("동영상이다!" 말하며 자리에서 일어나 카메라로 다가옴) ➔ `00:10`(왼손 뻗어 카메라 화면 터치) ➔ `00:13`(선글라스·밀짚모자 얼굴 셀카 클로즈업) ➔ `00:17`(목에 걸린 은색 하트 펜던트 목걸이 & 래시가드 지퍼 클로즈업).
     3. **`20240722_052422.mp4` (`00:09`, 6구간 해부):** `00:00`(새벽 비행기 기내 좌석과 창문 밖 구름 위 일출) ➔ `00:02`(창가 아래 들고 있는 스마트폰 홈 화면 앱 아이콘 노출) ➔ `00:04`(구름 바다 운해 위 황금빛 태양 클로즈업) ➔ `00:06`(스마트폰 화면을 카메라 촬영 모드로 전환해 들어 올림) ➔ `00:07`(스마트폰 카메라 뷰파인더로 기내 창문 일출을 담는 클라이맥스) ➔ `00:08`(새벽 여명 수평선 마무리).

## 2. 코어 검색 엔진 아키텍처 (`vite.config.ts` — `runHybridCorpusSearch` & `aiEngine.ts` — `searchVideoSceneItems`) — **[100% 최종 확정]**

### 2.1 검색 파이프라인 구조 (768차원 벡터 엑셀 + 온톨로지/지명 브레이크 하이브리드)
1. **한국어 토크나이저 및 조사/어미 분리 (`stripKoParticle`)**
   - 입력 쿼리에서 문장부호를 제거하고 공백 단위로 분리합니다.
   - `바닷가`, `창가`, `물가`, `휴가`, `아이`, `어린이`, `고양이`, `멍멍이`, `물놀이`, `목걸이`, `귀걸이`, `종로`, `을지로`, `다리`, `나무다리`, `선풍기`, `비행기` 등 끝글자가 조사와 겹치는 명사(`KEEP_NOUNS`)를 보호한 뒤, 한국어 조사를 제거하여 어근 토큰을 추출합니다.
2. **동영상 전 구간 타임라인 엄격 프레임 매칭 (`searchVideoSceneItems` — Strict Filtering & Minimum Score Threshold)**
   - 사용자가 입력한 자유 검색어에서 `클로즈업`, `포즈`, `취하다가`, `다가오는`, `촬영`, `화면` 등 일반 카메라 구도·행동 수식어를 불용어로 걸러내고, 핵심 사물·의상·배경 명사 토큰을 추출합니다.
   - 3개 동영상의 **20개 타임라인 구간(`timelineFrames`)** 각각과 대조하여, **① 실제 타임라인 프레임 적중(`bestFrameScore > 0`)**, **② 필수 핵심 토큰 충족(`matchedTokenCount >= requiredTokenMatches`)**, **③ 1순위 대비 최소 점수 임계치(`totalScore >= topScore * 0.55`)** 3중 브레이크를 통과한 진짜 정답 영상만 단독 노출합니다 (예: `"하트 목걸이 클로즈업"` 검색 시 무관한 새벽 비행기 일출 영상은 원천 차단되고 오직 `20240720_134808.mp4`의 `🎯 00:17 구간 포착` 1건만 단독 노출).
   - **실시간 포착 구간 썸네일 프리뷰 (`#t=matchedSeekSec`):** 특정 타임라인 구간이 포착된 동영상 카드는 정적 첫 프레임(`00:00`) 이미지 대신 `<video src="...#t=17">` 태그로 즉시 해당 초(Sec)의 실제 화면(하트 목걸이 클로즈업 등)을 카드 상단 썸네일로 바로 보여줍니다.
3. **HTTP `206 Partial Content` Byte-Range 동영상 스트리밍 (`vite.config.ts`)**
   - `/__photos/file` 미들웨어에 `Range: bytes=start-end` 헤더 파싱 및 `206 Partial Content`(`Accept-Ranges: bytes`, `Content-Range`) 응답을 구현하여, 브라우저 `<video>` 플레이어가 `currentTime = matchedSeekSec` 명령을 받을 때 지연 없이 즉시 해당 초(Sec) 구간으로 점프 재생합니다.

## 3. [탭 1: 🔍 파워 검색] 미니멀·차분·접이식(Collapsible) & 가로 스와이프(Carousel) UI (`VoiceHeroStage.tsx`, `DesktopDashboard.tsx`, `MobileAppView.tsx`, `PricingModal.tsx`)

### 3.1 5대 UI 다이어트 및 정보 구조(IA) 대개편 (Linear / Perplexity / Toss 스타일)
1. **본 화면 온보딩 장문 박스 완전 퇴출 ➔ 상단 헤더 '신호등 상태 캡슐' 1개로 통합:**
   - 본 화면 상단을 차지하던 초록색 장문 온보딩 박스를 전면 삭제하고, 상단 헤더 로고 옆에 **`[🟢 내 PC 엔진 안전 가동 중 (폰 연결됨)]`** 미니 상태 캡슐 딱 하나만 배치했습니다. 클릭 시에만 보안/검진 폴더/QR 페어링 안내 모달(`OnboardingModal`)이 열립니다.
2. **1층 (최상단 고정 주인공): 통합 검색창 + 3대 카테고리 탭 + 탭 맞춤형 1줄 추천 칩:**
   - 헤더 바로 아래 최상단(1층)에 큼직하고 차분한 통합 검색창과 **`[🖼️ 전체 갤러리 (550)]` `[📁 스마트 서류함 (20)]` `[🎬 동영상 해부 (3개·20구간)]`** 스위칭 탭을 가장 먼저 배치했습니다.
   - 검색창 바로 아래에는 현재 선택된 탭에 맞는 추천 검색어 칩 4~6개만 **가로 스크롤 1줄(`overflow-x-auto no-scrollbar`)**로 깔끔하게 흐르도록 정돈했습니다.
3. **2층 (접고 펴는 스마트 가이드 바 — Collapsible Accordion & Auto-Collapse):**
   - 상세 브리핑 보드는 기본적으로 **1줄 요약 아코디언(접힌 상태)**:
     `[✨ 무료 체험 준비 완료: 서류 20건 · 동영상 3개(20구간) 해부됨 · 중복/연사 174장 진단 완료 — 💡 무료 체험 분석 리포트 & 테스트 가이드 펼쳐보기 ▾]`
     로만 노출되며, 유저가 원할 때만 펼쳐볼 수 있습니다.
   - **검색 시 자동 접힘 (Auto-Collapse):** 검색어를 입력하거나 추천 칩을 클릭해 검색 결과가 나오면, 펼쳐져 있던 브리핑 아코디언이 자동으로 접혀(`setIsBriefingOpen(false)`) 검색 결과 사진·영상이 화면 상단에 즉시 올라옵니다.
4. **컬러 다이어트 (6색 네온사인 ➔ 무채색 다크그레이 베이스 + 단일 민트 포인트):**
   - 모든 카드와 박스의 형광색 테두리(민트/노랑/초록/주황)를 제거하고, 차분한 무채색 다크 슬레이트(`#09090B`, `#18181B`, `bg-zinc-900/70`)와 은은한 회색 실선(`border-white/10`)으로 90% 이상 통일했습니다.
   - 강조색은 현재 선택된 탭과 메인 검색 버튼 딱 1곳에만 시그니처 민트(`bg-primary-container text-zinc-950`)를 사용하고, 특전/요금제는 텍스트 포인트(`text-amber-400`)로만 절제했습니다.
5. **모바일(및 컴팩트 뷰) 가로 스와이프 카드덱 (`Horizontal Snap Carousel`):**
   - 모바일 화면(`MobileAppView.tsx`)과 브리핑 아코디언에서 동영상 3개 카드 및 로컬 PDF 서류 카드를 세로로 쌓지 않고, 좌우로 부드럽게 넘겨보는 **가로 스와이프 슬라이더(`flex overflow-x-auto snap-x snap-mandatory`)**로 구현하여 세로 스크롤 지옥을 완전히 해소했습니다.

### 3.2 🎬 타임라인 점프 재생 모달 (`VideoScenePreviewModal`)
- 검색된 동영상 카드 또는 카드 하단의 타임라인 구간 버튼(`00:00`, `00:03`, `00:06`, `00:11`, `00:15`, `00:18`, `00:20` 등)을 클릭하면 모달이 열리면서 **`videoRef.current.currentTime = matchedSeekSec`**으로 즉시 점프하여 그 순간부터 영상을 재생합니다.
- 모달 하단에는 해당 영상의 전 구간(`00:00 ~ 끝`) 해부 리스트가 인터랙티브 버튼으로 나열되어, 원하는 구간을 클릭할 때마다 즉시 해당 초(Sec)로 이동합니다.

## 4. [탭 2: 🧹 주치의 정리] 연사 클러스터링 정밀화(커플 컷 보존) & 차분한 다크 슬레이트 UI (`SmartTrashView.tsx`, `aiEngine.ts`)

1. **연사 클러스터링 정밀화 (인물 수·구도 일치 원칙 — `aiEngine.ts`):**
   - `dHash` 해밍 거리 임계치(`dist <= 12`, 첫 프레임 대비 `distFromFirst <= 14`)와 인물 피부 면적 차이(`skinDiff <= 5.5%`)를 엄격히 제한하여, **독사진(1인 셀카, 예: `20240719_112207_002.jpg`)과 커플 사진(2인 셀카, 예: `20240719_112207_080.jpg`, `_082.jpg`)이 절대 같은 연사 묶음으로 섞이지 않고 분리**되도록 구현했습니다.
2. **인물/커플 우선 Best 컷 선정 가중치 (`computeBestCutScore`):**
   - 한 묶음 내에서 대표 보존 컷(`bestPhotoId`)을 선정할 때 단순 배경 나뭇잎 선명도(`maxCellLap`)만 보지 않고, **함께 찍힌 인물(얼굴·피부 면적 `skinPct * 1400`) + 피사체 전체 평균 선명도(`meanCellLap * 1.5`)**에 최우선 가중치를 부여하여 두 사람이 함께 온전히 나온 커플/단체 컷이 1순위 Best 보존 컷으로 선택됩니다.
3. **진단 리포트 헤더 & 바둑판 Pick UI 다이어트 (`SmartTrashView.tsx`):**
   - 상단 알록달록한 3대 배지(민트/초록/주황)와 2줄 방패 박스를 제거하고, 우측 `[📁 신분증·조립설명서는 스마트 서류함에 안전 분리됨 →]` 무채색 링크와 차분한 1줄 안심 텍스트(`🛡️ 정리된 파일은 영구 삭제되지 않으며 [30일 대기함] 및 하단 [1초 되돌리기(Undo)]로 언제든 즉시 복구됩니다.`)로 압축했습니다.
   - 하단 3×3 / 4×4 바둑판 비교 섹션에서도 중복 노출되던 초록색 캡슐 배지를 걷어내고 `[⚙️ 내 기기 & 백업]` 탭과 동일한 다크 슬레이트 톤(`bg-[#18181B]`, `border-white/10`)으로 통일했습니다.
