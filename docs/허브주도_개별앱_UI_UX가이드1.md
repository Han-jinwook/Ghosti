# [제 1 부] 허브 전담 AI 통제 구역 (공통 인프라 & 레이아웃)

이 구역의 원칙들은 멀린 패밀리 생태계의 통일성을 위해 **허브 전담 AI가 직접 각 앱의 코드를 수정하여 배포(통제)**합니다. 개별 앱 AI는 이 구조를 임의로 훼손해서는 안 됩니다.

## 1. SSOT (Single Source of Truth) 원칙
- 유저 식별자(UUID)와 계정 정보, 지갑 정보는 오직 **허브 DB(`family_users`)만이 유일한 진실 공급원**입니다.
- 이메일이나 로컬 닉네임 등을 임의의 보조 수단으로 매핑하여 시스템을 우회하거나 어지럽히는 행위는 절대 금지됩니다.

## 2. 반응형 배너 분기 및 고정 위치 원칙 (`HubResponsiveWing`)
패밀리 앱에서 우측에 배치되는 공유 카드 및 파트너 배너 레이아웃은 허브 SDK(`HubResponsiveWing`)에 의해 통제됩니다.
- **[1120px 이상 (PC/태블릿 가로)]**: 우측 빈 공간에 사이드 윙(`aside`) 형태로 고정 배치합니다. 
- **[1120px 미만 (모바일/화면 축소)]**: 우측 윙을 숨기고, 화면 하단 스티키 배너 및 60초 지연 플로팅 버튼(FAB) 기반의 바텀 시트 팝업으로 대체합니다.

## 3. 공통 UI 중앙화 및 사전 승인 원칙 (충돌 방지)
- PWA 앱 설치 팝업, 전역 로그인 모달 등은 개별 앱 내부에 파편화시키지 않고, **오직 허브 SDK(`merlin-hub-sdk`) 내부에 중앙화**하여 패밀리 앱에 동일하게 전파할 의무를 가집니다.
  - **[HubPWAInstallPrompt 통일]**: 모든 PWA 설치 팝업은 허브 SDK의 `HubPWAInstallPrompt`를 사용해야 합니다. 해당 컴포넌트는 UserAgent 변조(네이버 웨일 사이드바 등)에 대비하여 **화면 가로폭이 768px을 초과하는 PC/데스크톱 환경에서는 절대 노출되지 않도록 하는 강력한 차단 로직**을 내장해야 합니다.
- 단, 개별 앱의 고유한 레이아웃이나 기존 기능과 시각적 충돌이 명확히 예상되는 경우, 허브 AI는 코드를 강제 덮어쓰기 전에 **반드시 사장님(멀린)의 사전 승인을 구한 뒤** 안전하게 적용해야 합니다.

## 4. 모바일 반응형(Mobile-First) UI 기초 공사
웹앱(PWA)이 네이티브 앱처럼 동작하도록 다음 뼈대 원칙을 허브 AI가 공통 레이아웃에 주입합니다.
- 하단 스티키 바나 플로팅 버튼(FAB)에 `pb-[env(safe-area-inset-bottom)]` 적용 (기기 하단 간섭 방지).
- 모바일에서 공유 버튼 등 핵심 액션은 1분 지연 노출(Dynamic Nudge)하여 피로도를 낮춤.

## 5. 헤더 패밀리앱 스위처(F) 고정 배치 원칙
- 헤더 메뉴 및 우측 프로필 위젯 배치 시, 패밀리앱을 상징하는 **'F' 마크(`HubAppSwitcher`)는 반드시 프로필 위젯의 우측(우측 최상단 끝)에 고정 배치**합니다.
- 패밀리 생태계 간 일관된 UI 경험을 위해, 어떠한 경우에도 F 마크를 프로필의 좌측이나 다른 영역에 임의로 배치하여 UI 통일성을 해쳐서는 안 됩니다.

## 6. 모바일 다메뉴(4개 이상) 헤더 네비게이션 표준 규격
모바일 화면(360px~430px)에서 메뉴 탭이 4개 이상일 때의 UI/UX 처리 정책입니다.

1. **[제1원칙: 1줄 핏팅 우선 (Fit-to-Width)]**:
   - 우측 `[🥳F]` 캡슐(약 60px)과 좌측 로고를 제외한 가로 여백(약 220~240px)에 **4개 메뉴 탭(2~3글자 컴팩트 라벨 + `px-2.5`)을 1줄에 완벽 핏팅**하여, 스크롤 자체를 발생시키지 않는 것을 최우선으로 합니다.
2. **[제2원칙: 자동 롤링/루프 절대 금지 (Anti-Marquee)]**:
   - 메뉴 탭이 혼자서 상시 움직이거나(전광판 Marquee) 주기적으로 스크롤되는 것은 **유저가 손가락으로 누르는 순간 엉뚱한 탭이 클릭되는 '치명적 오터치(Mis-tap)'와 심각한 시각 피로도를 유발하므로 절대 금지**합니다.
3. **[제3원칙: 5개 이상 스크롤 발생 시 표준 처리 (Fade Mask & One-time Peek)]**:
   - **우측 페이드 마스크 (`mask-image`)**: 스크롤바는 숨기되, 우측 끝 메뉴가 반쯤 잘려 보이게 은은한 페이드 그라데이션을 주어 "옆에 메뉴가 더 있다"는 것을 본능적으로 인지시킵니다.
   - **최초 진입 1회성 피크 넛지 (One-time Peek Bounce)**: 첫 진입 0.8초 후 우측으로 살짝 30px 슥 움직였다가 제자리로 돌아오는 1회성 가이드 애니메이션을 제공합니다.
   - **선택 탭 자동 중앙 정렬 (`scrollIntoView({ inline: 'center' })`)**: 유저가 탭을 선택하면 해당 탭이 화면 중앙으로 스무스하게 정렬됩니다.
