## 🛡️ 2. P2P 연결 · 백업 · 보안 5대 운영 철칙

1. **고정 도메인 터널(`Named Tunnel`) 기본값 및 iOS 백그라운드 정책 정직 표기**:
   - 외부 네트워크(LTE/5G Symmetric NAT) 폴백 시 임시 `trycloudflare` 주소가 아닌 고정 도메인 터널(`*.tunnel.ghosti.sundreamer.app`)을 기본값으로 사용합니다.
   - 모바일 클립보드·여권 동기화 안내 시 **"안드로이드·PC는 백그라운드 즉시 동기화되며, iOS(아이폰)는 Apple OS 정책상 앱 진입(포그라운드 전환) 시 0.1초 만에 즉시 동기화됩니다"**라고 정직하게 병기합니다.
2. **얼굴 여권(`ghost_passports`) 기본 로컬 전용(`OFF`) + 명시적 동의(`Opt-in`) 암호화 보관**:
   - `🪪 귀신계 여권`은 기본적으로 100% 내 기기 로컬 DB에만 저장(`isCloudSyncEnabled = false` 기본값)됩니다.
   - 고객이 직접 **`[📱 내 폰·다른 PC와 여권 동기화 켜기 (암호화 보관)]`** 스위치를 켰을 때만 사용자 키로 암호화 래핑된 벡터·도장 썸네일이 동기화됩니다.
3. **`G:` / `S:` 드라이브 및 계정관리 시트 비밀번호 기본 마스킹(`••••••••`)**:
   - 계정·비밀번호 행 조회 시 어깨너머 노출(Shoulder Surfing)을 막기 위해 화면에는 기본 마스킹(`••••••••`)으로 표시하며, 사용자가 **`[👁️ 보기]`**를 클릭했을 때만 원문이 노출됩니다 (`[📋 복사]`는 마스킹 상태에서도 즉시 작동).
4. **OS 기본 `[휴지통]` 일원화 & 랜섬웨어 서킷 브레이커**:
   - 파일 정리·삭제 시 별도 격리 폴더 없이 **OS 기본 `[휴지통]`(`Win32 FOF_ALLOWUNDO`)으로 직행**하며 하단 **`[↩️ 1초 실행 취소(Undo)]`**를 지원합니다.
   - 1분 내 30개 이상 대량 삭제·변조 또는 미끼 파일(`_000_ghosti_guard.docx`) 훼손 감지 시 백업 PC 1·2호 미러링을 0.01초 만에 즉시 동결합니다.
5. **표준 로컬 데이터 경로(`%LOCALAPPDATA%\Ghosti\data`) 단일화**:
   - 클립보드 큐(`clipboard_queue.json`), 상용구(`fixed_snippets.json`), 절전 스냅샷(`security_sleep_snapshot.json`), 수호 히스토리(`defender_guardian_history.db`) 등 모든 사용자 로컬 런타임 데이터는 `%LOCALAPPDATA%\Ghosti\data` 하위로 100% 격리 저장합니다.
