## 1. 3대 핵심 메뉴 및 노션 스타일 UI/UX 아키텍처

### 1.1 3대 핵심 메뉴 체계 (`DesktopDashboard.tsx`, `MobileAppView.tsx`, `LoungeView.tsx`)
1. **`🎯 찾기` (*"제목 몰라도 귀신같이 찾고"* / 개인 기본 0원)**: 사진·동영상·문서·`G:` 드라이브 1초 AI 내용 검색 (화면 내 불필요한 '무료체험' 배지 배제).

3. **`⚙️ 고치기` (*"먹통 설정 귀신같이 고치고"* / 개인 기본 0원)**: 먹통 프린터·네트워크 원클릭 복구, `[복원 기록]` 1초 원상복구.
4. **`📸 사진 공유` / `💼 업무 공유` (라운지 공유방)**: 방장 1인 결제 시 멤버 전원 무료 (가족·동호회·동창회 및 가상 `S:` 드라이브 업무 공유).

### 1.2 노션 스타일 좌측 접이식 사이드바 & 백지 도화지(Zen Canvas)
1. **좌측 사이드바 (`lg+` 244px 고정·접기 지원 + 모바일 `☰` 드로어):** 3대 핵심 메뉴 트리(`🎯 찾기`·`🧹 치우기`·`⚙️ 고치기`), 패밀리 방 목록(`우리집/본가/처가`), 서브메뉴, 하단 `[F 멀린 패밀리 앱]` 런처 통합.

## 2. 코어 검색 엔진 및 미디어 파이프라인

### 2.1 검색 탭 UX 규칙 (`useGhostiStore.ts`)
1. **첫 검색 시 '🎬 동영상' 기본 오픈:** 시각적 임팩트가 가장 큰 동영상 탭을 기본으로 열어 타임라인 구간 점프 재생 기술력을 즉시 체감하게 함.
2. **재검색 시 마지막 선택 탭 유지:** 유저가 수동으로 사진이나 문서 탭을 선택한 뒤 검색어를 변경하면 해당 탭 상태를 그대로 유지.

### 2.2 검색 파이프라인 구조
1. **한국어 토크나이저:** 불규칙 조사 제거 및 명사 보호 사전을 통한 어근 토큰 추출.
2. **동영상 전 구간 타임라인 매칭:** 동영상 전 구간 키프레임을 768차원 벡터로 인덱싱하여 `<video src="...#t=sec">`를 통해 0.1초 만에 타임스탬프 구간 점프 재생.
3. **탐색기 장착 `G:` 드라이브(구글 드라이브) 무설정 스마트 모드 (`Zero-Config`):**
   - 윈도우 탐색기에 마운트된 `G:\내 드라이브`를 자동 감지하여 팝업 없이 로컬 구글 세션을 활용해 모든 `.gsheet`(표 셀)와 `.gdoc`(본문)을 자동 색인.
   - 계정/비밀번호 화면 표시 시 로컬 기기이므로 마스킹(`••••`) 없이 원문 표시 + 아이디/비밀번호 텍스트 바로 옆에 각각 인라인 복사 이모지(`📋`) 제공.
   - 비밀번호는 프라이버시 보호를 위해 음성(TTS)으로 낭독하지 않으며 외부 AI 바톤터치 대상에서 제외.

## 3. 만국공통 '귀신같이 여권(Face Passport)' 및 인물 바구니

1. **다년도·다각도 5대 스타일 슬롯:** `정면·선명`, `측면·미소`, `야외·노을`, `선글라스·역광`, `야간·실내` 베스트 컷을 하나의 멀티 시드 패키지로 자동 결합.
2. **인물별 고유 타임라인 바구니:** 방이 아닌 각 인물의 최초 생성 연도에 귀속되는 10년/5년 단위 바구니(`2026~2017` 등)를 통해 세월의 변화를 추적하며 미래 바구니 자동 확장.
3. **무질문 0.1초 자동 연동 & 방별 별명(Persona) 독립 매핑:** 이메일 계정에 귀속되어 새 방 입장 시 0.1초 만에 자동 장착되며, 동일 시드로 `우리집: [👑 멀린]` ↔ `처가: [👑 둘째사위]` ↔ `동창회: [지우짱]` 등 방별 호칭으로 독립 매핑되어 검색 지원.
4. **화면 정화 (UI Diet):** `내 기기`에서는 여권 UI 완전 비노출. 공유방에서는 가로 아바타 나열 박스를 철거하고 확인이 필요한 항목만 큼직한 사각형 카드로 1장씩 보여준 뒤 등록 완료 시 화면에서 완전 소멸(`Auto-Hide`).

## 4. 공유방 6단계 일방통행 프로세스 및 권한/탈퇴 정책

기존의 `OS 기본 [휴지통]`, `방장 사전 수동 검수`, `썸네일 클릭 시 원본 소환`은 전면 폐기되었습니다.

1. **Step 1. 입구 컷 (AI 자율 선별 + 진짜 원본 자동 교체):**
   - 영수증·스크린샷 제외 및 흔들린 연사 필터링.
   - `64-bit dHash` 중복 감지 시 단순 용량 비교가 아닌 **`EXIF 촬영 메타데이터`가 살아있고 `실제 픽셀 해상도`가 더 큰 진짜 원본일 때만 자동 교체(기존 댓글·좋아요 보존)**.
2. **Step 2. 사전 검수 0% + `[⏳ AI 인덱싱 대기실]`:** 방장 수동 검열 없이 즉시 피드에 합류하며, 마스터 PC에서 썸네일과 태그를 생성하는 1~2분 동안만 꽃단장 버퍼 상태 배지 표시.
3. **Step 3. 13KB 숨김 썸네일 DB + `[🔄 원본 동기화]` 자체 해결:** 평소 멤버 기기에는 시스템 숨김 영역(`%LOCALAPPDATA%\Merlin\thumb_db`)에 13KB 썸네일만 두어 용량을 절약하고, 원본 동기화 시 지정 폴더로 복제하여 각자 로컬에서 100% 자체 해결.
4. **Step 4. 업로드 후 24시간 내 본인 삭제 + 방 개설 옵션:** 업로드 후 24시간 내에는 올린 본인이 직접 삭제 가능하며, 방 개설 시 **`방장 상시 숨기기 권한`** 옵션을 선택할 수 있음.
5. **Step 5. OS 기본 [휴지통] 직행 + 랜섬웨어 서킷 브레이커:** 1분 30개 대량 삭제 감지 시 자동 중단 및 미끼 파일(`_000_ghosti_guard.docx`) 감시.
6. **Step 6. 탈퇴 시 데이터 처리 기준:** 탈퇴/강퇴 즉시 해당 공유방의 썸네일 DB와 검색 인덱스는 자동 삭제되며, 유저 본인의 개인 여권 시드 및 로컬 동기화 원본은 100% 보존.

## 10. [내부 도구] 노션 무인 QA 자동화 및 완료 컬럼 최신 7건 유지 파이프라인

1. **완료 컬럼 최신 7건 상시 유지 & 초과분 안전 보관 (`archived: true`):**
   - 칸반 보드 `[완료]` 컬럼에 카드가 무제한 쌓여 화면이 아래로 길어지는 현상을 방지하기 위해, `notion_qa.py fetch` 시 최신 7건만 남기고 8번째 이후의 이전 카드는 자동으로 `archived: true`로 이동.
   - 영구 삭제가 아니므로 데이터베이스에서 안전하게 숨김 보관되며, 로컬 백업 원장(`poc/results/archived_done_cards_backup.json`)에 메타데이터 자동 누적.
2. **원클릭 복원 도구 (`restore_archived_done_cards.py`):**
   - 필요 시 스크립트 실행으로 숨겨진 이전 완료 카드를 1초 만에 화면으로 100% 원상복구 지원.
3. **CLI 명령어:**
   - `python notion_qa.py fetch`: 버그 목록 조회 + 완료 컬럼 최신 7건 자동 유지 동시 수행.
   - `python notion_qa.py trim-done [keep_count]`: 수동 트리밍 (기본 7건).
   - `python notion_qa.py complete <page_id> "<guide>"`: 버그 조치 후 알바생에게 재테스트 지시.
   - `python notion_qa.py mission "<title>" "<steps>"`: 테스트 미션 카드 출제.

## 11. [QA 운영 표준] 다중 디바이스 교차 검증 & 협력 확산 3단계 순서도 및 6대 섹터 격파 로드맵

1. **다중 디바이스 & 협력 확산 3단계 순서도:**
   - **1단계 [사무실 다중 PC 교차 검증 (알바생 단독)]**: 알바생 1인이지만 사무실 내 준비된 여러 컴퓨터 자리를 옮겨가며 해상도/배율, OS 환경, C:/D:/S: 로컬 경로 차이에 따른 UI/UX 깨짐 및 Z-코어 연동 오류를 1차 전수 점검.
   - **2단계 [사내 2인 이상 협력 연동 검증 (멀린님 부부 협력)]**: 패밀리 라운지 초대·수합, 업무 공유 라운지 동시 수정 방지 잠금(Lock/Unlock), 실시간 동기화를 멀린님 및 사모님(와이프)과 협력 검증.
   - **3단계 [가정·지인 외부 실사용 환경 확산 검증 (멀린님 사전 상의 절대 의무)]**: 외부 네트워크 및 실제 가족/지인 데이터 환경으로 확산 검증. **알바생 개인에게 집/지인 테스트를 직접 지시·전가하는 것을 엄격히 금지**하며, 반드시 멀린님과 사전 상의하여 지정된 절차와 그룹으로만 추진.
2. **6대 섹터 순차 완전 격파 원칙 (1번부터 순서대로 서브메뉴 한 개씩):**
   - `[0단계]` 공통 기반 (반응형 레이아웃, 라이트/다크 모드 글자 명도 통일, 알약 토글 버튼 표준화)
   - `[1단계]` 🧹 내 기기 - 치우기 (사진·쓰레기 정리, 연사·중복 묶음 Pick, 휴지통 이동 & 1초 복원)
   - `[2단계]` ⚙️ 내 기기 - 고치기 (Z-코어 3초 포렌식, 5대 은닉 금고, 오피스 증발 복구)
   - `[3단계]` 🎯 내 기기 - 찾기 (Z-Eye 투시검색, AI 시각 검색, 도화지 Zero-State 접기/펼치기)
   - `[4단계]` 📸 패밀리 - 사진 공유 (양가 분리 라운지, 얼굴 여권, 카톡 초대 & 3초 수합, 옛날 사진 스틱)
   - `[5단계]` 💼 업무 - 업무 공유 (권한별 라운지, 문서·도면 검색, 협업 잠금 Lock 동시성)
