## 🛠️ 2. 제트아이 5대 핵심 무기 라인업 (`Z몬스터` & Zero-Cloud 코어)

1. **`👁️ Z-Eye 투시검색` (`1초 투시검색`):**
   - 온디바이스 **`EmbeddingGemma 2`** 768차원 멀티모달(텍스트·비전·오디오) 벡터 엔진 + 한국어 시각 온톨로지 + `64-bit dHash` 픽셀 뼈대 결합.
   - 동영상 1초 핵심 구간 점프, 로컬 오피스 문서 및 탐색기 장착 **`G:` 드라이브(구글 드라이브 `.gsheet`/`.gdoc`)** 로컬 구글 세션 무설정 1초 색인·검색.
   - 첫 검색 시 임팩트가 큰 **`🎬 동영상`** 탭 기본 오픈, 재검색 시 유저가 마지막으로 선택한 탭 유지.
2. **`🩺 Z-Eye 클린몬스터` (`클린몬스터`):**
   - PC·폰 속 중복 파일, 연사 사진, 유령 프로세스, 용량 도둑을 1초 만에 투시 검진.
   - 앱 임의 삭제 0% 원칙: 유저가 직접 확인 후 정리 시 별도 보관함 없이 **OS 기본 `[휴지통]`(`Win32 FOF_ALLOWUNDO`)으로 직행**하며 하단 **`[↩️ 1초 실행 취소(Undo)]`** 즉시 복원 지원.
3. **`🛠️ 설정몬스터` (`설정몬스터`):**
   - 복잡한 PC·폰 설정 수리, 끊어진 `S:` 드라이브 재연결, 오피스 증발 파일 **3초 결정론적 포렌식 진단(5대 은닉 금고 + 윈도우 `$Recycle.Bin` `$I` 바이너리 해독 + 블랙박스 1초 소명)**.
   - 변경 0.01초 전 **`[복원 기록]`(`restore_points.json`)** 자동 생성 및 3단계 무결성 사전 검진(`🟢 100% 완벽 복원` / `🟡 부분 복원` / `🔴 복원 불가`) 후 1초 원상복구.
4. **`🛂 Z-Eye 여권` (`Face Passport`):**
   - 이메일 계정에 귀속된 다년도·다각도(`정면·측면·야외·선글라스·야간` 5대 슬롯) 안면 시드 및 인물별 고유 타임라인 바구니(성인 10년 / 미성년 5년 + 미래 바구니 자동 확장).
   - `[사진 공유]` 방 입장 시 질문 팝업 없이 0.1초 자동 장착되며, 방마다 부르는 호칭만 독립 매핑.
5. **`🏛️ 멀린 Z 코어` (`Merlin_Z_Core` — 단일 포트 `127.0.0.1:5199`):**
   - 16개 패밀리 앱이 공유하는 단 하나의 로컬 엔진(`D:\Z-Eye\universal_z_core\`).
   - MS 코드 서명(`Merlin_Z_Core_Setup.exe`) 단일 설치파일 내부에 **`plugin_zeye_os`**, **`plugin_senstalk`**, **`plugin_aggrofilter`** 3대 소프트웨어 플러그인이 기본 내장되어 포트 충돌 없이 `127.0.0.1:5199`에서 동시 비동기 작동.

## 🎙️ 3. 전 영역 무료 무제한 TTS (`현수 & 선희` 투톱) & 단골 AI 라이브 바톤터치

1. **성우진 100% 무료 무제한 일원화 (유료 외부 성우 API 영구 폐기):**
   - 제트아이 전 영역(`투시검색` · `클린몬스터` · `설정몬스터`)은 일일 횟수 제한 없이 평생 0원인 MS 신경망 성우 **`현수(ko-KR-HyunsuNeural)` & `선희(ko-KR-SunHiNeural)` 투톱**으로 작동합니다.
2. **음성 검색 결과 무토큰(`Zero-LLM`) 브리핑 & 카톡 실채팅방 장전:**
   - 음성으로 검색하면 화면과 동시에 성우가 결과를 즉시 읽어주며, `"요약해 줘"` 발화 시 LLM 토큰 소모 없이 문서 첫 문단 핵심 3문장 또는 키워드 포함 문장만 0.01초 만에 추출해 낭독합니다 (고지문: *"💡 AI 요약이 아닌 문서 내 검색어 포함 문장입니다"*).
   - `"이쁜이한테 카톡 보내줘"` 발화 시 카카오톡 실제 `'이쁜이'` 채팅방을 찾아 입력창에 파일/요약을 장전하고 유저가 최종 `[전송]`만 누르게 합니다.
3. **3초 무응답 시 단골 AI(`제미나이` 기본값) 라이브 음성 바톤터치:**
   - 외부 지식 질문이나 3초 무응답 시 로컬 브라우저 히스토리를 스캔해 유저가 최근 사용한 AI(`ChatGPT` / `Gemini` / `Claude` / `Perplexity`)를 자동 감지하여 라이브 음성 모드로 연결하며, **사용 기록이 `0건`일 때는 무조건 `제미나이(Google Gemini Live)`를 기본값으로 열어줍니다.**
