## 1. 프로젝트 개요 (Executive Summary)

- **제품명:** 귀신같이 (Ghosti)
- **포지셔닝:** 서버 클라우드 의존 없이, 말 한마디로 내 폰과 PC의 사진·영상·문서를 1초 만에 찾아내는 **'초고속 로컬 AI 스나이퍼'** 유틸리티.
- **핵심 가치:**
  1. **100% 프라이버시 (Zero-Cloud):** 내 사생활 사진과 기밀 서류를 외부 빅테크 서버로 올리지 않음.
  2. **서버 인프라 비용 0원:** 기기 내부 NPU/GPU 및 로컬 브릿지를 통한 무한 마진 구조.
  3. **압도적인 검색 속도:** 768차원 로컬 벡터 코사인 연산으로 0.1초 이내 타겟 색출.

## 2. 3대 핵심 메뉴 및 2층 네비게이션 아키텍처

귀신같이는 사용자의 이용 목적에 맞추어 **3대 대분류 메뉴**로 완벽히 일원화하여 작동합니다.

### 2.1 `[💻 내 기기]` (개인 기본 — 언제나 0원)
- **대상:** 1인 개인 기기 (스마트폰 1대 + 주력 PC 1대 + 노트북 1대).
- **특징:** 로그인 즉시 `🎯 찾기`(1초 내용검색), `🧹 치우기`(귀신같이 청소), `⚙️ 고치기`(귀신같이 수리)를 기간 제한 없이 상시 무료로 무제한 사용. 화면 내 불필요한 '무료체험' 배지를 배제하여 품격 있는 정식 유틸리티 경험 제공.

### 2.2 `[📸 사진 공유]` (가족 · 동호회 · 동창회)
- **대상:** 가족 앨범, 초·중·고 동창회, 산악회, 골프 동호회 등 사진/동영상 공유 모임.
- **특징:**
  - 오직 사진·동영상(`JPG, PNG, HEIC, MP4, GIF`)만 공유 허용 (업무 문서 차단).
  - **`🛂 귀신같이 인물 여권` 발동:** 우리집에서는 '큰아들', 처가방에서는 '둘째사위'로 자동 호칭 변환.
  - **13KB 숨김 썸네일 DB + `[🔄 원본 동기화]`:** 멤버 기기에는 13KB 썸네일만 두어 용량을 아끼고, 원본 동기화 시 각자 지정 폴더로 복제하여 자체 해결.
  - **요금제:** 방장 1인만 결제하면 초대된 가족/회원 전원 무료 (동호회·동창회는 인원 무제한 월 4,900원).

### 2.3 `[💼 업무 공유]` (1인 멀티PC / SOHO / 소기업 / 중소기업 `S:` 드라이브)
- **대상:** 1인 사업자 다중 PC, 세무·법무 사무소, 건설 현장, 스타트업 업무 팀.
- **특징:**
  - 윈도우 탐색기 가상 드라이브(`S:`) 마운트 및 30KB 오프라인 고속 프리뷰.
  - 동시 편집 충돌 방지 `[🔒 편집 중 (이름)]` File Lock 안내.
  - 업무 문서·도면·현장 영수증 검색 특화 (업무 프라이버시 보호를 위해 인물 여권은 미발동).
  - 메인 PC 1대 + 백업 PC 1·2호 미러링 및 `🌙 야간·퇴근 초절전 모드` 지원.

## 3. 독점 고유명사 및 3대 핵심 기능 체계

기존의 흔한 보통명사를 폐기하고, 사용자의 귀에 착 감기는 `~고` 3단 연결 리듬("찾고, 치우고, 고치고")과 완결형 버튼 체계를 확립합니다.

1. **`🎯 찾기` (서브 캡션: *"제목 몰라도 귀신같이 찾고"* / 1초 내용 검색):**
   - 사진·영상 프레임·문서 본문 속 텍스트와 의미를 1초 만에 찾아내는 초고속 AI 검색 엔진.
   - 탐색기 마운트 `G:` 드라이브 내 모든 구글독스(`.gdoc`)·구글시트(`.gsheet`) 무설정 스마트 색인 지원.
2. **`🧹 치우기` (서브 캡션: *"중복 사진 귀신같이 치우고"* / 귀신같이 청소):**
   - 기기 내 중복 사진(`64-bit dHash`), 오촬영/흔들린 사진(Laplacian 블러 실측), 바탕화면 쓰레기 파일을 시각적으로 대조·정리하는 디지털 검진 센터.
   - 모든 정리는 윈도우 휴지통으로 안전 이동되며, 최근 1달 `[복원 기록]` 3단계 사전 검진(`🟢 100% 복원 가능` / `🟡 부분 복원 가능` / `🔴 복원 불가`)을 통해 1초 만에 원상복구.
3. **`⚙️ 고치기` (서브 캡션: *"먹통 설정 귀신같이 고치고"* / 귀신같이 수리):**
   - 윈도우 및 스마트폰의 복잡한 시스템 설정, 프린터 스풀러 오류, 네트워크 충돌을 대화형 음성으로 진단하고 화면 위에 손가락(`👆`) 오버레이로 동행 안내하는 전문 해결사.

## 4. 탐색기 장착 `G:` 드라이브 무설정 스마트 모드 (Zero-Config)

1. **도입 배경:**
   - 유저들이 계정 정보(ID/PW), 거래처 정산표, 원고 등을 로컬 파일뿐 아니라 구글시트(`.gsheet`)와 구글독스(`.gdoc`)에 분산 보관하지만, 기존 로컬 파서는 이를 읽지 못함.
2. **무설정 스마트 연동:**
   - 번거로운 OAuth 승인 팝업 없이 탐색기에 마운트된 `G:\` 드라이브를 자동 감지하여 백그라운드 색인.
3. **계정/비밀번호 화면 노출 규칙:**
   - 본인 기기에서 직접 조회하는 것이므로 불필요한 마스킹(`••••`) 없이 원문 표시.
   - 아이디와 비밀번호 텍스트 바로 옆에 각각 인라인 복사 이모지(`📋`)를 부착해 원클릭 복사 제공.
4. **프라이버시 안전핀:**
   - 비밀번호는 옆 사람에게 들리지 않도록 음성(TTS)으로 낭독하지 않으며, 외부 AI 바톤터치 대상에서 원천 배제.

## 5. 전사 공통 UI/UX 표준 규격

### 5.1 모바일 메뉴 탭 1줄 핏팅 원칙
- 360px~430px 모바일 화면에서 메뉴 탭이 4개 이상일 때 자동 전광판 롤링(Marquee)을 절대 금지하며, 컴팩트 라벨을 통해 1줄에 완벽 핏팅(`Fit-to-Width`)합니다. 5개 이상 스크롤 발생 시 우측 페이드 마스크(`mask-image`)를 적용합니다.

### 5.2 검색창 Zero-Clutter 및 최근 검색어 드롭다운
- 검색창 하단의 불필요한 보조 안내문을 배제하고, 입력창 내부의 인라인 삭제(`✕`) 버튼으로 해결합니다.
- 포커스 시 로컬 누적된 최근 검색어 드롭다운이 플로팅되며 원터치 재검색을 지원합니다.

### 5.3 더미 샘플 데이터 온보딩
- 데이터가 없는 초기 빈 화면(Blank Slate) 노출을 방지하기 위해 등록 전 샘플 데이터를 노출하며, 유저가 실제 데이터를 1건이라도 등록하는 즉시 샘플 데이터를 완전히 수거합니다.
