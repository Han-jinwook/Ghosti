## 🧭 3대 핵심 메뉴 체계 (SSOT v3.0)

1. **`💻 [내 기기]` (혼자 쓸 땐 언제나 100% 무료 — 0원):**
   - 이메일 로그인 즉시 **`클린몬스터` 진단 및 `1초 투시검색`** 실행 (기간·횟수 제한 없는 상시 무료 제공).
   - 내 폰·PC 사진, 동영상 1초 핵심 구간, 오피스 문서 및 탐색기 장착 **`G:` 드라이브(`.gsheet`/`.gdoc`)** 무설정 1초 투시검색.
   - 5대 오피스 은닉 금고 + 윈도우 휴지통(`$Recycle.Bin` `$I` 바이너리 헤더) 3초 포렌식 및 **`[복원 기록]`(`restore_points.json`)** 1초 원상복구.
2. **`📸 [사진 공유]` (패밀리 / 동호회 · 동창회 — 방장 1인 결제, 초대 멤버 전원 무료):**
   - **패밀리 공유 (`우리집` / `양가 3방 분리`)** 및 **동호회 · 동창회 (`모임명 문패` / `학교·학년·반 문패`)** 단일화.
   - 만국공통 **`🛂 Z-Eye 여권`** 자동 연동 & 방별 호칭 자동 번역, `64-bit dHash` + EXIF 해상도 검증 진짜 원본 자동 교체, **`[🔄 원본 동기화]`** 내 기기 자체 해결.
3. **`💼 [업무 공유]` (1인 멀티PC / SOHO / 소기업 / 중소기업 `S:` 드라이브):**
   - 공용 업무 PC 1대(**`S:` 드라이브 직결**) + **백업 PC 1·2호 실시간 미러링** + **`[🌙 야간·퇴근 초절전 모드]`**(월 전기료 약 1,800원) + **`File Lock`** 동시 편집 읽기모드 안내.
