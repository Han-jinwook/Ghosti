## 1. 4대 시크릿 라운지 2층 네비게이션 아키텍처 & 상단 헤더 (`DesktopDashboard.tsx`, `MobileAppView.tsx`, `LoungeView.tsx`)

### 1.1 상단 헤더 구조 및 불필요 요소 정화
- **좌측 브랜드 & 슬로건:** `세이씨 (SaySee)` 로고 아래에 *"나·가족·모임·친구의 사진과 영상을 말 한마디로 0.04초 만에 찾는 프라이빗 AI 라운지"* 슬로건을 배치하고, 그 옆에 은은하게 반짝이는 초록색 상태 캡슐 **`[🟢 엔진 가동중]`**을 배치했습니다.
- **우측 상단 영역 비움:** 기존의 `'무료체험중'`, `'4대 라운지 요금표'`, `'요금제 안내'`, `'모바일 뷰'` 버튼을 모두 제거하여, 향후 **프로필 · 멀린 코인 · 알림**이 들어갈 깔끔한 우상단 공간을 확보했습니다.

### 1.2 1층 메인 탭 (4대 라운지) & 2층 맞춤형 서브메뉴 (정식 구독 시 1번 탭 Auto-Hide)
`[🟢 엔진 가동중]` 우측으로 충분한 여백을 두고 4대 라운지 메인 메뉴가 배치되며, 선택한 라운지에 따라 2층 서브메뉴 4개가 동적으로 전환됩니다 (`activePricingPlan !== 'free_trial'` 정식 구독 활성화 시 1번 `[✨ 무료체험]` 탭은 자동으로 숨김 처리):

## 2. 코어 검색 엔진 & 검색 탭 UX 규칙 (`vite.config.ts`, `aiEngine.ts`, `useSaySeeStore.ts`, `VoiceHeroStage.tsx`)

### 2.1 첫 검색 시 '🎬 동영상' 기본 노출 & 재검색 시 '마지막 선택 탭 유지' (`useSaySeeStore.ts`)
1. **첫 검색 시 임팩트 중심 자동 포커스 (`!hasExecutedUserSearch && !hasUserSelectedSearchTab`):**
   - 사용자가 처음 검색어를 입력하면 3개 탭에 각각의 검색 결과 숫자를 배지로 동시에 표시하되(`🎬 동영상 (2)` · `🖼️ 사진 (7)` · `📁 문서 (1)`), 가장 시각적 임팩트가 큰 **`🎬 동영상` 탭을 기본(Default)으로 오픈**하여 타임라인 구간 점프 재생의 기술력을 즉시 체감하게 합니다.
2. **탭 수동 선택 후 재검색 시 마지막 탭 유지 (`hasUserSelectedSearchTab === true`):**
   - 사용자가 특정 탭(예: `🖼️ 사진` 또는 `📁 문서`)을 클릭해 열람하다가 새로운 검색어로 다시 검색하면, 각 탭의 결과 건수 배지는 실시간으로 업데이트하되 **사용자가 마지막으로 선택했던 탭이 그대로 열린 상태로 유지**됩니다.

### 2.2 검색 파이프라인 구조 (768차원 벡터 엑셀 + 온톨로지/지명 브레이크 하이브리드)
1. **한국어 토크나이저 및 조사/어미 분리 (`stripKoParticle`):**
   - `바닷가`, `창가`, `물가`, `휴가`, `아이`, `어린이`, `고양이`, `멍멍이`, `물놀이`, `목걸이`, `귀걸이`, `종로`, `을지로`, `다리`, `나무다리`, `선풍기`, `비행기` 등 끝글자가 조사와 겹치는 명사(`KEEP_NOUNS`)를 보호한 뒤 한국어 조사를 제거하여 어근 토큰을 추출합니다.
2. **동영상 전 구간 타임라인 엄격 프레임 매칭 (`searchVideoSceneItems`):**
   - 최신 동영상 3개(`20240719_105706.mp4`, `20240720_134808.mp4`, `20240722_052422.mp4`)의 **전 구간(`00:00`~끝, 총 20개 타임라인 프레임)**과 대조하여, ① 실제 타임라인 프레임 적중, ② 필수 핵심 토큰 충족, ③ 1순위 대비 최소 점수 임계치(`totalScore >= topScore * 0.55`) 3중 브레이크를 통과한 정답 영상만 노출합니다.
   - 포착된 카드는 `<video src="...#t=matchedSeekSec">` 프리뷰와 HTTP `206 Partial Content` Byte-Range 스트리밍을 통해 클릭 즉시 해당 초(Sec)부터 재생됩니다.

## 3. 만국공통 '세이씨 여권(SaySee Face Passport)' & 인물별 고유 타임라인 바구니 & 화면 정화(UI Diet) (`poc/build_face_clusters_index.mjs`, `useSaySeeStore.ts`, `FaceMemberRegistryModal.tsx`, `LoungeView.tsx`)

### 3.1 다년도·다각도(정면·측면·야외·선글라스·야간) 5대 스타일 슬롯 자동 선별 알고리즘
- 동일 인물의 대표 시드를 추출할 때 매년 천편일률적인 정면 컷만 뽑지 않고, 연도를 분산함과 동시에 촬영 조건과 각도가 최대한 다른 **5대 스타일 슬롯(`정면·선명`, `측면·미소`, `야외·노을`, `선글라스·역광`, `야간·실내`)** 베스트 컷을 내부에서 하나의 **‘멀티-조건 시드 패키지’**로 자동 결합합니다.

### 3.2 인물별 고유 타임라인 바구니 (Person-Bound Timeline Bucket) & 미래 바구니 자동 확장
1. **방(Room)이 아닌 '각 인물(Person ID)의 최초 생성 연도'에 귀속:**
   - 성인(10년 주기) / 미성년자(5년 주기) 바구니의 기준 연도는 각 인물의 시드가 최초 생성된 연도에 고정됩니다.
   - 한 라운지 안에 **2026년에 최초 세팅된 기존 가족(`2026~2017` 바구니)**과 **2029년에 새로 합류한 처가 식구(`2029~2020` 바구니)**가 함께 있더라도, 검색 및 역스캔 시 각 인물은 본인의 고유 연도 바구니를 독립적으로 유지합니다.
2. **미래 바구니(Forward Bucket) 자동 생성:**
   - 시간이 흘러 2027년 이후의 신작 사진이 들어오면 기존 `2026~2017` 바구니를 밀어내지 않고, 그 위에 **`2027~2036`(성인 10년) 또는 `2027~2031`(아동 5년) 미래 바구니**를 자동으로 신설하여 세월의 기록을 보존합니다.

### 3.3 무질문 0.1초 자동 장착 & 방별 별명(Room Persona) 독립 매핑 (`getActivePersonaForCluster`)
1. **"시드를 가져올까요?" 질문 팝업 제로 — 이메일 여권 자동 연동:**
   - 새 라운지(처가방, 본가방, 클럽방, 스쿨방 등)를 개설하거나 입장할 때 번거로운 확인 창 없이 이메일 계정(`passportEmail`)에 귀속된 세이씨 여권 시드가 0.1초 만에 자동 장착됩니다 (`[🛂 세이씨 여권 자동 연동됨]`).
2. **시드는 100% 공유하되 방마다 부르는 호칭(Persona)만 독립 작동:**
   - 방 개설자(`face_member_5`)는 **`우리집: [👑 멀린]` ↔ `처가(친정): [👑 둘째사위]` ↔ `본가(친가): [👑 큰아들(진욱)]` ↔ `클럽방: [👑 멀린프로]`**로, 자녀(`face_member_4`)는 **`우리집: [지우]` ↔ `처가방: [외손녀(지우)]` ↔ `스쿨방: [지우짱]`**으로 방의 성격에 맞게 별명이 자동 전환되며, 어떤 방에서든 해당 방의 별명으로 검색하면 동일한 768차원 여권 시드로 0.04초 만에 매칭됩니다.
3. **크로스-라운지 자율 진화 (`evolvePassportAcrossLounges`):**
   - 타 라운지(예: `🎒 스쿨 라운지`)에서 친구들이 올린 사진으로 진화한 시드 슬롯이 이메일 여권을 통해 `우리집`·`처가`·`본가` 가족방에 실시간 전파되어 과거 사진까지 자동 구출합니다.

### 3.4 화면 정화(UI Diet) 4대 규칙 및 `👑 방장` 호칭 통일
1. **`👤 개인 라운지`에서 얼굴/여권 박스 100% 제거 (완전 비노출):**
   - 나 혼자 기기를 검색·정리하는 개인 라운지(`activeLoungeType === 'personal'`)에서는 `FaceMemberInlineBar` 및 여권/얼굴 등록 섹션을 아예 렌더링하지 않으며, 검색창 바로 아래에 동영상·사진·문서 결과만 즉시 노출됩니다.
2. **가로 6열 미니 아바타 박스 철거 ➔ '1장씩 스무스 사각형 카드 (등록 완료 시 Auto-Hide 완전 소멸)':**
   - 이미 등록된 멤버(`은숙`, `👑 멀린`, `치우`, `천우`, `지우`)는 상단 라운지 바(`LoungeFeedContextBanner`)의 **깔끔한 별명 알약 버튼**으로만 표시하고, 복잡한 연도 바구니 수치(`2026~2017↪36` 등)는 `[🛂 여권 관리]` 모달 내부로만 격리했습니다.
   - 확인이 필요한 항목(새 각도 후보 또는 새로 등장한 인물)이 있을 때만 **큼직한 사각형 사진(`rounded-2xl`) 1장씩** 카드로 띄워 직관적인 1줄 질문으로 안내합니다:
     - **`"😎 선글라스 낀 이 분도 [👑 멀린]님 맞죠?"`** *(처가방에서는 `[👑 둘째사위]`)* ➔ **`[⭕ 맞아요! 등록]`**
     - **`"👋 새로 등장한 이 분의 별명을 적어주세요"`** ➔ 입력 후 **`[⭕ 맞아요! 등록]`**
   - 모든 확인 카드가 처리되면(남은 건수 0건) **카드 박스 전체가 화면에서 완전히 사라집니다(`return null`)**.
3. **어르신·가족 친화적 문구 정돈 (`✨ AI 얼굴 자동 매칭 도우미`):**
   - 내부 기획용 단어(`3단 집단지성 프로토콜`, `노약자 모드`)를 화면에서 제거하고, **`✨ AI 얼굴 자동 매칭 도우미`** 배지와 **`⚡ 확인 건너뛰고 사진만 바로 올리기 (방장이 나중에 정리)`** 버튼으로 따뜻하고 직관적이게 다듬었습니다.
4. **`호스트 ➔ 👑 방장` 전면 교체 및 왕관(`👑`) 계급장 표시:**
   - 방 개설자(`face_member_5`)의 별명 알약 앞에 항상 **`👑` 왕관 아이콘**을 부착하고, 모든 안내·버튼을 **`👑 방장 누락분 뒷정리`**, **`👑 방장 총점검`**으로 통일했습니다.

## 4. 3번 서브메뉴 `[⏳ AI 인덱싱 대기실]` — 안심 시간 벌기용 버퍼 (`LoungeIndexingWaitingRoom`)

- **개념 정의:** 누군가 수동으로 검열하는 공간이 아니라, 멤버들의 스마트폰에서 올라온 고화질 사진·영상이 방장의 마스터 PC(또는 24시간 GPU 클라우드 도우미)에서 **Gemma 2 768차원 실명·상황 인덱싱 및 13KB 캐시 변환을 마치는 동안 머무는 안심 시간 벌기용 버퍼**입니다.
- **라운지별 맞춤형 대기실 작동:**
  - `👨‍👩‍👧‍👦 패밀리`: 우리집 · 본가(친가) · 처가(친정) 방 분리 태그 및 가족 얼굴 자동 매칭 버퍼
  - `⛳ 클럽`: 동호회 참석자 얼굴 클러스터링 & 13KB 캐시 + 5MB 무손실 원본 P2P 시드 패키징 버퍼
  - `🎒 스쿨`: 낮 시간(학교·학원) 동안 친구들이 찍어 올린 인생샷·축제 영상을 모아두었다가, 하교 후 방장 집 게이밍 PC가 켜지는 즉시 0.1초 자동 색인·배포하는 버퍼 (방장 PC가 꺼져 있을 때 **`[⚡ 24시간 GPU 클라우드 도우미 가동]`** 또는 **`[👉 방장에게 PC 켜달라고 콕 찌르기]`** 지원)

### 4.2 `⛳ 클럽 라운지` 4050 동창회 락인(Lock-in) 특화 UX & 계절↔월(Month) 양방향 확장 검색 인덱싱 (`LoungeView.tsx`, `useSaySeeStore.ts`)
1. **생성형 맞춤형 간판 'Text-to-Banner' 최상단 자동 장착:**
   - 방 개설/전환 시 키워드(예: `'성동고 1989'`)를 감지하여 8090 레트로 감성 배경(`복고풍 칠판` / `노을 진 운동장` 전환 지원) 중앙에 **`'성동고 89회 동창회'`** 타이포그래피가 합성된 와이드 배너를 라운지 최상단에 자동 장착합니다.
   - 배너 우측에는 카카오톡 단체방 유입을 유도하는 원터치 초대장 복사 버튼 **`[💌 초대장 카피: "네가 몰랐던 89년 수학여행 네 사진 다 찾았다"]`**를 제공합니다.
2. **첫 화면 얼굴 검색 전면 배치 & '추억 vs 근황' 투트랙(Two-Track) 탭 이원화:**
