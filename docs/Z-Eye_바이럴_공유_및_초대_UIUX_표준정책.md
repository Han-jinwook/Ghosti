## 🏛️ 1. 패러다임 대전환: 왜 구시대적 초대를 버리는가?

### ❌ 과거 방식의 한계 (공식 폐기 대상)
1. **우측 상시 초대/공유 카드**:
   - PC 화면 우측을 거대하게 차지하여 작업 공간을 좁히고, 유저 눈에는 '광고 딱지'로 인식되어 배너 블라인드(무시) 발생.
2. **모바일 하단 1분 플로팅 원형 공유 아이콘**:
   - 유저가 집중해서 사진을 보거나 조작하는 도중(1분 경과 시) 갑자기 하단에서 튀어나와 썸네일이나 버튼을 가려 **오터치(터치 미스)와 불쾌감**을 유발.
3. **추천인·초대코드·초대 리워드 중심 설계**:
   - 유저는 아무런 맥락 없이 지인에게 "이 앱 써봐" 하고 메인 링크를 보내지 않음 (스팸 취급).
   - 애플/구글 앱스토어 심사 시 '보상형 추천(Incentive Spam)' 정책 위반 리스크 상존.

### ⭕ 신규 표준: '100% 기능 맥락 기반 스마트 바이럴'
- 유저는 오직 **"내가 만든 결과물(내 사진 방, 동창회 앨범, 업무 S: 드라이브, PC 청소 결과)을 상대방에게 보여주거나 전달해야 할 때"**만 자발적으로 공유 버튼을 누릅니다.
- 따라서 상시 노출로 유저를 괴롭히지 않고, **결정적 행동 순간(Moment of Delight)에만 핀셋으로 맞춤 공유를 찔러주는 것**이 바이럴 전환율을 10배 이상 높입니다.

## 🖥️ 2. PC / 데스크톱 UI/UX 표준 규격

1. **우측 상시 초대 카드 ➔ 완전 제거**:
   - 우측 패널의 거대한 초대 카드는 완전히 도려내어, 사진 바둑판과 파일 탐색 작업 영역을 100% 넓고 쾌적하게 확보.
2. **상단 헤더 우측 표준 `Share` 아이콘 유지**:
   - 프로필 알약(`게스트/회원`)과 다크모드 아이콘 사이에 위치한 **표준 공유 아이콘(`share`)**은 그대로 유지.
   - 역할: 혹시라도 앱 자체를 타인에게 소개하고 싶은 헤비 유저를 위한 범용 링크 복사 창구.

## 📱 3. 모바일 (Capacitor / 모바일 웹) UI/UX 표준 규격

모바일은 화면 폭(360~400px)이 극도로 협소하므로, PC 헤더의 모든 아이콘을 그대로 욱여넣을 수 없습니다.

1. **하단 1분 플로팅 원형 공유 아이콘 ➔ 영구 폐기**:
   - 화면을 가리고 오터치를 유발하던 플로팅 원형 버튼은 전면 제거.
2. **모바일 공유의 2대 정석 배치 (해결책)**:
   - **① 메인 공유 (기능 기반 100% 연동)**:
     - 모바일에서는 일반 공유 버튼을 헤더에 억지로 구겨 넣지 않고, **100% 기능 내부 맥락에만 일체화**하여 제공.
   - **② 범용 공유 숨은 창구 (햄버거 메뉴 / 프로필 팝업)**:
     - 모바일 좌측 사이드바(햄버거 `☰` 메뉴) 하단 또는 상단 프로필 알약 탭 시 열리는 모달 밑바닥에 `[🔗 친구에게 제트아이 소개하기]` 한 줄 메뉴로 깔끔하게 수용. (헤더 공간 낭비 제로).
