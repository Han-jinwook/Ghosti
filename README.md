# 귀신같이 (Ghosti)

문서·사진·동영상 내용 검색, PC·스마트폰 상태 점검 및 정리, 가족·모임 원본 사진 공유, 다중 기기 통합, 팀 공용 폴더(`S:` 드라이브)를 기기 내 로컬 방식으로 제공하는 관리 도구입니다.

---

## 5단 핵심 메뉴 구성

1. **귀신비서 (무료 기본)**
   - 은행·관공서 미사용 보안 모듈 절전 전환 및 필요 시 자동 실행, 임시 파일·시작프로그램 점검, 중복·흔들린 사진 정리.
   - 정리된 파일은 영구 삭제 없이 OS 기본 휴지통 및 복원 기록으로 이동해 언제든 되돌릴 수 있습니다.
2. **귀신검색 (`Ctrl + 0` / `Ctrl + 우클릭` · 무료 기본)**
   - 파일 이름을 몰라도 문서(PDF·엑셀·한글·워드) 본문, 사진 속 글자, 동영상 장면 구간으로 바로 검색합니다.
3. **사진 공유 (무료 기본)**
   - 가족(`우리집`·`본가`·`처가`), 동호회, 동창회 모임에서 화질 압축이나 만료 기간 없이 원본 사진을 함께 모으고 검색합니다.
4. **내 기기 통합 Pro (선택형 유료 · 30일 무료체험)**
   - 같은 이메일로 내 스마트폰과 여러 대의 PC를 연결해 통합 검색, 양방향 클립보드 공유, 사진·표 OCR 추출, 귀신 라벨러를 사용합니다.
5. **업무 공유 — 공용 폴더 `S:` 드라이브 (선택형 유료 · 30일 무료체험)**
   - 별도 NAS 장비 없이 대표 PC 폴더를 팀 공용 드라이브(`S:`)로 연결해 사내 문서를 함께 검색하고 편집 잠금·백업을 관리합니다(대표 1인 정액제).
