PART 1 · PURPOSE & VISION

🔥 1. 왜 『귀신같이(Ghosti)』를 만드는가? — 앱의 목적·취지 및 국내외 비전

🎯 앱의 탄생 목적과 취지: 디지털 일상의 3대 고통 해방

오늘날 모든 직장인·자영업자·부모님들은 매일 똑같은 세 가지 디지털 스트레스에 시달리고 있습니다.

  • • 첫째 (찾기의 고통): 분명 내 컴퓨터와 폰에 있는 계약서·엑셀 단가표·아이 사진인데 파일 이름이 기억나지 않아 수십 개 폴더를 일일이 열어보며 시간을 허비합니다.
  • • 둘째 (클라우드 요금과 유출 불안): 사진과 문서가 쌓일수록 매달 클라우드 용량 요금을 내야 하고, 내 사생활 사진이나 회사 기밀 문서를 외부 서버에 올리는 것 자체가 불안합니다.
  • • 셋째 (느려진 기기와 반복 타이핑 노가다): 은행 사이트 한 번 다녀오면 보안프로그램들이 뒤에서 돌아 컴퓨터가 느려지고, 한영키 실수·PDF 줄바꿈 깨짐·칸 나눠 붙여넣기 같은 단순 타이핑 노가다에 에너지를 뺏깁니다.

👉 『귀신같이』는 내 파일을 외부 서버로 단 1바이트도 올리지 않는 100% 온디바이스(On-Device) 로컬 AI 엔진(멀린 Z 코어)으로, 개인 기본 기능을 카드 등록도 광고도 없이 평생 무료로 해결해 주는 ‘실전 생활·업무 비서’입니다.

🌏 국내 및 글로벌 비전: 우리가 함께 가슴 뛰며 만들어가는 목표

🇰🇷 [국내 비전] 대한민국 모든 PC와 스마트폰의 필수 기본 유틸리티

과거 모든 컴퓨터에 압축 프로그램과 파일 검색 유틸리티가 필수로 깔렸던 것처럼, “파일 내용 찾기, 사진 정리, 컴퓨터 속도 관리, 타이핑 자동화는 귀신같이 하나로 끝난다”는 새로운 표준을 세웁니다. 개인과 일반 PC에서는 조건 없는 무료로 대중적 신뢰를 얻고, 폰↔PC 원격 연동과 사무실 팀 공유(S: 드라이브)로 탄탄한 수익 모델을 완성합니다.

🌐 [글로벌 비전] 프라이버시 시대의 가장 실용적인 로컬 AI 표준 (Ghosti AI)

전 세계적으로 “내 사진과 회사 문서를 빅테크 클라우드 서버에 올리기 싫다”는 로컬 프라이버시 수요와 매달 나가는 구독료 피로감(Cloud Fatigue)이 폭발하고 있습니다. 서버 비용이 거의 들지 않는 온디바이스 AI 구조와 9개 핵심 특허 기술을 무기로, 북미·일본·유럽 등 글로벌 시장에서도 가장 빠르고 정직한 로컬 AI 워크스페이스로 자리 잡는 것이 우리의 비전입니다.

  • • 탭 2. 문서 · 메모 · 영수증: 사진첩에 뒤섞인 영수증·계약서·칠판 사진만 따로 모아 분류합니다.
  • • 탭 3. 스크린샷 · 캡처: 임시로 캡처해 두고 잊어버린 스크린샷 쓰레기를 골라냅니다.

※ 삭제한 파일은 영구 삭제되지 않고 Windows 정식 휴지통 및 타임머신 복원함으로 안전하게 이동하여 언제든 1초 만에 원상복구됩니다.

② 우측 귀신비서 채팅창: ‘실적을 모아서 생색내는’ 1회성 대화 칩 원칙

비서가 사사건건 팝업을 띄우며 쫓아다니면 유저가 피로해합니다. 그래서 귀신비서는 뒤에서 조용히 일을 해둔 뒤, 실적이 쌓였을 때 우측 채팅창에서 한 번씩 보고하며 생색내는 원칙으로 작동합니다:

  • • 1회성 대답 칩 (클릭 즉시 소멸): 말풍선 아래에 뜨는 추천 대답 버튼을 누르면 그 즉시 버튼이 사라져 채팅창이 지저분해지지 않습니다.
  • • 은행·관공서 보안프로그램 자동 절전: 은행 업무를 안 볼 때도 뒤에서 메모리를 먹는 보안프로그램(TouchEn, ASTx, AnySign 등)을 발견하면 “평소엔 재워두고 은행 갈 때만 깨워드릴까요?”라고 물어 1클릭 동의를 받습니다.
  • • 다운로드 폴더 ZIP 3건 이상 누적 시 우클릭 0.35초 압축풀기 제안: ZIP 파일을 받을 때마다 귀찮게 말을 걸지 않고, 다운로드 폴더에 압축파일이 3건 이상 쌓였을 때만 “압축파일이 N건 모여 있던데 우리 0.35초 우클릭 압축풀기로 써보실래요?”라고 안내합니다. 버튼을 누르면 탐색기가 열리며 가장 최근 .zip 파일에 파란색 선택 포커스가 자동으로 맞춰집니다.
메뉴 2순위 · 기본 무료

👻 귀신검색 (소환창 명칭: 『귀신검색창』 · 단축키 Ctrl + 0 / 우클릭 꾹~)

웹 검색창을 없애고 바탕화면 어디서나 0.1초 만에 부르는 로컬 투시 검색
① 왜 앱 안의 고정 검색창을 없앴는가? (3대 호출 방식)

파일을 찾으려고 굳이 브라우저나 앱 화면을 다시 열 필요가 없습니다. 윈도우 바탕화면이나 탐색기, 엑셀 작업 중 어디서든 아래 3가지 방법으로 『귀신검색창』이 마우스 옆에 즉시 소환됩니다:

  • • 호출 1 (마우스): 빈 공간이나 작업 중 마우스 우클릭을 0.35초 살짝 길게 꾹~ 누르기
  • • 호출 2 (혼합): Ctrl + 마우스 우클릭
  • • 호출 3 (키보드): Ctrl + 0 단축키 입력

※ 소환된 『귀신검색창』은 일반 창처럼 상단 [⤢ 크게(갤러리) / ⤡ 작게] 2가지 모드로만 심플하게 전환되며, 작게 모드에서는 검색 결과 양과 미리보기에 따라 슬림 바(520px) ↔ 중형(960×640)으로 스스로 크기가 조절됩니다. 앱 내 [👻 귀신검색] 메뉴는 이 소환술을 몸에 익히는 현장 수련장 역할을 합니다.

② 파일 제목을 몰라도 찾는다! 3대 투시 검색 초능력
