## Brand & Style

This design system expresses confidential, private artificial intelligence through radiant optical materials set against quiet, infinite space. Designed for an on-device, voice-driven photo memory engine, the interface communicates zero-latency understanding, acoustic precision, and sovereign local privacy.

The aesthetic fuses **Tactile Glassmorphism** with **Atmospheric Dark-Mode Luminescence**:
- **Atmospheric Depth:** Deep obsidian and midnight navy substrates provide infinite contrast, eliminating visual clutter so user memories command focus.
- **Spectral Illumination:** Radiant cyan, electric cerulean, and soft ultraviolet signals illuminate active acoustic states, vector matches, and local neural processing without harsh glare.
- **Tactile Materiality:** Translucent spatial planes, frosted quartz boundaries, micro-refractions, and multi-stage ambient rings provide an intuitive sense of touch and fluid response.
- **Privacy-Forward Reliability:** Dense, balanced typographic layouts and crisp geometric markers reassure the user that machine learning operations remain strictly confined to the hardware in their hand.

## Colors

The palette establishes an acoustic, cinematic environment structured into spatial canvas tiers, neural status accents, and luminous focal points.

### Palette Architecture
- **Base Canvas (`#121318`):** Deep charcoal abyss absorbing secondary optical reflections.
- **Surface Elevation (`#1E1E24`):** Secondary container surface providing baseline structural separation.
- **Nocturne Deep (`#151D48` & `#1A237E`):** Rich midnight navy used for ambient container gradients, active voice card highlights, and local index filters.
- **Primary Kinetic Accent (`#00E5FF`):** Radiant neon cyan signifying acoustic input, real-time waveform modulation, and exact vector search matches.
- **Secondary Atmospheric Accent (`#7C4DFF`):** Soft violet signifying local neural inference, context extraction, and temporal tags.
- **Tertiary Accent (`#00B0FF`):** Electric blue for secondary interactive links, active toggles, and metadata highlights.
- **Structural Traces (`rgba(148, 163, 184, 0.14)`):** Muted slate borders defining physical boundaries without obstructing content.
- **Text & Contrast:** 
  - Pure Focus: `#FFFFFF`
  - High Contrast Readable: `#E2E8F0`
  - Muted Label / Tabular Metadata: `#94A3B8`

## Typography

The typography stack pairs modern Latin geometric grotesques with universal fallback stacks for CJK (Pretendard, Apple SD Gothic Neo, SUIT, and Malgun Gothic). 

- **Headlines (`Plus Jakarta Sans`):** Features tight geometric proportions and deep apertures, commanding presence during memory presentation while remaining friendly and ergonomic.
- **Body & Microcopy (`Inter`):** Engineered for screen legibility, high x-height, and neutral optical rhythm across bilingual Korean/English search queries.
- **Data, Diagnostics, & Timestamps (`JetBrains Mono`):** Dedicated tabular monospace treatment applied to photo timestamps, memory coordinates, latency metrics (e.g., `38ms on-device`), and vector match coefficients.

## Layout & Spacing

The layout is built for fluid touch ergonomics, single-handed mobile usage, and edge-to-edge media browsing within progressive web app display viewports.

### Grid & Layout Structure
- **Mobile Handset (&lt; 640px):** 4-column fluid layout with an inner viewport margin of `1rem` (16px) and column gutters of `0.75rem` (12px). Bottom 104px reserved as a safe zone for the floating voice action capsule.
- **Tablet & Foldable (640px - 1024px):** 8-column responsive grid with `2rem` (32px) margins and `1rem` (16px) gutters. Memory photos render in a staggered masonry view.
- **Desktop Dashboard (&gt; 1024px):** 12-column bounded canvas (max-width `1280px`) centered with `1.5rem` (24px) gutters.

### Spatial Hierarchy
- Compact UI components (micro badges, search tokens) employ `space-xs` (4px) and `space-sm` (8px).
- Internal card padding defaults to `space-md` (16px) for compact listings and `space-lg` (24px) for hero voice transcripts.
- Sections and semantic groups separate using `space-xl` (40px).

## Elevation & Depth

Spatial layering relies on glassmorphic light transport, backdrop attenuation, and colored luminescence rather than flat drop shadows.

### Glassmorphic Surfaces
- **Base Canvas:** Solid `#121318`.
- **Level 1 (Grid Cards & Containers):** Background `rgba(30, 30, 36, 0.65)` layered over `backdrop-filter: blur(16px) saturate(180%)`. Border: 1px solid `rgba(148, 163, 184, 0.12)`.
- **Level 2 (Interactive Floating Sheets, Modals):** Background `rgba(21, 29, 72, 0.70)` layered over `backdrop-filter: blur(28px)`. Border: 1px solid `rgba(0, 229, 255, 0.25)`.
- **Level 3 (Action Pill & Voice Trigger):** Background `linear-gradient(135deg, rgba(26, 35, 126, 0.85), rgba(18, 19, 24, 0.90))`. Inner highlight: inset 0 1px 0 rgba(255, 255, 255, 0.25).

### Illumination & Ambient Glows
- **Passive Depth:** Subtle dark drop shadow `0 12px 32px rgba(0, 0, 0, 0.45)`.
- **Acoustic Active Glow:** Radial energy spread from active voice states using `0 0 32px rgba(0, 229, 255, 0.35)` merged with `0 0 64px rgba(124, 77, 255, 0.20)`.
- **Neural Compute Glow:** Gentle breathing aura with `0 0 24px rgba(124, 77, 255, 0.30)`.

## Shapes

The design uses a cohesive organic roundedness model to create an inviting, human-centered tactile interface that balances sleek optics with friendly interaction:
- **Small Controls & Tags (`rounded-sm`, 8px):** Badges, chip filters, tooltip bubbles, and metadata tags.
- **Primary Inputs & Cards (`rounded-lg`, 16px):** Search input bars, photo cards, list groups, and alert banners.
- **Featured Panels (`rounded-xl`, 24px):** Memory discovery cards, preview modals, and contextual sheets.
- **Continuous Curvature (Pill / 9999px):** Primary voice capture trigger, status indicators, floating dock controls, and progress tracks.

## Components

### Buttons
- **Primary Kinetic Button:** Rounded pill shape, background `linear-gradient(135deg, #00E5FF, #00B0FF)`, text `#121318` font weight 700. Pressed state scales down slightly to 0.97.
- **Secondary Ghost Button:** Frosted backdrop `rgba(255, 255, 255, 0.05)`, border 1px solid `rgba(148, 163, 184, 0.20)`, text `#E2E8F0`. Hover triggers a cyan border highlight (`rgba(0, 229, 255, 0.5)`).

### Tactile Voice Mic Trigger
- Centered floating bottom trigger with a multi-layer pulse ring system.
- Idle: 64px circle with a core gradient of `#1A237E` to `#00B0FF`, enclosed in a thin `#00E5FF` rim.
- Listening State: Multi-layer concentric pulse rings expand outward using CSS animation (`transform: scale(1.6)`, opacity fading from 0.4 to 0). Real-time mic volume translates to SVG sine wave amplitude rendered in `#00E5FF` across the center axis.

### Chips & Badges
- **Voice Entity Chips:** Pill shapes (`rounded-full`) with `rgba(124, 77, 255, 0.15)` fill and `1px solid rgba(124, 77, 255, 0.40)`. Shows recognized entities like `"Last Summer"`, `"Jeju Beach"`, or `"Mom's Birthday"`.
- **Privacy Assurance Badge:** Compact pill containing a padlock icon, filled with `rgba(0, 229, 255, 0.10)`, with `JetBrains Mono` text `"ON-DEVICE INDEX"`.

### Input Fields
- Dark translucent capsule (`rgba(30, 30, 36, 0.8)`) with `backdrop-filter: blur(12px)`.
- Border: 1px solid `rgba(148, 163, 184, 0.18)`.
- Active focus state transitions border to `#00E5FF` accompanied by an external glow `0 0 12px rgba(0, 229, 255, 0.25)`.
- Text is `#FFFFFF`, placeholder `#94A3B8`.

### Memory Cards
- Ratio-driven visual media framed in 16px or 24px rounded corners.
- Overlaid with a bottom dark gradient (`rgba(18, 19, 24, 0.85)` to transparent) highlighting contextual match metadata, time, and confidence percentages in tabular monospace fonts.

### Checkboxes & Radios
- 20px rounded elements (`rounded-sm` for checkboxes, circular for radios).
- Inactive: Border 1.5px solid `#94A3B8`, clear background.
- Active: Background `#00E5FF`, border `#00E5FF`, with a deep charcoal `#121318` icon checkmark.
