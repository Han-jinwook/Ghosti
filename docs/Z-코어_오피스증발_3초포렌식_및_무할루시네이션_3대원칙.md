## 🔍 2. 오피스 증발 · 실수 삭제 3초 포렌식 (`trace_missing_file_omni`)

유저가 **`1초 투시검색`**에서 찾거나 **`설정몬스터`**에 *"작업하던 엑셀/한글 파일이 사라졌어요"*라고 호소할 때, 하드디스크 전체를 30분간 무작정 뒤지지 않고 아래 **3단계 결정론적 포렌식 파이프라인**으로 **3초 이내**에 찾아냅니다 (`universal_z_core/os_agent/plugin_zeye_os.py`):

1. **1단계 — 5대 오피스 은닉 금고(`5 Hidden Vaults`) 직격 스캔 (0.5초):**
   - `Excel / Word AutoRecover` (`%APPDATA%\Microsoft\Excel\`, `%APPDATA%\Microsoft\Word\`)
   - `Office UnsavedFiles` (`%LOCALAPPDATA%\Microsoft\Office\UnsavedFiles\`)
   - `HWP(한글) 자동저장 금고` (`%APPDATA%\HNC\User\AutoSave\`)
   - `카카오톡 받은파일 & 임시 캐시` (`Documents\카카오톡 받은 파일`)
   - `Z-코어 Active Document Shadow Vault` (`%LOCALAPPDATA%\Merlin\ShadowVault\`)
2. **2단계 — 윈도우 휴지통(`C:\$Recycle.Bin\{SID}\`) `$I` 바이너리 헤더 직접 해독 (0.5초):**
   - 윈도우 휴지통에 들어가면 파일명이 `$Rxxxxxx.xlsx`처럼 난수로 바뀌어 일반 검색으로는 절대 찾을 수 없습니다.
   - `plugin_zeye_os.py`의 `scan_windows_recycle_bin()`은 짝꿍 메타데이터 파일인 **`$Ixxxxxx` 바이너리 헤더(Version 1 Vista/7 및 Version 2 Win10/11 규격, 64-bit File Size + FILETIME 삭제 시각 + UTF-16LE 원본 전체 경로)**를 직접 파싱하여 **삭제되기 전의 원래 파일명과 원래 폴더 위치**를 정확히 복원해 냅니다.
3. **3단계 — 블랙박스 삭제·이동 로그 대조 및 10초 정직 컷오프:**
   - 5대 금고와 휴지통에도 없을 경우, OS 파일 이벤트 블랙박스를 대조하여 *"언제 어떤 프로세스에 의해 이동/영구 삭제되었는지"* 1초 만에 소명하거나, 흔적이 없으면 **10초 내에 정직하게 고지하고 종료**합니다.

## ⏱️ 3. `[복원 기록]`(`restore_points.json`) 3단계 무결성 사전 검진(Pre-Check) 타임머신

1. **공식 명칭 통일:** 사용자 화면에는 개발자 용어(`Git 커밋`) 대신 **`[복원 기록]`**으로 표기합니다.
2. **조회 시 0.01초 3단계 무결성 사전 검진 배지:**
   - **`🟢 [100% 완벽 복원 가능]`**: 백업 스냅샷과 대상 경로가 100% 온전하여 1초 만에 완벽 원복 가능한 상태.
   - **`🟡 [부분 복원 가능 (M건 중 N건)]`**: 일부 파일이 외부에서 이동/삭제되었으나 나머지 항목은 즉시 복원 가능한 상태.
   - **`🔴 [복원 불가 (파일 없음)]`**: 사용자가 백업 원본까지 수동으로 영구 소각하여 복원이 불가능한 상태 (거짓 성공 보고 원천 차단).
