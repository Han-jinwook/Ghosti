# 🤝 Pure Sharing Suite (순수 공유 가이드)

본 문서는 Merlin Hub SDK의 SNS/링크 순수 공유 위젯에 대한 연동 명세입니다.
*(2026-10-24부로 `?ref=` 추천인 코드, 10% 추천 리베이트, `[앱 초대 List]`는 전면 폐기되었으며, 브랜드 품격을 높이는 담백한 '순수 공유' 체제로 운영됩니다.)*

---

## 1. 주요 모듈 & Components
- **부품 Components**:
  - `HubShareSquare` (사이드 윙 및 모바일 바텀시트 순수 공유 카드 위젯)
  - `HubShareButton` (`"주변에 알려주기"` 공유 버튼)
  - `HubReferralWidget` (하위 호환용 순수 공유 배너)

---

## 2. 공유 컴포넌트 표준 문구 및 적용 예시

- **카드 타이틀 (`customTitle` 기본값)**: `"써보니 편한 기능, 주변에도 알려주세요"`
- **카드 설명 (`description` 기본값)**: `"혼자 쓰기 아까운 AI 도구를 가족·지인과 함께 나눠보세요."`
- **공유 버튼 텍스트**: `"주변에 알려주기"` (이모지 제외)

```tsx
import { HubResponsiveWing, HubShareSquare } from "@/services/merlin-hub-sdk/react";

// 표준 반응형 윙 공유 카드 적용 (우측 사이드윙 및 모바일 플로팅 공유 버튼 자동 연동)
<HubResponsiveWing
  bannerId="app_share"
  shareTitle="써보니 편한 기능, 주변에도 알려주세요"
  shareDescription="혼자 쓰기 아까운 AI 도구를 가족·지인과 함께 나눠보세요."
/>
```
