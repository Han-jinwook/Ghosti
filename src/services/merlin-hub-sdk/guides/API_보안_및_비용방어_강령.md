# 멀린 패밀리 API 보안 및 클라우드 비용 방어 표준 수칙

## 1. 개요 및 배경
2026년 9월 9일, 프론트엔드 번들 및 환경변수 노출로 인한 Gemini API 악용 사태(약 31.6만 원 비정상 호출)를 겪은 후, 재발 방지를 위해 전 패밀리 앱에 적용되는 절대 원칙입니다.

---

## 2. 3대 보안 및 과금 방어 절대 원칙

### ① 클라이언트 번들 내 AI API Key 직접 인젝션 100% 금지
- Vite, Next.js 등 빌드 도구의 `define: { 'process.env.API_KEY': ... }` 설정을 통해 API 키를 JS 번들에 삽입하는 행위를 전면 금지합니다.
- 클라이언트에 포함된 키는 브라우저 개발자 도구 및 웹 크롤러 스캐너에 100% 노출됩니다.
- **표준 아키텍처**:
  - 클라이언트 ➔ **백엔드 프록시 (Supabase Edge Function 또는 Render 백엔드)** ➔ **AI API (Gemini / OpenAI 등)**
  - API Key는 오직 백엔드 서버의 비공개 환경변수(`SUPABASE_SECRETS` 또는 Render Environment)에만 보관합니다.

### ② 클라우드 결제 예산 한도(Budget & Cap) 필수 설정
- 구글 클라우드(GCP) 결제 계정 복구 시 반드시 아래 예산 정책을 즉시 적용합니다:
  - **월 목표 예산**: 10,000원 ~ 30,000원 (실제 사용량에 맞춰 최소화)
  - **임계치 알림**: 50%, 90%, 100% 도달 시 이메일 및 모바일 즉각 알림
  - **프로젝트 일일 할당량(Quota Cap)**: Gemini API 콘솔에서 분당 요청 수(RPM), 일일 최대 요청 수(RPD)를 개인 개발용에 맞게 제한(Cap) 설정.

### ③ API Key 사용 범위 제한(Key Restrictions) 필수
- 부득이하게 클라이언트 키(예: Google Maps, Firebase 등)를 사용할 때는:
  - **애플리케이션 제한**: 특정 웹사이트 도메인(`*.sundreamer.app`, `localhost` 등) HTTP 리퍼러 제한 적용
  - **API 제한**: 해당 키로 호출 가능한 API를 단 1개(예: Geocoding API만)로 한정하여 다른 고비용 API 호출 원천 차단.

## 3. 중앙 집중형 AI 키 금고 (OS Hub Gateway) & 멀티 계정 라우팅 표준

모든 유료 AI API Key(Gemini, OpenAI 등)는 **개별 프론트엔드(Netlify 등)에 보관하는 것을 영구 금지**하며, 오직 **허브 백엔드(`os.sundreamer.app` / Render)** 단일 금고에서 중앙 집중 관리합니다.

### 🎯 멀티 계정(소유자별 분기) 라우팅 네이밍 규칙
소유자 계정(멀린님, 사모님, 앱별 프로젝트 등)이 다를 경우 Render 환경변수에서 다음과 같이 접미사(Suffix)로 구분하여 보관합니다:
- `GEMINI_API_KEY_MERLIN`: 멀린님 소유 구글 계정의 Gemini Key (루미노트 CRM 기본)
- `GEMINI_API_KEY_WIFE`: 사모님 소유 구글 계정의 Gemini Key (썬드리머 후기 등)
- `GEMINI_API_KEY_DEFAULT`: 기본 시스템 폴백 키
- `OPENAI_API_KEY_WHATEAT`: 개별 앱 특화 키

### 🔄 클라이언트 호출 프로토콜 (Header Routing)
개별 앱 프론트엔드는 허브 AI 엔드포인트(`/api/ai/gemini`) 호출 시 헤더를 통해 소유 계정을 지정합니다:
- `x-client-secret`: 허브 앱 인증 시크릿
- `x-ai-account`: `'merlin'` | `'wife'` | `'default'`
- 허브 백엔드가 요청 헤더에 맞는 환경변수 키를 동적으로 선택하여 구글/OpenAI에 프록시 요청 후 결과만 반환합니다.

## 4. 개별 앱 런칭/점검 시 필수 보안 체크리스트 (Hard Requirement)

모든 패밀리 앱(썬드리머, 리얼픽, 뭐먹지, 어그로필터, 볼트 등) 배포 및 유지보수 시 전담 AI는 다음 사항을 100% 검증해야 합니다:

- [ ] **Netlify/프론트엔드 환경변수 검사**: `VITE_GEMINI_*`, `VITE_OPENAI_*`, `NEXT_PUBLIC_*_KEY` 등 유료 결제성 시크릿 키가 환경변수에 들어있지 않은가? (발견 즉시 즉각 삭제)
- [ ] **빌드 번들 누출 검사**: `git grep -i "AIzaSy"` 또는 소스코드 내 하드코딩 여부 0건 검증
- [ ] **허브 프록시 경유 확인**: 모든 AI 기능이 프론트엔드 직접 호출이 아닌 `os.sundreamer.app` 백엔드 프록시를 경유하도록 구현되어 있는가?
- [ ] **GCP 결제 계정 할당량 캡(Cap) 확인**: 월 1~3만 원 예산 알림 및 분당/일일 요청 제한(RPM/RPD) 적용 여부
