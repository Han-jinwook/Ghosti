## 2. 내 기기 통합 (Pro 확장) — 귀신Key 관련 추가 기능
- **`7일 통합 클립보드 보관함 (PC↔PC 무버튼 직결 · 폰↔PC 1탭 전송)` (E2EE · 7일/최대 500건 보관 통일 · 2026-11-26 멀린님 최종 확정)**
  - **확정 설명 카피**: *"카톡 '나에게 보내기'로 글자·링크 칠 필요 끝! PC끼리는 `Ctrl+C`만 누르면 바로 붙고, 스마트폰에서는 `[드래그/공유 ➔ PC로 보내기]` 한 번(또는 앱 열기)이면 1초 만에 PC `Ctrl+V`로 꽂히며 7일간 전 기기에서 안전하게 꺼내 씁니다."*
  - **커스텀 키보드(방식 C) 영구 폐기 ➔ 설정 0개 기본(방식 A) + 앱 안 여는 OS 순정 1탭 전송(방식 B) 투트랙 결합 (`3귀신` 담당)**:
    - **PC ↔ PC (집컴 ↔ 회사컴 ↔ 노트북)**: 100% 무버튼 실시간 양방향 직결 (`Ctrl+C` 시 `0.2초` 만에 다른 PC `Ctrl+V` 즉시 장전).
    - **스마트폰 ➔ PC (앱 안 열고 1탭 메인 + 앱 열기 보조)**: Android는 글자 드래그 플로팅 메뉴 **`[귀신 클립보드 저장]` (`ACTION_PROCESS_TEXT`)** + 상단 알림바 빠른 전송 버튼, iOS는 **`[공유] ➔ [귀신같이 PC로 바로 보내기]` (`Share Extension`)** 1탭으로 앱 전환·`[붙여넣기 허용]` 팝업 없이 PC `Ctrl+V`로 직송. 공통 보조 동선으로 복사 후 귀신같이 앱 열기 자동 전송도 유지하며, iOS 유저에게는 필요 시 `[아이폰 설정 > 귀신같이 > 다른 앱에서 붙여넣기 > 허용]` 1줄 선택 팁 제공. *(※ 일반 유저 거부감·이탈을 유발하는 커스텀 키보드 `전체 접근 허용` 방식은 영구 폐기)*
    - **PC ➔ 스마트폰**: PC에서 `Ctrl+C` 한 텍스트/링크가 폰 `[7일 통합 클립보드 보관함]`에 실시간 도착하며, 폰에서 귀신같이 앱을 열면 `45ms` 내 폰 클립보드에 자동 장전되어 바로 붙여넣기 가능.
- **`F1~F6` 개인 상용구 내 모든 PC 동기화** *(집 PC · 회사 PC · 노트북 등 PC 간 1초 동기화 · 스마트폰에는 물리 `F1~F6` 키가 없으므로 PC 전용 동기화로 명확화 · 서버 브릿지 `device_sync_snippets` 개통 완료)*
