# 🛡️ SaySee & ClearMonster 핵심 정책 및 엔지니어링 원칙 (`정책_및_핵심원칙.md`)

> **최종 업데이트:** 2026-10-16  
> **목적:** 대표님과 확정된 서비스 정책, 검색 정밀도 원칙, 100% 로컬 아키텍처 원칙, 클리어몬스터 안전 기준을 명문화하여 모든 개발 세션에서 일관되게 준수하도록 합니다.

## 1. 검색 엔진 코어 확정 원칙 ("768차원 벡터 엑셀 + 온톨로지/지명 브레이크")

1. **검색 엔진 코어 100% Fix 보존**
   - `vite.config.ts`의 `runHybridCorpusSearch` 하이브리드 구조(768차원 EmbeddingGemma 2 벡터 유사도 + 한국어 개념 족보 `Is-A` 상속 및 EXIF GPS 지명 가드레일)는 최종 확정(Fix)되었습니다.
   - 특정 사진이나 검색어 때문에 임시 평면 정규식을 검색창에 덕지덕지 붙이는 행위를 절대 금지하며, 어휘 확장이 필요할 때는 오직 `src/data/koreanPhotoOntology.json`의 `Is-A` 계층 트리만 업데이트합니다.
2. **`Is-A` 단방향 상향 상속 원칙 ("자식 ➔ 부모만 허용, 역방향·형제 오염 금지")**
   - 사진에 구체어(`"생맥주"`, `"수영복"`, `"불쇼"`, `"청라"`)가 검출되면 그 부모 상위어(`"술"`, `"옷"`, `"공연"`, `"인천"`)만 사진 인덱스에 상속합니다.
   - 하위 구체어를 검색했을 때 형제 개념(`"맥주"` 검색 시 `"와인"`, `"불쇼"` 검색 시 `"박물관 공연"`)이 절대 섞여 나오면 안 됩니다.
3. **엄격한 `AND` 교집합 원칙 (억지 `OR` 결과 노출 금지)**
   - 복합 명사/지명 검색어(예: `"청라 보트"`) 입력 시 핵심 명사 조건을 동시에 만족하는 사진이 없으면 **정직하게 `0장`을 반환**합니다.

## 2. 100% 로컬 온디바이스 아키텍처 정책 (외부 LLM / 코인 정산 폐기)

1. **Phase 1 외부 API 의존도 0%**
   - 2~3단어 복합 및 자연어 문장 검색이 로컬 768차원 하이브리드 엔진만으로 `0.04초` 만에 작동하므로, 외부 Gemini API를 연동하던 'LLM 스무고개 인터뷰(Phase 1-B)'와 '하이패스 일일 코인 정산/토글' 기능은 전면 폐기합니다.
2. **로컬 문장 조합기 기반 추천 칩**
   - 상단 문장형 추천 칩 역시 외부 LLM 호출 없이, 인덱싱된 사진의 `[지명/시기 + 배경/사물 + 행동/분위기]` 팩트를 로컬 문장 조합기(`buildLocalSentenceSamplesFromCorpus`)로 결합하여 생성합니다.
3. **원본·썸네일·메타데이터 외부 서버 전송 금지**
   - 사용자의 사진 원본, 썸네일, EXIF 위치 정보, 로컬 벡터 DB는 어떠한 경우에도 외부 클라우드 서버에 업로드하거나 저장하지 않습니다.

## 3. 클리어몬스터 (ClearMonster) 4대 탭 & 안전 격리 정책

1. **4대 쓰레기 탭 구성 및 Bes2 기준 적용**
   - `① 동일한 복사본·연사` / `② 주차장·영수증·서류 메모` / `③ 스크린샷` / `④ 심한 흔들림·오촬영` 4대 탭으로 구성합니다.
   - `D:\Bes2\분석로직.md`의 쓰레기 텍스트 정의(임시 기록용 사진, 전자기기/부품 접사 `#부품·접사` 등)와 Positive Filter(식당 음식·와인병 `#식당·음식` 오탐 방지) 기준을 적용합니다. (단, Bes2의 무거운 UI나 연사 코드는 가져오지 않습니다.)
2. **연사·중복 `[✓ 원본 1장 안전하게 보존됨]` 및 PC 바둑판(Grid) Pick UI**
   - `① 동일한 복사본·연사` 탭 상단에는 초록색 `[✓ 원본 1장 안전하게 보존됨]` 배지를 명시하고, PC 화면에서는 3×3 / 4×4 바둑판(Grid) 배열로 펼쳐 보여줍니다.
   - 유저가 눈으로 비교해 베스트 컷 1장만 클릭(`Pick`)하면 선택된 1장은 보존되고 나머지 사본들이 즉시 `세이씨_정리대기함`(`test_photos_quarantine`)으로 격리됩니다.
3. **즉시 영구 삭제 금지 ➔ 안전 격리 보관함(Quarantine) 경유**
   - 정리 실행 시 파일을 즉시 삭제하지 않고 격리 보관함(`test_photos_quarantine`)으로 먼저 이동시키며, 언제든 원클릭 복원이 가능해야 합니다.
