# 🏛️ Merlin Family Hub 기능 스펙 (Core Specs)

## 1. 🔑 인증 시스템 (Identity & Access)
- **OTP 로그인**: 이메일 기반 6자리 일회용 비밀번호 발송 및 검증.
- **JWT 세션**: 발급된 토큰을 통해 패밀리 앱 간 통합 세션 유지.
- **SSO(Single Sign-On)**: `.sundreamer.app` 도메인 쿠키 공유를 통한 자동 로그인 지원.

## 2. 💰 지갑 및 자산 관리 (Wallet System)
- **통합 잔액**: 모든 패밀리 앱에서 공통으로 사용하는 `family_coin_balances`.
- **코인 트랜잭션**: 
  - `DEDUCT`: 앱 서비스 이용 시 코인 차감.
  - `CHARGE`: 결제를 통한 코인 충전.
  - `REWARD`: 환영 보상, 이벤트 참여 등으로 인한 코인 지급.
  - `GIFT_SENT` / `GIFT_RECEIVED` / `GIFT_REFUND`: 패밀리 앱 상품 및 코인 선물 발송·수령·취소 환급.
- **이력 관리**: 모든 증감 내역은 `family_wallet_transactions`에 영구 기록.

## 3. 💳 KCP & 네이버페이센터 결제 엔진 (Payment Engine)
- **결제 준비**: `ordr_idxx` 발급 및 KCP 팝업 초기화 데이터 전송.
- **디지털 코인 충전 엔진 (ALRJ8)**:
  - 어그로필터 등 패밀리 서비스 코인 충전 전담.
  - PG사 승인 번호(TNO) 대조 및 무결성 검증 후 `family_wallet_logs` 및 잔액 즉시 동기화.
- **썬드리머 실물 PG 전담 승인 엔진 (ALZX5)**:
  - **엔드포인트**: `POST /api/sundream/payment/prepare` 및 `/api/sundream/payment/callback`
  - **최신 HTTPS REST 승인 (KCP PG-API)**: `https://spl.kcp.co.kr/gw/enc/v1/payment` 호출을 통한 무설치 표준 REST 승인 통신.
  - **ALZX5 전용 인증서 탑재**: 사설 인증서 직렬화 문자열 탑재 및 환경변수 격리.
  - **사후 3대 DB 원장 자동 동기화**:
    1. `orders`: 결제 상태 `paid` 갱신 및 KCP 거래번호(`pg_tid`) 기록.
    2. `sales`: 8대 정품 라인업 정규식 분할 파싱 ➔ CJ대한통운 전담 CRM 실판매원장 자동 등록.
    3. `points`: 1,000P 단위 사용 포인트 차감 원장 기록.
  - **전자 영수증 자동화**: 승인 완료 후 `#my/products` 자동 복귀 및 전자 영수증 모달 즉시 팝업.
- **썬드림 네이버페이센터 직접 연동 엔진 (`[주문형] 썬드림` / `np_gbizv910502`)**:
  - **엔드포인트**: `POST /api/sundream/payment/naverpay-order` 및 `GET /api/sundream/payment/naverpay-items`
  - **KCP 한도 완전 독립**: KCP(`ALZX5`) 월 한도와 무관하게 네이버페이센터(`np_gbizv910502`) 공식 서버(`https://pay.naver.com/customer/api/order.nhn`)로 주문을 직접 등록하고 8자리 `ORDER_ID`를 발급받아 네이버페이 주문서(`order.pay.naver.com` / `m.pay.naver.com`)로 즉시 연결.
  - **비회원 즉시 구매 & 회원 포인트 할인 통합 지원**:
    - 비회원(및 네이버페이 안전센터 검수): 정가 + 조건부 배송비로 즉시 네이버페이 주문서 호출.
    - 썬드리머 회원: 최대 50% 포인트 할인(1,000P 단위) 차감 후 최종 실결제 차액만 네이버페이 `TOTAL_PRICE`로 등록하여 포인트 할인과 네이버페이 결제를 동시 지원.
  - **상품정보 XML 동기화**: `GET /api/sundream/payment/naverpay-items?ITEM_ID=...` 엔드포인트를 통해 네이버페이 서버의 실시간 상품 원장 XML 조회 요청에 표준 `<response><item>` XML 반환.

## 4. 📱 앱 연동 관리 (App Integration)
- **Client ID / Secret**: 각 앱별 고유 인증 키를 통한 API 접근 제어.
- **Scope 관리**: 앱별 허용된 기능 범위(Wallet 읽기, 쓰기 등) 정의.
- **중복 가입 방지**: 최초 가입 앱 기록 및 패밀리 통합 유저 매핑.

## 5. 📬 통합 이메일링 시스템 (Emailing Bridge)
- **네이버 SMTP 메일링**: nodemailer를 활용한 `smtp.naver.com` 연동. HTML 형식 메일을 지원하여 마케팅 및 안내 시 이미지 첨부 가능.
- **트리거 API**: 개별 패밀리 앱 백엔드에서 허브 API(`/api/notification/send`)를 통해 유저별 맞춤 이메일 발송 위임 가능.

## 6. 🛠️ 관리자 도구 (Admin Tools)
- **수동 코인 조정**: 운영자가 유저의 코인을 직접 지급하거나 차감 가능.
- **서버 상태 모니터링**: KCP 게이트웨이 연결 상태 및 서버 아웃바운드 IP 확인.
- **통합 이메일 발송 관리**:
  - 타겟팅 발송: '전체 사용자' 혹은 '특정 패밀리 앱(어그로필터 등) 사용자'를 구분하여 맞춤 이메일 발송.
  - 중요 공지사항(`isNotice: true`) 옵션: 점검 및 긴급 장애 안내 시 사용자의 이메일 알림 수신 동의 여부와 무관하게 100% 강제 이메일 발송 처리.

## 7. 🧪 테스트 계정 관리 & DB 완전 초기화 엔진 (Test Account & Purge Engine)
- **개요**: 패밀리 생태계 확장 및 개별 앱(썬드리머, 어그로필터, 뭐먹지 등) 개발/출시 과정에서 로그인, 온보딩 포인트, 추천 보상, 앱 간 전환 등을 반복 테스트할 수 있도록 테스트 계정의 모든 DB 데이터를 1초 만에 완전 삭제(Purge)하는 어드민 도구.
- **검색 및 다중 히스토리 UI (최대 10개 퀵 칩)**:
  - **이메일 검색**: 네이버 ID(@naver.com 기본 디폴트) 및 Gmail, 다음, 카카오, 직접 입력 도메인 셀렉터 지원.
  - **닉네임 검색**: 통합 닉네임 기준 유저 검색 지원.
  - **다중 검색어 로컬 저장 & 퀵 태그 칩**: 최근 검색한 계정들을 `localStorage` 배열에 최대 10개까지 자동 누적 보관하며, 검색창 하단에 `[⏱️ 최근 검색]` 퀵 칩으로 나열하여 터치 한 번으로 즉시 분리 세팅 및 0.1초 즉시 조회(`executeSearch`) 지원 (개별 삭제 `✕` 및 전체 비우기 탑재).
- **허브 5대 테이블 + 개별앱 CRM 원장 2-Way 정밀 연계 제어 (Purge Engine)**:
  1. `family_user_registrations`: 앱별 가입/등록 이력 영구 삭제.
  2. `family_referrals`: 추천인/피추천인 관계 데이터 영구 삭제.
  3. `family_wallet_*`: 지갑 트랜잭션, 포인트, 코인 잔액 및 적립/차감 이력 영구 삭제.
  4. `family_otp`: 미인증/인증 잔여 OTP 코드 영구 삭제.
  5. `family_users`: 허브 마스터 회원 정보 영구 삭제.
  6. **LumiNote CRM 2-Way 연계 처리 옵션 (기존 고객 자산 철저 보호)**:
     - **🛡️ [옵션 1: 기존 고객 안전 모드 (기본/강력 추천)]**: 11년 기존 오프라인 고객의 기본 정보(이름/주소/연락처/구매기록) 및 기존 보유 포인트는 **100% 안전 보존**하고, 오직 **'썬드리머.앱 가입 축하금(5,000P)' 단일 건만 핀포인트 삭제** + `hub_uuid` 연결만 리셋하여 신규 앱 가입 테스트 가능.
     - **🗑️ [옵션 2: 임시 계정 완전 삭제]**: 순수 신규 임시 테스트 계정(`(임시) 썬드리머N`) 전용으로 루미노트 `customers` 행 + 모든 포인트를 DB에서 영구 물리 삭제.
- **테스트 편의 가이드 배너**:
  - 브라우저에 남아있을 수 있는 로컬 세션 토큰 정리를 위해, Purge 전/후 아무 때나 가입된 앱에서 `[로그아웃]` 또는 `[앱 탈퇴]`를 한 번 터치하도록 안내하는 꿀팁 배너 상시 노출.

## 8. ⚡ 썬드림 포인트 SSOT 자동 디스패처 데몬 (Sundream Points Dispatcher Daemon)
- **개요**: 루미노트 Supabase `points` 테이블 원장에 신규 포인트(적립/차감)가 입력되면, 그 어떤 경로(판매관리, 포인트관리 수동등록, 엑셀 대량 업로드, 시스템 배치 등)에서 등록되었든 허브 본진 백엔드가 실시간 감지하여 100% 누락 없이 이메일 알림을 자동 발송하는 단일 진실 공급원(SSOT) 디스패처 엔진.
- **아키텍처 및 동작 원리**:
  1. **주기적 원장 감시**: 허브 서버(`MerlinFamilyOS` - Render 상시 가동) 기동 시 백그라운드 워커로 루미노트 `points` 원장 모니터링.
  2. **중복 발송 원천 차단 (Idempotency)**: 메모리 캐시 및 `family_notifications` 원장 대조(`[PointID: {id}]` 태그)를 통해 1건의 포인트에 2회 이상 중복 발송되지 않도록 완벽 보장.
  3. **스토어 KCP 실결제 예외 처리**: 스토어 구매적립(`p.created_by === '썬드리머스토어'` 또는 `[구매적립]`) 건은 결제완료 영수증 메일 1통에서 상세 안내되므로 자동 스킵하여 고객에게 메일 중복 발송 방지.
  4. **스마트 호칭 및 Resend 이메일 발송**: 4단계 스마트 호칭(피부카페 -> 화습카페 -> 성명 -> 회원) 엔진을 적용하여, 적립/차감 성격별 전용 문안으로 Resend SMTP 실시간 전송 및 `family_notifications` 영구 로깅.

## 9. 🚚 썬드리머 배송완료 후 7일 경과 자동 구매확정 데몬 (Sundream Auto-Confirm Daemon)
- **개요**: 썬드리머 주문 중 배송완료(`delivered`) 상태로 7일(168시간)이 경과한 건을 허브 백엔드가 1시간 주기로 자동 감지하여 구매확정(`confirmed`) 처리하고 잔여 50% 구매 포인트를 자동 적립하는 풀오토 백그라운드 워커.
- **아키텍처 및 동작 원리**:
  1. **정밀 기준일 SSOT 수립 (`created_at` / `purchase_date`)**: 배송 출발일(송장 등록일 = `created_at`) 및 주문일(`purchase_date`)을 불변의 카운트다운 기준점으로 확립하여, 스탭의 메모 작성이나 센스봇 발송 등으로 `updated_at`이 갱신되더라도 7일 타이머가 리셋되지 않도록 방어.
  2. **1시간 주기 무중단 감시 워커**: Render 상시 백엔드에서 1시간마다 루미노트 `sundream_orders` 테이블의 `delivered` 주문을 조회하여 `created_at` (또는 `purchase_date`) 기준 7일 초과 여부를 정밀 판별.
  3. **원자적 상태 전이 및 50% 포인트 자동 적립**: 7일 경과 주문을 `confirmed` 상태로 자동 갱신하고, 주문 시 기지급된 50%를 제외한 나머지 50% 포인트를 루미노트 `points` 테이블에 자동 적립 (SSOT 디스패처 데몬과 연동되어 축하 메일 자동 발송).

## 10. 🎁 패밀리 통합 '선물함 & 선물하기(HubGiftBox)' 엔진 (Family Gift System)
- **개요**: 쿠폰/티켓 등의 이중 용어를 폐기하고 오직 **'선물(Gift)'** 단일 개념으로 우리 앱 내 디지털 상품 및 코인을 지인에게 포장해 전달·수령하는 생태계 내부 순환 엔진.
- **5대 REST API 엔드포인트 (`/api/wallet/gift/*`)**:
  1. `GET /api/wallet/gift/list`: 받은 선물(`received`), 보낸 선물(`sent`), 원클릭 교류 지인(`contacts` - 추천인/피추천인/선물 교류 지인 자동 수집) 통합 조회.
  2. `POST /api/wallet/gift/send`: 잔액 검증 후 발신자 코인 차감(`GIFT_SENT`), 인앱 알림 등록 및 감성 선물 도착 이메일 비동기 발송.
  3. `POST /api/wallet/gift/claim`: 수신자 선물 열기 및 코인 즉시 적립(`GIFT_RECEIVED`), 발신자에게 수령 완료 알림 발송.
  4. `POST /api/wallet/gift/cancel`: 미수령(`UNCLAIMED`) 선물 취소 및 발신자 코인 즉시 전액 환급(`GIFT_REFUND`).
  5. `POST /api/wallet/gift/nudge`: 미수령 선물에 대한 리마인드 인앱 알림 및 이메일 재발송.
