## 1. 상위 3대 핵심 메뉴 & 2층 서브메뉴 아키텍처

제트아이의 모든 화면은 **`[내 기기]`**, **`[사진 공유]`**, **`[업무 공유]`** 3대 상위 메뉴로 일원화되며, 각 메뉴는 4개의 직관적인 2층 서브메뉴를 가집니다.

### 1.1 `[💻 내 기기]` (혼자 쓸 땐 언제나 100% 무료 — 0원)
- **핵심 원칙:** 별도의 체험 기간 제한 없이 이메일 로그인 즉시 **`클린몬스터` 진단 및 `1초 투시검색`**을 기간·횟수 제한 없이 실행합니다.
- **2층 서브메뉴 구성:**
  1. `🧹 클린몬스터 진단`: 내 PC·폰의 용량 도둑, 중복 파일, 연사 사진, 유령 시작프로그램 1초 종합 진단 보드
  2. `👁️ Z-Eye 투시검색`: 동영상 1초 핵심 구간 · 사진 · 로컬 문서 · 탐색기 장착 `G:` 드라이브(`.gsheet`/`.gdoc`) 1초 투시검색 도화지(`Zen Canvas`)
  3. `🩺 Z-Eye 클린몬스터`: 항목별 상세 비교(`남길 원본 1개` vs `정리 대상 N개`) 및 **`OS 기본 [휴지통]`(`Win32 FOF_ALLOWUNDO`) 직행 + `[↩️ 1초 실행 취소(Undo)]`**
  4. `🛠️ 설정몬스터`: 원클릭 PC·폰 수리, 끊어진 `S:` 드라이브 재연결, 오피스 증발 파일 3초 포렌식 수색 및 **`[복원 기록]`(`restore_points.json`) 3단계 무결성 사전 검진(`🟢 100% 완벽 복원` / `🟡 부분 복원` / `🔴 복원 불가`) 타임머신**

### 1.2 `[📸 사진 공유]` (패밀리 / 동호회 · 동창회 — 방장 1인 결제, 멤버 전원 무료)
- **핵심 원칙:** 가족과 모임을 아우르는 가족(`우리집` / `본가` / `처가` 3방 분리)과 모임(`동호회·소모임` 모임명 문패 / `동창회·반창회` 학교·학년·반 문패)을 아우르는 사진·동영상 전용 공유 공간으로 단일화합니다 (`S:` 드라이브 미제공).
- **2층 서브메뉴 구성:**
  1. `📸 패밀리 공유 시작` / `⛳ 동호·동창회 시작`: 공유방 온보딩, `🛂 Z-Eye 여권` 자동 장착 및 3초 레이더 수합 보드
  2. `🏠 우리집·본가·처가 앨범` / `📸 모임·동창 앨범 & 원본 다운로드`: 인물 별명 알약 바 + 타임라인 피드 + **`[🔄 원본 동기화]`** 토글
  3. `⏳ 새 사진 정리함 (AI 인덱싱 대기실)`: 방장 사전 수동 검수 없이 즉시 게시되며, Gemma 2 768차원 벡터 인덱싱 및 13KB WebP 썸네일 변환이 진행되는 1~2분 버퍼
  4. `👑 가족 초대 & 방 관리` / `👥 동호·동창회 관리 & 회원 초대`: 무수락 카톡 초대 링크·QR 발급, **방 개설 옵션(`24시간 내 올린 본인 삭제` + `방장 상시 [숨기기] 권한 보유 여부`)** 설정, 회원 관리

### 1.3 `[💼 업무 공유]` (1인 멀티PC / SOHO / 소기업 / 중소기업 `S:` 드라이브)
- **핵심 원칙:** 공용 업무 PC 1대(`S:` 가상 드라이브 직결) + **백업 PC 1·2호 실시간 미러링** + **`[🌙 야간·퇴근 초절전 모드]`**(월 전기료 약 1,800원)를 제공하는 업무 전용 공간입니다 (`🛂 인물 여권` 미발동).
- **2층 서브메뉴 구성:**
  1. `💼 업무 공유(S:) 시작`: `S:` 드라이브 원클릭 마운트 및 백업 PC 1·2호 설정 보드
  2. `🔍 업무 문서·현장사진 & S: 드라이브`: **투시검색 뷰 ↔ 윈도우 폴더 트리 뷰 듀얼 모드**, 30KB 0.1초 오프라인 요약 프리뷰, **`File Lock` 동시 편집 읽기모드 안내(`"🔒 현재 [OOO]님이 사용 중입니다. 읽기 모드로 열립니다."`)**
  3. `⏳ 새 업무파일 정리함`: 신규 등록 문서·도면·현장사진 OCR/시맨틱 인덱싱 대기실
  4. `🏢 팀원 권한 & S: 드라이브 연결`: 부서별 폴더 접근 권한, 랜섬웨어 서킷 브레이커(1분 내 30개 이상 삭제·변조 또는 `_000_zeye_guard.docx` 미끼 파일 훼손 시 즉시 미러링 차단), 퇴근 초절전 모드 제어

## 2. `👁️ Z-Eye 투시검색` & 탐색기 장착 `G:` 드라이브 무설정 색인 명세

### 2.1 멀티모달 1초 투시검색 엔진 (`src/services/aiEngine.ts`)
- **768차원 멀티모달 벡터 + 한국어 시각 온톨로지 + `64-bit dHash` 픽셀 뼈대:**
  - `EmbeddingGemma 2` 단일 모델로 텍스트·사진·동영상 프레임·오디오 파형(Zero-STT)을 동일한 768차원 벡터 공간에 매핑합니다.
  - 복합 명사 및 지명 질의 시 엄격한 `AND` 교집합 필터를 적용하여 일치하는 미디어가 없을 때는 거짓 결과 없이 정직하게 `0건`을 반환합니다.
- **검색 탭 포커스 규칙:**
  - 최초 검색 시 건수 배지(`🎬 동영상` · `🖼️ 사진` · `📁 문서`)를 모두 표시하되 **`🎬 동영상` 탭을 기본 오픈**하며, 이후 유저가 특정 탭을 선택한 뒤 재검색하면 **마지막 선택 탭을 그대로 유지**합니다.

### 2.2 탐색기 장착 `G:` 드라이브(`.gsheet`/`.gdoc`) 무설정 스마트 색인 & 무마스킹 ID/PW 복사 (`plugin_zeye_os.py`)
- **엔드포인트:** `GET / POST http://127.0.0.1:5199/__zcore/gdrive-smart-scan`
- **작동 메커니즘:**
  1. `Google Drive for Desktop`이 마운트한 `G:\` 드라이브 및 `%LOCALAPPDATA%\Google\DriveFS` 로컬 SQLite 메타데이터/크롬·엣지 로컬 구글 세션을 활용하여, 복잡한 OAuth 설정창 없이 `.gsheet` · `.gdoc` 바로가기 파일(`doc_id` + 로컬 캐시 본문)을 0.3초 만에 색인합니다.
  2. 파일 내부의 계정·비밀번호 정보를 찾아낼 때, 내 PC 로컬에서 본인이 직접 여는 화면이므로 **비밀번호를 `****`로 마스킹하지 않고 원문 그대로 선명하게 표시(`maskPasswordOnScreen: false`)**합니다.
  3. **아이디(ID)와 비밀번호(PW) 텍스트 바로 옆에 각각 복사 이모지(`📋`)**를 인라인으로 배치하여 클릭 한 번으로 아이디와 비밀번호를 각각 클립보드에 즉시 복사할 수 있습니다.

## 3. 전 영역 무료 무제한 TTS (`현수 & 선희` 투톱) & 단골 AI 라이브 바톤터치 명세

### 3.1 MS 신경망 무료 무제한 성우 투톱 (`universal_z_core/os_agent/merlin_tts_engine.py`)
- **성우 라인업 (유료 외부 성우 API 영구 폐기 · 일일 제한 없음 · 평생 0원):**
  - 남성 메인: **`현수` (`ko-KR-HyunsuNeural`)** — 차분하고 신뢰감 있는 만능 비서 톤
  - 여성 메인: **`선희` (`ko-KR-SunHiNeural`)** — 밝고 또렷한 아나운서 톤
- **Write-Through 영구 로컬 캐시:** 최초 1회 합성된 MP3는 `tts_cache/{sha256}.mp3`에 영구 캐싱되어 2회 차부터 `0.001초` 무지연 재생됩니다.

### 3.2 음성 검색 결과 브리핑 · 무토큰 문서 낭독 · 카톡 실채팅방 장전 (`src/services/voiceSearchAndAiBatonEngine.ts`)
1. **음성 검색 자동 브리핑:** 음성으로 검색하면 화면 결과 표시와 동시에 `현수` 또는 `선희`가 매칭 결과를 즉시 낭독합니다.
2. **무토큰(`Zero-LLM`) 문서 핵심 요약 및 키워드 포함 문장 낭독:**
   - `"요약해 줘"` 또는 `"읽어 줘"` 발화 시 유료 LLM API 호출 없이(토큰 비용 `0원`), 로컬 추출 텍스트의 첫 문단 핵심 3문장 또는 검색어 포함 문장(`±1문장`)만 0.01초 만에 뽑아 읽어줍니다.
   - 화면 배지 고지: **`"💡 AI 요약이 아닌 문서 내 검색어 포함 문장입니다 (LLM 토큰 소모 0)"`**.
3. **카카오톡 실채팅방 타겟 장전 (`POST /__zcore/senstalk/send`):**
   - `"이쁜이한테 카톡 보내줘"` 발화 시 `plugin_senstalk`의 Win32 UIA 엔진이 PC 카카오톡에서 실제 `'이쁜이'` 채팅방을 검색해 열고 입력창에 요약 텍스트/파일을 장전합니다 (유저 최종 `[전송]` 게이트 준수).
4. **3초 무응답 시 단골 AI 자동 감지 & 기본값 `제미나이(Gemini)` 라이브 음성 바톤터치 (`GET /__zcore/detect-preferred-ai`):**
   - 로컬 브라우저(Chrome/Edge/Whale/Brave) `History` DB의 최근 30일 방문 빈도를 스캔하여 유저가 가장 자주 쓰는 AI(`ChatGPT` / `Gemini` / `Claude` / `Perplexity`)를 자동 판별합니다.
   - **방문 기록이 `0건`이거나 판별 불가할 때는 무조건 `제미나이(Google Gemini — https://gemini.google.com/app?hl=ko)`를 기본값으로 열어** 라이브 음성 대화를 이어갑니다.

## 4. `🛂 Z-Eye 여권` & `[📸 사진 공유]` 5단계 일방통행 프로세스

1. **다년도·다각도 5대 슬롯 & 인물별 고유 타임라인 바구니:**
   - 인물당 `정면·선명`, `측면·미소`, `야외·노을`, `선글라스·역광`, `야간·실내` 5대 슬롯을 자동 결합하며, 연도 바구니(성인 10년 / 미성년 5년 + 미래 바구니 자동 확장)는 방이 아닌 각 인물의 최초 시드 생성 연도에 귀속됩니다.
2. **`64-bit dHash` + EXIF 해상도 검증 진짜 원본 자동 교체:**
   - 동일 구도 중복 사진 감지 시, 새로 올라온 사진에 **`EXIF 촬영 원본 메타데이터`가 살아있고 실제 픽셀 해상도(`width × height`)가 더 클 때만** 기존 댓글·좋아요를 유지한 채 고화질 원본으로 자동 교체합니다.
3. **평소 숨김 썸네일 DB(`13KB`) & `[🔄 원본 동기화]` 토글 자체 해결:**
   - 평소에는 `%LOCALAPPDATA%\Merlin\thumb_db`에 초경량 썸네일만 보관하며, Wi-Fi 및 여유 공간이 충분할 때 `[🔄 원본 동기화]`를 켜면 지정한 내 기기 폴더에 원본을 복제하여 방장 PC 호출 없이 내 기기에서 0.01초 만에 자체 열람합니다.
4. **탈퇴(`자퇴` · `강퇴` 동일) 시 데이터 격리 소각 및 내 개인 여권 100% 보존:**
   - 공유방 탈퇴 시 해당 공유방의 숨김 썸네일 DB · 공유방 검색 인덱스 · 타 멤버 여권 목록만 0.1초 만에 자동 삭제되며, **본인의 `Z-Eye 여권` 시드 및 `내 기기` 개인 인덱스는 100% 그대로 보존**됩니다.
