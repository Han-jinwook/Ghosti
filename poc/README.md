# SaySee PoC — EmbeddingGemma 2 성능 검증 (D-15)

UI 개발 전에 **PC와 모바일에서 EmbeddingGemma 2(텍스트+비전)로 실제 사진 300장을 색인**해 실측 성능을 확인하는 도구.

## 실행

```powershell
cd d:\SaySee\poc
npm install
npm run dev
```

터미널에 주소 2개가 표시됨:
- `https://localhost:5199/` → **PC 측정용**
- `https://192.168.x.x:5199/` (Network) → **폰 측정용** (같은 WiFi)

> 자체 서명 인증서라 처음 접속할 때 "안전하지 않음" 경고가 뜸 → **고급 → 계속 진행**. 모바일 WebGPU는 HTTPS에서만 동작해서 필요한 절차임.

## 측정 순서

1. **① 기기 환경**에서 WebGPU 사용 가능 여부를 확인
2. **② 설정**은 기본값(q4 / 예산 280 / 768차원)으로 먼저 1회 측정
3. **③ 사진 선택**
   - PC: `📁 폴더 선택` 또는 `🖥️ PC의 test_photos 사용`
   - 폰: `🖼️ 사진 선택`(실제 온보딩과 같은 방식) 또는 `🖥️ PC의 test_photos 사용`(사진을 폰에 옮기지 않고 LAN으로 받음)
4. **④ 측정 시작** → 완료 후 결과가 자동으로 `poc/results/*.json`에 저장됨
5. **⑤ 검색**에서 한국어/영어 질의로 결과를 육안 확인 → `⚡ 프리셋 질의 일괄 측정`

첫 실행은 모델 다운로드(q4 기준 약 284MB)가 포함됨. 두 번째부터는 브라우저 캐시를 사용함.

## 측정 항목

| 항목 | 설명 |
|---|---|
| 모델 로드 | 텍스트+비전 로드 시간, 네트워크 수신량 |
| 워밍업 | 첫 추론(셰이더 컴파일) 시간. 색인 시간과 분리해서 측정 |
| 장당 디코딩 / 추론 | p50 / p95 |
| 300장 환산 | D-08 온보딩 대기 시간 판단 기준 |
| 비전 해제 → 텍스트 재로드 | D-08 시뮬레이션 |
| 질의 임베딩 / 검색 지연 | 목표 100ms 이하 |
| NaN 벡터 | fp16 / q4f16 정밀도 이상 여부 |
| WebGPU 한도 | `maxStorageBufferBindingSize` 등 |
| JS 힙 | Chrome 계열만 제공. GPU 메모리는 브라우저에서 측정할 수 없음 |
