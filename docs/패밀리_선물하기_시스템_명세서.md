# 🎁 멀린 패밀리 통합 '선물하기(HubGiftBox)' 시스템 공식 명세서

- **문서 버전**: v1.0
- **제정 일자**: 2026-10-19
- **핵심 철학**: *"쿠폰·티켓이라는 헷갈리는 말을 버리고 오직 **'선물'**로 통일한다. 우리의 모든 선물은 곧 우리 앱 내의 상품이다."*
- **적용 대상**: 멀린 패밀리 OS 허브, 2호 제트아이(Z-Eye), 1호 썬드리머 및 전 패밀리 앱

---

## 🏛️ 1. 생태계 4대 핵심 원칙 (Constitution)

1. **용어 단일화 ('쿠폰/티켓' 폐지 ➔ '선물'로 100% 통일)**:
   - 사용자에게 혼란을 주는 '쿠폰', '티켓', '바우처', '교환권' 등의 용어를 전면 폐기합니다.
   - 주는 것도 **`선물`**, 받는 것도 **`선물`**, 보관함도 **`내 선물함 (`받은 선물` / `보낸 선물`)`**로 통일합니다.
   - 모든 선물은 외부 기프티콘이 아닌 **우리 패밀리 앱 내의 실제 디지털 상품(예: AI 설정몬스터, AI 클린몬스터, 패밀리 라운지 1개월, 패밀리 코인)**입니다.
2. **전 패밀리 앱 '광고(AdSense) 전면 폐지' (Zero-Ads Clean UI)**:
   - 좁은 모바일 화면을 가려 스트레스를 유발하는 배너 광고를 모든 앱에서 영구 퇴출합니다.
   - 완전 무료로 풀거나, 100코인(100원)~수천 원대의 합리적인 소액 상품 및 선물하기로만 쾌적하게 운영합니다.
3. **썬드리머 포인트(P) 분리 원칙**:
   - 썬드리머 1호 앱의 오프라인 기기/소모품 전용 `포인트(P)`는 디지털 코인(C)과 절대 섞지 않습니다.
   - 대신 썬드리머 회원들에게 제트아이 등 디지털 앱의 상품을 **`특별 선물`**로 쏴주는 방식으로 원가 0원의 교차 프로모션을 전개합니다.
4. **푸시 알림(1순위) + 이메일(2순위) 전달 체계**:
   - 번거로운 카톡 공유 대신, 선물하기 버튼을 누르는 즉시 수신자의 스마트폰으로 **네이티브 푸시 알림(`🔔 띠링! 선물이 도착했습니다`)**을 1순위로 쏘고, 이메일을 보조 알림으로 발송합니다.

## 🎨 2. 선물하기 UI/UX 디테일 설계

### 2-1. 상품 화면: 모든 상품 옆 `[🎁 선물하기]` 버튼 직결
미리 사서 쟁여두는 복잡한 단계 없이, 모든 앱의 요금제/상품 카드 우측에 `[바로 쓰기]`와 나란히 **`[🎁 선물하기]`** 버튼을 배치합니다.

```
┌──────────────────────────────────────────────────────────┐
│ 🛠️ AI 설정몬스터 (1회)                       100 코인    │
│ 복잡한 폰/앱 설정을 AI 음성으로 1초 만에 해결             │
│                            [ 바로 쓰기 ]  [ 🎁 선물하기 ] │
├──────────────────────────────────────────────────────────┤
│ 🧹 AI 클린몬스터 (1회)                     1,900 코인    │
│ 중복 사진·유령 파일 종합검진 및 원클릭 정리               │
│                            [ 바로 쓰기 ]  [ 🎁 선물하기 ] │
├──────────────────────────────────────────────────────────┤
│ 🏠 패밀리 라운지 (1개월)                   5,900 코인    │
│ 우리집·본가·처가 사진 무제한 프라이빗 공유 방             │
│                            [ 방 만들기 ]  [ 🎁 선물하기 ] │
└──────────────────────────────────────────────────────────┘
```

### 2-2. 누구에게 보낼까? (타이핑 없는 1초 수신자 선택 모달)
`[🎁 선물하기]` 클릭 시 뜨는 미니 모달은 이메일을 일일이 칠 필요 없이 3가지 탭으로 즉시 선택합니다:
1. **`[👨‍👩‍👧‍👦 내 라운지 멤버]`**: 현재 같은 방(우리집·본가·처가·클럽)에 있는 멤버 알약(`[👑 큰아들]`, `[막내딸]`, `[장모님]`)을 **터치로 체크만 하면 끝!** (전체 선택 가능)
2. **`[🤝 최근 교류 지인]`**: 내가 초대했거나 선물을 주고받았던 지인 리스트 1클릭 선택.
3. **`[✉️ 새 지인 (이메일)]`**: 아직 방에 없는 외부 지인에게 보낼 때만 이메일 입력 (푸시 + 이메일 발송).

---

### 2-3. 프로필 내 `[🎁 내 선물함]` (초심플 2탭 구조)
프로필(내 정보)에서 `[🎁 내 선물함]`을 열면 **오직 `받은 선물`과 `보낸 선물` 딱 2개의 탭**만 존재합니다.

```
┌────────────────────────────────────────────────────────────┐
│  🎁 내 선물함                                   [✕ 닫기]   │
├────────────────────────────────────────────────────────────┤
│         [ 📥 받은 선물 (4) ]         [ 📤 보낸 선물 ]       │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  1️⃣ [연 구독 감사 선물] 제트아이에서 도착!                   │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 🏠 패밀리 라운지 1개월 (남은 선물: 3개)               │  │
│  │ 💬 "연 구독 감사 선물입니다! 지인들에게 나눠주세요"   │  │
│  │                          [ 🎁 지인에게 선물하기 > ]  │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  2️⃣ [👑 방장의 특별선물] 멀린 방장님이 보냄                │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 🛠️ AI 설정몬스터 (1회)                               │  │
│  │ 💬 "우리 가족방 합류 환영 선물입니다^^"               │  │
│  │                                  [ ⚡ 선물 쓰기 ]    │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  ── 사용 완료된 선물 ──────────────────────────────────    │
│  • 🧹 AI 클린몬스터 (보낸이: 큰아들)           [사용완료]   │
└────────────────────────────────────────────────────────────┘
```

#### 탭 1: `📥 받은 선물`
- 내가 누군가(방장, 가족, 친구, 또는 본사 이벤트)에게 받은 모든 선물이 이곳에 모입니다.
- **내가 직접 쓸 선물**: **`[⚡ 선물 쓰기]`** 버튼을 누르면 즉시 해당 기능이 작동하거나 내 지갑/라운지에 적용됩니다.
- **나눠줄 선물 (연 구독 방장 특전 등)**: **`[🎁 지인에게 선물하기 (3개 남음)]`** 버튼을 눌러 지인에게 1개씩 바로 전달할 수 있습니다.

#### 탭 2: `📤 보낸 선물`
- 내가 가족이나 지인에게 보낸 선물 리스트와 상대방의 수령 상태(`🟢 수령완료` / `🟡 미수령 대기중`)가 표시됩니다.
- 아직 안 열어본 지인에게는 **`[🔔 푸시 알림 다시 보내기]`** 또는 **`[선물 취소(회수)]`**가 가능합니다.

## 👑 3. 연 구독 '방장'의 2대 자동 선물 시나리오 (제트아이 킬러 바이럴)

방장이 패밀리 라운지 **연 구독권(59,000원 / 89,000원)**으로 방을 개설하면 두 가지 선물이 자동 작동합니다:

1. **시나리오 A: 1주일 내 가입 멤버 전원에게 `'👑 방장의 특별선물'` 자동 발송**
   - 라운지 개설 후 **7일 이내에 방에 합류하는 모든 멤버 전원**에게 시스템이 방장 이름으로 **`AI 설정몬스터 (100원 상당) 선물`**을 자동 지급합니다.
   - 멤버 폰에 즉시 푸시 알림 도착: *"🔔 [👑 방장의 특별선물] 멀린 방장님이 환영 선물로 'AI 설정몬스터'를 보내셨습니다!"*
   - 방장은 가만히 있어도 가족/모임원들에게 센스 있는 방장으로 대접받으며, 멤버들은 공짜 선물을 써보며 앱의 핵심 기능에 즉시 온보딩됩니다.
2. **시나리오 B: 방장에게 `'패밀리 라운지 1개월 선물 × 3개'` 지급**
   - 연 구독 결제 즉시 방장의 `[📥 받은 선물]`함에 **패밀리 라운지 1개월 선물 3개**가 들어옵니다.
   - 방장은 `[🎁 지인에게 선물하기]`를 눌러 본가, 처가, 친구에게 1개월 무료 방 개설 선물을 쏴주어 새로운 패밀리 라운지가 연쇄 개설되도록 유도합니다.

## 🗄️ 4. 허브 DB 스키마 설계 (`family_gifts`)

허브 DB(`wwopcuitvjldixkyzpzi`)에 추가될 단일 선물 원장 테이블 규격입니다:

| 컬럼명 | 타입 | 설명 |
| :--- | :--- | :--- |
| `id` | `uuid` (PK) | 선물 고유 ID |
| `app_id` | `text` | 상품 소속 앱 (`saysee`, `aggrofilter`, `hub_coin` 등) |
| `product_code` | `text` | 상품 코드 (`SAYSEE_SET_1`, `SAYSEE_CLEAN_1`, `SAYSEE_FAMILY_1M`, `COIN_1000` 등) |
| `product_name` | `text` | 화면 표시용 선물 이름 (예: `🛠️ AI 설정몬스터 (1회)`, `🏠 패밀리 라운지 1개월`) |
| `coin_value` | `bigint` | 액면 코인 가치 (예: `100`, `1900`, `5900`) |
| `quantity` | `integer` | 남은 수량 (기본 `1`, 방장 연 구독 보너스는 `3`) |
| `sender_id` | `uuid` | 보낸 회원 UUID (시스템 자동 지급 시 `null` 또는 시스템 ID) |
| `sender_label` | `text` | 보낸이 표시명 (예: `👑 멀린 방장님`, `제트아이 본사`) |
| `receiver_id` | `uuid` | 받는 회원 UUID (가입 회원인 경우 즉시 매핑) |
| `receiver_email` | `text` | 받는 회원 이메일 (비회원 발송 시 이메일 기준 대기 후 가입 시 자동 귀속) |
| `room_id` | `text` | 라운지 연동 선물인 경우 방 ID (선택) |
| `message` | `text` | 선물 메시지 (예: `"우리 가족방 합류 환영 선물입니다^^"`) |
| `can_regift` | `boolean` | 타인에게 재선물(양도) 가능 여부 (방장 1개월권 3개 보너스는 `true`) |
| `status` | `text` | `'UNCLAIMED'`(미수령) \| `'AVAILABLE'`(수령/사용가능) \| `'USED'`(사용완료) \| `'CANCELED'`(회수됨) |
| `created_at` | `timestamptz` | 발송 일시 |
| `used_at` | `timestamptz` | 사용 완료 일시 |
