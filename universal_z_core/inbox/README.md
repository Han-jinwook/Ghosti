1. **복사 배포 및 임의 개조 금지**:

2. **투함 파일명 양식**:
   - `D:\Z-Eye\universal_z_core\inbox\[프로젝트명]_[YYYYMMDD]_[이슈요약].md`
   - 예: `CafeBreaker_20261022_스마트에디터_이미지드롭_요청.md`
3. **필수 기재 항목**:

## ⚖️ 2. Z-Eye 마스터 에이전트의 2단계 심사 및 보고 원칙

`Z-Eye` 에이전트는 본 `inbox\`에 새 의견이 접수되면 무조건 병합하지 않고, 반드시 아래 **2가지 기준**으로 먼저 심사하여 멀린님께 보고합니다:

2. **🚨 스토어 심사 패스 리스크 검열 (최우선 절대 기준)**:
