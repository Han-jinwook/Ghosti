## 🎯 핵심 결단 5대 요약

1. **`[💻 내 기기]` 혼자 쓸 땐 언제나 100% 무료(0원) & 로그인 즉시 상시 무료 실행:**
   - 혼자 쓰는 개인 영역은 유료 구독이나 체험 제한을 두지 않습니다.
   - **`[내 기기]`**는 혼자 쓸 때(PC 1대 + 모바일 1대) **기간·횟수 제한 없이 언제나 100% 무료(0원)**이며, 이메일 로그인 즉시 **`클린몬스터` 진단 및 `1초 투시검색`**이 실행됩니다.

   - 상위 메뉴는 **`[💻 내 기기]`**, **`[📸 사진 공유]`**(패밀리 / 동호회·동창회), **`[💼 업무 공유]`**(1인 멀티PC / SOHO / 소기업 / 중소기업 `S:` 드라이브) 3대 메뉴로 완벽히 일원화합니다.

4. **양방향 교차 무료 구독권 선물 특전 (연간/마스터권 결제 시):**
