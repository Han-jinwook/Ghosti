## 1. 언어별 무버튼 자동 성형 핵심 무기 (1/9번 기능 현지화)
`귀신Key`의 대표 무버튼 자동 성형 기능(1/9)은 OS/브라우저 언어(`navigator.language`)에 따라 각 언어권 사무직의 가장 큰 입력 통증에 맞춰 자동 분기됩니다.

| 언어권 | 브랜드 노출명 | 무버튼 자동 성형 핵심 무기 | 실무 통증 해결 예시 |
| :---: | :--- | :--- | :--- |
| **`ko` (한국어)** | **귀신Key** | **한영 오타 자동 교정** | 한영키 실수 영타(`dkssudgktpdy`)를 무버튼으로 한글(`안녕하세요`) 자동 전환 *(이메일·URL·영문 약어 자동 보호)* |
| **`en` (영어권)** | **GhostKey** | **`CapsLock` 대소문자 역전 자동 복구** | `CapsLock`이 눌린 채 입력된 `hELLO wORLD` / `tHANKS`를 무버튼으로 `Hello World` / `Thanks`로 즉시 복구 *(PDF/AI/API 약어 보호)* |
| **`ja` (일본어권)** | **GhostKey** | **전각 ↔ 반각 1초 자동 통일** | 견적서·웹 폼 입력 시 혼재되는 전각 영숫자·하이픈·전각 스페이스(`０１０－１２３４`)를 깔끔한 반각(`010-1234`)으로 자동 통일 |

## 2. 공통 글로벌 8대 기능 (`ko` · `en` · `ja` 동일 제공)
언어별 무버튼 자동 성형(1/9) 외 나머지 8가지 핵심 기능은 전 언어권에 동일하게 제공됩니다:
- `1→2→3` 순차 붙여넣기 (`Ctrl+0` → `Ctrl+V` 연타)
- `[1]` PDF 끊어진 줄바꿈 · 서식 세탁 (`Ctrl+0` → `1`)
- `[2]` 스샷 · 300DPI PDF 변환 (`Ctrl+0` → `2`)
- `[3]` 다중 복사 1초 합본 (`Ctrl+0` → `3`)
- `[4]` 번호 · 일정 하이픈 성형 (`Ctrl+0` → `4`)
- `[5]` 현재 창 최상단 고정 (`Ctrl+0` → `5`)
- `F1~F6` 개인 상용구 (`Ctrl+0` → `F1~F6`) / `F7~F12` 팀 공유 상용구(업무 공유)
- 로컬 7일 클립보드 검색 (`Ctrl+0` → 검색)
