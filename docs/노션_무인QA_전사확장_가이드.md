## 🚀 [Step 1] 노션에서 새 알바생용 보드 만들기 (멀린님 30초 작업)

3. 새 알바생에게는 이 노션 페이지 링크를 주고, 멀린님은 **주소창(URL) 가운데 있는 32자리 영어+숫자 ID**를 복사합니다.

## 💬 [Step 2] 다른 PC의 에이전트에게 그대로 던져줄 메시지 (복붙용)

다른 컴퓨터의 안티그래비티 채팅창에 아래 상자 내용을 복사해서 붙여넣고, **맨 위 2줄(`NOTION_TOKEN`, `NOTION_DATABASE_ID`)만 채워서 엔터**를 치시면 그 PC 에이전트가 파일 생성부터 세팅까지 혼자 다 끝냅니다!

```text
너는 나와 함께 IDE 채팅창에서 바이브 코딩으로 앱을 고도화하고, 다른 자리의 해나라님가 노션 칸반 보드에 등록한 버그와 요청을 무인으로 처리하는 개발 파트너 에이전트야.
[상황에 대한 이해]: 지금 이 IDE 채팅창 앞에는 나(멀린)와 네가 직접 대화하며 일하고 있고, 노션은 알바생과의 소통 창구다. 따라서 노션에 올라온 간단한 버그나 명백한 오류는 바로 고쳐서 노션에 반영하면 되지만, 기존 기획과 충돌하거나 중요한 결정이 필요한 요청이 올라왔을 때는 노션에 묻지 말고 **지금 이 IDE 채팅창에서 나에게 바로 질문하고 내가 승인하면 진행**해라.
절대 다른 드라이브나 다른 프로젝트 폴더를 뒤지지 말고, 오직 현재 프로젝트 폴더 안에서만 아래 작업을 즉시 수행해라.

[1. 연동 정보 (.env.local 파일에 바로 저장해라)]
- NOTION_TOKEN=여기에_기존_ntn_토큰_그대로_붙여넣기

  (* 1번 '테스트 미션'은 알바생에게 테스트할 체크리스트를 출제하는 칸, 2번 '테스트 중'은 알바생이 현재 테스트 진행 중인 칸, 3번 '발견된 버그'는 알바생이 각 체크항목 바로 아래에 붉은색 글씨(red)로 코멘트를 적고 넘기는 칸이며, 에이전트가 수정을 마치면 '재테스트 대기'로 이동시킨다.)

[2. 현재 프로젝트 루트에 `notion_qa.py`를 생성해라 (나한테 터미널 명령어 치라고 하지 말고 네가 직접 실행할 것)]

- `python notion_qa.py mission "<미션 제목>" "<체크리스트>"`: 새 기능/화면 작업이 끝났을 때 알바생이 순서대로 눌러보며 확인할 수 있도록 '테스트 미션' 칸에 체크리스트(☐) 카드를 자동 생성한다.
- `python notion_qa.py fetch`: 상태가 '버그/요청'(또는 기존 '발견된 버그')인 카드의 ID, 제목, 본문 블록 내용을 출력한다.
- `python notion_qa.py complete <page_id> "<guide_text>"`:
  1) 해당 카드 상태를 '재테스트 대기'로 변경한다.
  2) 카드 본문 맨 아래에 구분선과 함께 `"[AI 수정 완료 및 재테스트 지시]\n" + guide_text` 블록을 추가한다.
  3) 완료 직후 남은 '버그/요청' 카드가 있으면 자동으로 조회해 "이어서 2번 카드도 처리할까요?"라고 나에게 브리핑한다.
- `python notion_qa.py watch`: 평상시 AI 토큰 소모 0으로 파이썬이 15초마다 노션 '버그/요청' 컬럼만 감시하다가, 새 카드가 등록되는 순간에만 출력 후 종료(Exit 0)하여 너(AI)를 깨우게 해라.

[3. 절대 수칙 (`AGENTS.md`에도 반드시 박아둘 것)]
- 나한테 스크립트 코드를 화면에 길게 뿌리거나 터미널에 뭐 치라고 시키지 말고, 네가 직접 `.env.local`과 `notion_qa.py`를 만들고 실행해라.
- 알바생이 '버그/요청'에 올린 카드 중 단순 버그는 즉시 고치고, 기획 충돌이나 중요 결정이 필요한 건은 이 IDE 채팅창에서 나에게 먼저 물어보고 승인받은 뒤 진행해라.
- 해나라님은 비개발자이시므로, 노션 카드에 미션이나 `[AI 수정 완료 및 재테스트 지시]`를 적을 때는 개발 전문용어(비동기, 캐시, F12 콘솔, 영문 컴포넌트명 등)를 절대 쓰지 말고, 일반인이 화면 어디를 눌러 무엇을 확인하면 되는지 친절하고 쉬운 일상어로만 작성해라.

지금 바로 `.env.local`과 `notion_qa.py`, `AGENTS.md` 세팅을 끝내고, 노션 보드 연동이 잘 되는지 테스트해서 간단히 보고해!
```

> ⚠️ **도입 배경 및 목적(Why):**
> 에이전트가 테스트 미션 카드를 대충 추상적으로 적어 놓으면, 멀린님이 직접 알바생 자리 옆에 가서 화면을 보며 시시콜콜 하나하나 말로 설명해 주어야 하므로 노션 무인 QA 솔루션의 존재 이유가 사라지고 이중일이 됩니다. 따라서 모든 미션 카드 작성 및 재정리 시 아래 **3대 철칙**을 예외 없이 준수합니다.

### 1. 기체크(`☑`) 항목 100% 보존 원칙
- 기존 미션 카드를 수정·재정리할 때는 노션 API로 해당 카드의 기존 블록(`to_do`)을 먼저 조회하여, **해나라님가 이미 체크 완료한 항목(`☑`, `checked: true`)은 문구와 체크 상태를 그대로 보존**합니다.
- 아직 체크하지 않은 항목(`☐`, `checked: false`)이나 최신 UI 개편으로 바뀐 부분만 아래 2·3번 철칙에 맞춰 디테일하게 재작성·추가합니다.

### 2. 연관 기능 · 연쇄 UI/UX 변화 동시 검증 의무 (항시 탑재)
- 특정 기능이 정상 작동하면 **그로 인해 다른 기능이나 다른 영역의 UI/UX에 어떤 연쇄 변화가 일어나는지**까지 반드시 함께 체크항목에 넣어야 합니다.
- **필수 포함 연쇄 체크 예시:**
  1. **클린몬스터 정리 및 1초 복원 연쇄 반응:** 사진 1장 또는 일괄 정리 버튼을 눌렀을 때 단순히 사진만 사라지는지 보는 것이 아니라, **① 상단 제목의 `정리 후보 N장` 숫자와 `탐색 반응 속도 N점 → +N% 향상` 수치가 즉시 바뀌는지, ② 4대 카테고리 탭의 장수가 줄어드는지, ③ 맨 아래 `🗑️ OS 기본 [휴지통] 이동 내역 (N건)` 숫자가 올라가는지, ④ 휴지통 토글을 펼쳐 `[↩️ 1초 복원]`을 눌렀을 때 원래 카테고리 목록과 상단 숫자가 원래대로 복구되는지**를 한 흐름으로 묶어 검증하게 합니다.
  2. **노션 스타일 동적 토글 & 선택 배지 연동:** `💬 기기 종합검진 & 대화형 맞춤 정리` 토글 헤더를 눌러 접었다 펼쳤을 때 부드럽게 여닫히는지, 그리고 내부 3개 카드(`모바일 바탕화면`, `PC 바탕화면`, `상주 보안모듈`)에서 버튼을 각각 선택할 때마다 **토글 제목 줄의 상태 배지가 `✓ 1/3 항목 선택됨` ➔ `✓ 2/3 항목 선택됨` ➔ `✓ 3/3 항목 선택됨`으로 실시간 변화하는지** 함께 체크하게 합니다.
  3. **업무 공유 문서 잠금 & 좌·우 화면 연동:** 잠금 표시(`🔒 박과장 수정 중`)된 문서를 클릭했을 때 **① 오른쪽에 `📄 문서 내용 미리보기` 창이 열리면서 왼쪽 목록 폭이 자동으로 줄어드는지, ② 오른쪽 창 안에 `🔒 현재 [박과장]님이 사용 중입니다. 읽기 모드로 열립니다.` 안내와 `[👁️ 읽기 모드로 열기]` 버튼이 뜨는지, ③ 우측의 `[잠금 시뮬레이션 해제]` 버튼을 누르는 즉시 오른쪽 창이 `🔓 현재 사용 중인 팀원이 없습니다 — 바로 편집 가능`으로 바뀌고 동시에 왼쪽 파일 목록의 배지도 `🔓 수정 가능`으로 함께 바뀌는지** 검증하게 합니다.

### 3. 구체적 숫자 · 입력값 · 기대 결과값 100% 지정 의무
- *"검색해 보세요"*, *"스티커를 붙여보세요"*, *"진단 버튼을 눌러보세요"* 같은 모호한 표현을 금지하고, **알바생이 그대로 따라 치고 눈으로 숫자를 대조할 수 있도록 구체적인 숫자와 텍스트를 지정**합니다.
- **구체적 수치 지정 예시:**
  - `내 기기 ➔ 🧹 클린몬스터 진단`에서 `[🧹 클린몬스터 진단 시작]` 클릭 시: 결과 카드 **`영상 3개 해부 완료` · `사진 100장 분석 완료` · `문서 15건 색인 완료`**가 펼쳐지는지, 이어서 `[🗑️ ① 샘플 정리 눌러보기]` ➔ `[✓ ① 휴지통 이동됨]`, `[↩️ ② 1초 되돌리기]` ➔ `[✓ ② 1초 복원 완료!]`로 바뀌고 왼쪽 메뉴 `🩺 귀신같이 클린몬스터` 옆 숫자가 줄었다가 원래대로 돌아오는지 명시합니다.
  - `패밀리 ➔ 새 사진 정리함`의 옛날 사진 스티커 테스트 시: `① 첫 사진 키워드 입력` 칸에 **연도 `1992`, 장소 `경주 수학여행`, 계절 `가을`**을 입력하고 `[+ 스틱(Chip) 자동 생성]`을 눌렀을 때 `🏷️ 1992` · `🏷️ 경주 수학여행` · `🏷️ 1992년 가을` 스티커가 생기는지, 그리고 노란 `❓ 언제/어디인가요?` 표시가 붙은 **3번째 사진 카드**의 `[👆 [🏷️ 1992년 가을] 1초 부착]`을 눌렀을 때 그 표시가 `🗓️ 1992년 가을`로 바뀌는지 구체적으로 지정합니다.
  - `업무 공유 ➔ 문서·도면 본문 검색` 테스트 시: 먼저 목록 위 `문서 및 미디어 (N건)` 숫자를 메모하게 한 뒤, 빠른 검색어 **`철거 단가 4,850,000원`**을 클릭했을 때 **`(1건)`**으로 좁혀지고 오른쪽 미리보기 표에 `4,850,000원`이 보이는지, `[✕ 지우기]` 후 메모한 숫자로 복귀하는지 명시합니다 (실제 S: 드라이브 파일이 섞여 전체 건수는 PC마다 다름).

## 🔴 [핵심 항시 수칙 8] 항목별 붉은색 인라인 코멘트 · 하단 상투문 폐지 · UI/UX 버그 무허락 즉시 수정·배포 3대 표준

> 1. 기존에는 해나라님가 카드의 맨 하단에 코멘트를 모아서 적다 보니, 어느 체크리스트(`☐`) 항목에 대한 피드백인지 위아래를 번갈아 대조해야 하는 불편이 있었습니다. 이제부터 알바생은 **각 체크리스트(`☐`) 항목 바로 아래에 붉은색 글씨(`color: "red"`)로 직접 코멘트**를 남깁니다.

### 1. 항목 바로 아래 '붉은색 글씨(`red`)' 인라인 코멘트 감지 원칙
- 알바생은 테스트 중 이상하거나 개선이 필요한 항목이 있으면, 카드 맨 아래로 내려가지 않고 **해당 `☐` 체크항목 바로 아랫줄(또는 하위 들여쓰기 블록)에 붉은색 글씨로 코멘트와 캡처 이미지를 작성**합니다.
- 모든 프로젝트의 `notion_qa.py`는 본문 블록을 파싱할 때:
  1. 블록 자체 색상(`block.color`) 또는 `rich_text` 내부의 `annotations.color`에 `"red"`가 포함되어 있으면 **`🔴 [해나라님 붉은색 코멘트]`**로 자동 태깅하여 에이전트가 단 1건도 놓치지 않고 식별하게 합니다.
  2. `to_do` 항목 내부에 들여쓰기(`has_children: true`)된 하위 블록까지 재귀 조회(`_format_blocks_recursive`)하여 항목별 코멘트와 첨부 스크린샷을 100% 읽어옵니다.

### 2. 미션 카드 하단 고정 안내 텍스트 전면 폐지 및 삭제
- `notion_qa.py`의 `create_mission()`에서 기존에 자동 삽입하던 하단 문구(`✅ 모두 잘 작동하면: 이 카드를 [완료] 칸으로 옮겨주세요! 🚨 안 되거나 어색한 부분이 있으면: 이 글 맨 아래에 어떤 점이 이상한지...`)를 완전히 제거합니다.
- 이미 보드에 생성되어 있는 카드들에 남아 있는 해당 하단 문구 블록도 즉시 삭제하여 카드를 깔끔하게 유지합니다.

### 3. 간단한 UI/UX 버그 및 명백한 오류 — '멀린님 무허락 즉시 수정·배포·노션 반영' 철칙
- **즉시 직행 대상 (무허락 자율 완결)**:
