## 0. 글로벌 공식 브랜드 체계 확정 (`귀신같이 Z-Eye`) & 5대 무기 라인업

- **공식 브랜드명:** **`귀신같이 (Z-Eye / Zeye)`**
  - **마케팅 핵심 브랜드 서사 (`Zero-Cloud` + `A to Z`):** **`"Zero-Cloud (클라우드 월세 0원, 해킹 위험 0%)"`** + **`"A to Z (내 기기의 모든 파일과 문제를 처음부터 끝까지 꿰뚫어 보는 눈)"`**으로 풀어내어 브랜드 스토리텔링을 완성합니다.
  - **초월적 상징성 (Ultimate Z + Zero-Cloud):** 알파벳의 끝판왕 `Z(Ultimate)`와 `Zero-Cloud(클라우드 비용 Zero, 서버 유출 Zero)`의 앞 글자 `Z`, 만물을 꿰뚫어 보는 눈(`Eye`)을 결합. 서구권의 `Xen-(제노포비아)` 부정적 어감을 원천 배제하고 국내외 산업용 X-ray·안과 AI·기존 B2B 앱과의 상표권/SEO 충돌을 단번에 해결.
  - **글로벌 발음 유연성:** 한국·일본·유럽에서는 묵직한 어감의 **`귀신같이(Ghosti)`**, 미국 본토에서는 직관적인 **`지아이(Z-Eye)`**로 소통.
- **핵심 슬로건:** **`“The Ultimate All-Seeing AI & Zero-Cloud Lounge”`** *(만물을 꿰뚫어 보는 궁극의 AI 투시 엔진 & 무클라우드 시크릿 라운지)*
- **5대 무기 라인업:**
  1. **👁️ Z-Eye 투시검색:** 동영상 1초 구간·문서 본문·얼굴을 꿰뚫어 보는 최종 진화형 현미안 엔진
  2. **🛂 귀신같이 여권 (Face Passport):** 이메일 계정에 귀속되어 어느 방에 가든 1초 만에 자동 연동·진화하는 만국공통 안면 시드
  3. **🔒 Z-Eye 라운지:** `💻 내 기기` / `📸 사진 공유(패밀리·동호회·동창회)` / `💼 업무 공유(S: 드라이브)`
  4. **🩺 Z-Eye 클린몬스터:** PC·폰 속 숨은 쓰레기와 유령 프로세스를 투시 검진하는 Z몬스터(클린몬스터·설정몬스터) (`OS 기본 [휴지통]` 직행 + `[↩️ 1초 실행 취소(Undo)]`)
  5. **🛠️ Z-Eye 설정몬스터:** 복잡한 기기 설정을 AI 음성으로 1:1 안내하고 오프라인 서버 릴레이를 해결하는 해결사

### 1.3 노션(Notion) 스타일 좌측 접이식 사이드바 & 백지 도화지(Zen Canvas) UI/UX 아키텍처 (`DesktopDashboard.tsx`, `VoiceHeroStage.tsx`, `LoungeView.tsx`, `FaceMemberRegistryModal.tsx`)

   - 상단 헤더는 초슬림 1줄로 압축되어 좌측에는 노션 스타일 경로 브레드크럼(`사진 공유 (패밀리) / 우리집 / 앨범`)이, 우측 끝에는 멀린 패밀리 앱 공통 불변 앵커(**`[👑 문패] [🛠️ 설정몬스터] [🪙 크레딧] [☀️/🌙 테마 토글]`**)가 동일한 위치에 고정됩니다.
   - 모바일(`360px` 이상 `< lg`)에서는 상단 1줄에 3대 핵심 메뉴 단축 알약(`내 기기 / 패밀리 공유 / 동호·동창회 / 업무 공유(S:)`)을 노출하고, 좌상단 `☰` 버튼 터치 시 전체 사이드바 드로어가 슬라이드 오픈됩니다.

3. **1줄 노션 콜아웃(`Callout`) 접기 & 업무 공유 (S: 드라이브) 우측 '사이드 피크(`Side Peek`)' 드로어:**

## 2. 코어 검색 엔진 & 검색 탭 UX 규칙 (`vite.config.ts`, `aiEngine.ts`, `useZ-EyeStore.ts`, `VoiceHeroStage.tsx`)

### 2.1 첫 검색 시 '🎬 동영상' 기본 노출 & 재검색 시 '마지막 선택 탭 유지' (`useZ-EyeStore.ts`)
1. **첫 검색 시 임팩트 중심 자동 포커스 (`!hasExecutedUserSearch && !hasUserSelectedSearchTab`):**
   - 사용자가 처음 검색어를 입력하면 3개 탭에 각각의 검색 결과 숫자를 배지로 동시에 표시하되(`🎬 동영상 (2)` · `🖼️ 사진 (7)` · `📁 문서 (1)`), 가장 시각적 임팩트가 큰 **`🎬 동영상` 탭을 기본(Default)으로 오픈**하여 타임라인 구간 점프 재생의 기술력을 즉시 체감하게 합니다.
2. **탭 수동 선택 후 재검색 시 마지막 탭 유지 (`hasUserSelectedSearchTab === true`):**
   - 사용자가 특정 탭(예: `🖼️ 사진` 또는 `📁 문서`)을 클릭해 열람하다가 새로운 검색어로 다시 검색하면, 각 탭의 결과 건수 배지는 실시간으로 업데이트하되 **사용자가 마지막으로 선택했던 탭이 그대로 열린 상태로 유지**됩니다.

### 2.2 검색 파이프라인 구조 (768차원 벡터 엑셀 + 온톨로지/지명 브레이크 하이브리드)
1. **한국어 토크나이저 및 조사/어미 분리 (`stripKoParticle`):**
   - `바닷가`, `창가`, `물가`, `휴가`, `아이`, `어린이`, `고양이`, `멍멍이`, `물놀이`, `목걸이`, `귀걸이`, `종로`, `을지로`, `다리`, `나무다리`, `선풍기`, `비행기` 등 끝글자가 조사와 겹치는 명사(`KEEP_NOUNS`)를 보호한 뒤 한국어 조사를 제거하여 어근 토큰을 추출합니다.
2. **동영상 전 구간 타임라인 엄격 프레임 매칭 (`searchVideoSceneItems`):**
   - 최신 동영상 3개(`20240719_105706.mp4`, `20240720_134808.mp4`, `20240722_052422.mp4`)의 **전 구간(`00:00`~끝, 총 20개 타임라인 프레임)**과 대조하여, ① 실제 타임라인 프레임 적중, ② 필수 핵심 토큰 충족, ③ 1순위 대비 최소 점수 임계치(`totalScore >= topScore * 0.55`) 3중 브레이크를 통과한 정답 영상만 노출합니다.
   - 포착된 카드는 `<video src="...#t=matchedSeekSec">` 프리뷰와 HTTP `206 Partial Content` Byte-Range 스트리밍을 통해 클릭 즉시 해당 초(Sec)부터 재생됩니다.

## 3. 만국공통 '귀신같이 여권(Z-Eye Face Passport)' & 인물별 고유 타임라인 바구니 & 화면 정화(UI Diet) (`poc/build_face_clusters_index.mjs`, `useZ-EyeStore.ts`, `FaceMemberRegistryModal.tsx`, `LoungeView.tsx`)

### 3.1 다년도·다각도(정면·측면·야외·선글라스·야간) 5대 스타일 슬롯 자동 선별 알고리즘
- 동일 인물의 대표 시드를 추출할 때 매년 천편일률적인 정면 컷만 뽑지 않고, 연도를 분산함과 동시에 촬영 조건과 각도가 최대한 다른 **5대 스타일 슬롯(`정면·선명`, `측면·미소`, `야외·노을`, `선글라스·역광`, `야간·실내`)** 베스트 컷을 내부에서 하나의 **‘멀티-조건 시드 패키지’**로 자동 결합합니다.

### 3.2 인물별 고유 타임라인 바구니 (Person-Bound Timeline Bucket) & 미래 바구니 자동 확장
1. **방(Room)이 아닌 '각 인물(Person ID)의 최초 생성 연도'에 귀속:**
   - 성인(10년 주기) / 미성년자(5년 주기) 바구니의 기준 연도는 각 인물의 시드가 최초 생성된 연도에 고정됩니다.
   - 한 라운지 안에 **2026년에 최초 세팅된 기존 가족(`2026~2017` 바구니)**과 **2029년에 새로 합류한 처가 식구(`2029~2020` 바구니)**가 함께 있더라도, 검색 및 역스캔 시 각 인물은 본인의 고유 연도 바구니를 독립적으로 유지합니다.
2. **미래 바구니(Forward Bucket) 자동 생성:**
   - 시간이 흘러 2027년 이후의 신작 사진이 들어오면 기존 `2026~2017` 바구니를 밀어내지 않고, 그 위에 **`2027~2036`(성인 10년) 또는 `2027~2031`(아동 5년) 미래 바구니**를 자동으로 신설하여 세월의 기록을 보존합니다.

### 3.3 무질문 0.1초 자동 장착 & 방별 별명(Room Persona) 독립 매핑 (`getActivePersonaForCluster`)
1. **"시드를 가져올까요?" 질문 팝업 제로 — 이메일 여권 자동 연동:**

       - **🎯 사전 답사(`Pre-Scout`) 완료된 사이트/앱 (`PRE_SCOUT_TARGET_REGION_PINSET` — 정답 구역 핀셋 스캔):** 페이지 구조(`Blueprint`)를 알고 있는 화면에서는 목표 요소가 위치한 특정 부모 컨테이너(상단 리본 영역, 특정 팝업창 내부 등)만 핀셋으로 타겟팅하여 그 내부의 텍스트와 노드는 누락 없이 온전히 스캔합니다.
        - **🔍 미답사(초행길) 화면 (`UNEXPLORED_2STAGE_HIERARCHICAL_ZOOM_IN` — 계층형 2단 줌인 스캔):** 처음 보는 복잡한 PC 화면일 경우, 1차로 화면 대분류 영역(`Landmark/Panel` 단위 5~10개 블록) 요약만 먼저 파악한 뒤, 목표와 관련된 영역(예: `설정 패널` 또는 `관공서 인증서 팝업`)으로 줌인(`Zoom-in`)하여 해당 구역 내부는 과도한 삭제 없이 **비표준 클릭 요소(`cursor: pointer`, `div/span` 가짜 버튼, 중요 에러 안내 텍스트 라벨 등)까지 100% 무손실 정밀 스캔**합니다.

### 5.10 No-Cloud P2P 하이브리드 폴백 아키텍처(특허 제2호) & 초경량 Supabase DB 스키마 (`src/services/p2pHybridBridge.ts`, `supabase/z_eye_zero_cloud_schema.sql`, `vite.config.ts`)
1. **성공률 99.9% + 중계 서버비 0원 P2P 2단계 하이브리드 폴백 (`p2pHybridBridge.ts`):**
   - **Stage 0 — DB 저장 0 Byte 시그널링 (`SUPABASE_REALTIME_BROADCAST_ZERO_DB`):** Supabase Realtime Broadcast 메모리 패스스루 채널(`zeye-p2p-room:{roomId}`)만 사용하여 SDP Offer/Answer, ICE Candidate, 아웃바운드 터널 엔드포인트를 중매하므로 DB 테이블 Write 비용이 0 Byte입니다.
   - **Stage 1 — 1순위 `WebRTC DataChannel` 다이렉트 P2P (`WEBRTC_DATACHANNEL_DIRECT`):** 일반 NAT/동일 망 환경에서 중계 서버 없이 13KB WebP 썸네일, 30KB 오프라인 문서 요약, 5MB 무손실 원본을 직접 송수신합니다.

  3. 설정몬스터의 손가락 화살표(`👆`)로 **`① [전송 ↑]` ➔ `② 바로 옆 [라이브 음성 🎧]`** 버튼만 콕 집어 안내하여, 우리 서버 토큰 비용 0원으로 최고급 AI 실시간 음성 상담까지 막힘없이 이어줍니다.

## 3. ⚡ 4대 핵심 시나리오 상세 작동 플로우

### 시나리오 A — 문서 사전 요약본 무토큰 즉시 낭독 (*"이 문서 요약해서 읽어줘"*)
1. 문서를 최초 인덱싱할 때 로컬에서 미리 생성해 둔 `2~3줄 핵심 요약문`을 로컬 DB에서 0.001초 만에 로드합니다 (실시간 LLM 호출 0회).
2. **`선희(ko-KR-SunHiNeural)`** 아나운서 음성으로 요약본을 즉시 또렷하게 낭독합니다.

### 시나리오 B — 특정 단어가 나오는 문장 전수 발췌 낭독 (*"계약서에서 '위약금'이나 '해지' 나오는 문장 다 읽어줘"*)
1. 로컬 정규식/문자열 파서(`extractKeywordSentencesZeroLlm`)가 0.001초 만에 문서 본문 전체에서 `'위약금'`, `'해지'`가 포함된 문장들만 모두 발라냅니다.
2. 화면에는 해당 문장들을 **노란 형광펜으로 하이라이팅**하여 즉시 보여줍니다.
3. 음성으로는 먼저 **`현수`**가 *"요청하신 위약금, 해지 단어가 포함된 문장 총 N개를 찾았습니다. 선희 아나운서가 차례대로 읽어드립니다"*라고 브리핑한 뒤, 곧바로 **`선희`**가 매칭된 문장들을 순서대로 읽어줍니다.

### 시나리오 C — 실제 카톡 대화방 직행 장전 & 귀신같이 자동 복귀 (*"계약서 찾아서 카톡 '이쁜이'에게 전달해줘"*)
1. **PC (`멀린 Z 코어` 내장 `plugin_senstalk.py`)**: 0.1초 만에 파일을 찾은 뒤 카카오톡을 활성화하여 `'이쁜이'` 대화방 창을 화면 최상단에 띄우고 파일을 장전합니다.
2. **모바일 (`1MB APK`)**: 카톡 공유(`Intent.ACTION_SEND`) 호출 후 설정몬스터 `AccessibilityService`로 검색창에 `'이쁜이'`를 자동 입력·선택하여 실제 `'이쁜이'` 채팅방 전송 확인 화면까지 직행시킵니다.
3. **유저 1-Tap 승인 (`Zero-Auto-Action`) & 자동 복귀**: 유저가 실제 카톡방임을 눈으로 확인하고 `[Enter]`/`[전송]`을 누르면, 카톡방에 파일이 올라간 모습을 **1~2초간 확인시켜 준 뒤 원래 보던 귀신같이 화면으로 자동 복귀**(화면 상단 `[⬅️ 귀신같이로 복귀]` 플로팅 알약 버튼 동시 제공)합니다.

### 시나리오 D — 고난도 질문 시 유저 단골 AI(기본값: `제미나이`) 입력창 자동 채움 & `[라이브 음성 🎧]` 바톤터치 (*"이 계약서에서 나한테 불리한 조항 있어?"*)
1. **자율 난이도 감지 & `현수` 음성 안내**:
   - 단순 검색/발췌를 넘어서는 심층 분석·자문 질문임을 0.001초 만에 감지하고 `현수` 목소리로 안내합니다:
     > *"깊은 분석이 필요한 질문이네요! 평소 쓰시는 제미나이(또는 챗GPT) 입력창에 이 문서와 질문을 바로 넣어 띄워드릴게요. `[전송]` 버튼을 누르신 뒤, 바로 옆 `[라이브 음성]` 버튼을 누르시면 말로 편하게 상담하실 수 있습니다!"*
2. **최근 사용한 AI 0.01초 자동 판별 (`detect_most_recent_ai_and_baton_touch`)**:
   - **1순위**: 현재 PC 화면에 열려 있는 브라우저 탭/창 제목(`ChatGPT`, `Gemini`, `Claude`) 스캔.
   - **2순위**: 크롬(`Chrome`)·엣지(`Edge`)·웨일(`Whale`) 로컬 방문 기록(`History` SQLite DB)에서 `last_visit_time`이 가장 최신인 AI 1위 자동 선택.
   - **3순위 (열어본 기록이 0건인 초기 유저 기본값 — 멀린님 확정)**: 구글 계정으로 즉시 로그인되는 **`제미나이 (Gemini, https://gemini.google.com/app)`**를 기본으로 오픈!
3. **입력창 자동 채움 & 2단계 손가락 가이드(`👆`) + 귀신같이 복귀 알약 버튼**:
   - 유저가 수동으로 붙여넣기할 필요 없이 `[찾은 문서 전체 텍스트 + 유저 질문]`을 입력창에 자동 장전합니다.
   - 화면 위에 **`① [전송 (↑)] 버튼 클릭` ➔ `② 바로 옆 [라이브 음성 🎧] 버튼 클릭`** 손가락 가이드를 띄우고, 구석에는 **`[⬅️ 대화 종료 후 귀신같이 복귀]`** 플로팅 알약 버튼을 배치하여 상담 종료 후 원터치로 복귀시킵니다.

## 1. 하이브리드 네이티브 브릿지 고도화 (PWA + 1MB APK 아키텍처)

1. **1MB 초경량 안드로이드 APK (백그라운드 로컬 에이전트)**
   - **역할:** 모바일 브라우저(PWA)의 샌드박스 한계를 돌파하기 위해 OS 파일 시스템 접근/물리 이동·삭제 권한(`MANAGE_EXTERNAL_STORAGE` / MediaStore)을 통제하고, 로컬 기기(NPU/GPU)에서 EmbeddingGemma 2 모델을 백그라운드 구동.
   - **통신 구조:** APK가 `localhost` 로컬 웹서버(또는 Local WebSocket Bridge)를 띄우고, 무거운 네이티브 UI 패키징 없이 가벼운 **PWA 웹 프론트엔드**가 로컬 루프백으로 통신하여 UI를 렌더링.
2. **완전한 P2P (Peer-to-Peer) 다이렉트 연합 검색 (디폴트 아키텍처)**
   - **Zero-Cloud 원칙:** 원본 사진, 썸네일, 메타데이터, 768차원 벡터 DB 등 유저의 어떠한 개인 데이터도 중앙 클라우드 DB에 저장하지 않음.
   - **이메일 로그인의 역할:** 오직 기기 간 **WebRTC 시그널링(Signaling, IP/세션 중계)** 및 **멀린 생태계 결제/코인 권한 검증** 용도로만 사용.
   - **연합 검색 (Federated Search):** PC, 스마트폰, 태블릿 등 동일 이메일로 묶인 다중 기기가 P2P 다이렉트 채널로 연결되어, 검색 쿼리 발생 시 각 기기의 로컬 인덱스를 동시에 찔러 결과를 취합·표시.

## 2. Phase 2: 슈퍼 앱 도약 및 수익 극대화 (Phase 1 런칭 후 순차 업데이트)

### 2.1 클린몬스터 Full (단건 과금 모듈)
- **스마트폰 전체 앱/캐시 스캔 및 기기 건강 상태 점검**
  - 사진뿐만 아니라 스마트폰 내 설치된 전체 앱 패키지 용량, 장기 미사용 앱(좀비 앱), 앱별 임시 캐시, 대용량 다운로드 잔여 파일을 정밀 스캔.
- **LLM 기반 대화형 기기 진단 리포트**
  - 수집된 기기 텔레메트리(가용 RAM, 스토리지 포화도, 미사용 앱 목록)를 바탕으로 클라우드/로컬 LLM이 *"현재 RAM 대비 시스템 상주 프로세스가 무겁습니다. 6개월간 열지 않은 앱 42개(총 14.8GB) 정리를 권장합니다"* 형태의 **맞춤형 대화형 진단 리포트**를 생성하고 원클릭 정리를 유도.

### 2.2 Z-Eye 공유방 마스터권 확장 (연 구독 캐시카우)
- **OCR 다이내믹 라우터 (지능형 서류 관리)**
  - 로컬 AI가 1차 분류한 영수증·서류·문서 사진들의 고해상도 텍스트를 LLM/OCR 파이프라인이 정밀 판독하여 **영수증(지출 증빙) / 의료 처방전·진단서 / 계약서·회사 서류 / 신분증·여권** 등 세부 카테고리로 자동 분류·태깅하는 스마트 서류철 기능.
- **음성 통화 녹음 파일 STT 텍스트화 및 시맨틱 검색**
  - 스마트폰 내 통화 녹음 및 음성 메모 파일(`.m4a`, `.mp3`, `.wav`)을 로컬/경량 STT(Whisper 계열 또는 Gemma 오디오 파이프라인)로 인덱싱하여 *"지난달 세무사님이랑 통화할 때 얘기한 서류"*처럼 음성 녹음 내용까지 통합 검색.
- **동영상 프레임 분석 기반 검색 (Video Frame Indexing)**
  - 동영상 파일에서 키프레임(1fps 또는 씬 전환 프레임)을 추출해 768차원 벡터로 인덱싱함으로써, 수십 분짜리 영상 속 특정 장면(*"아기가 처음 걸음마 떼던 순간"*)의 타임스탬프를 0.1초 만에 핀포인트 점프.

## 3. PR, 특허, 마케팅 및 비즈니스 전략 (Phase 2~3 연계)

### 3.1 다중 AI 앙상블 특허 및 오픈소스 허들 전략
1. **특허 출원 전략 (청구항 설계)**
   - 특정 단일 오픈소스 모델명(예: EmbeddingGemma 2)에 종속된 청구항이 아니라, **「다중 기기 P2P 연합 통신 및 로컬 NPU 임베딩 모델 - 물리·광학 검증 필터 - 클라우드 LLM 기반 동적 라우팅(스무고개 질의 정제) 아키텍처」** 결합 구조로 청구항을 설계하여 후발 주자 및 대기업의 우회 침해를 원천 방어.
2. **'Powered By AI' 멀티 스택 고지 전략**
   - 앱 설정 화면 하단에 `Google EmbeddingGemma 2`, `Perceptual dHash & Laplacian Optical Engine`, `OpenAI Whisper`, `Dynamic LLM Routing Engine (Gemini/Argon)` 등 복합 앙상블 스택을 명시하여:
     - 일반 유저에게는 **압도적인 딥테크 신뢰감** 부여
     - 경쟁사 및 카피캣에게는 **단일 모델 복제로는 따라잡을 수 없다는 리버스 엔지니어링 피로감(진입 장벽)** 부여

### 3.2 타겟 마케팅 및 폭발적 바이럴 루프
1. **핵심 타겟팅 (Anti-Cloud & Storage Fatigue)**
   - Google One, iCloud+ 등 매달 빠져나가는 클라우드 용량 월정액 구독료에 피로감을 느끼는 유저
   - 가족·사생활 사진이 외부 빅테크 서버에 동기화·학습되는 것에 거부감을 가진 **프라이버시 민감층(Anti-Cloud)**
2. **초기 진원지 확보 (Merlin Core 1,000)**
   - 멀린코드 커뮤니티 초기 방장 유저를 대상으로 **선착순 100명 10년 방장 마스터권(월 구독료 × 10개월 치)**을 제공하여 초기 시드 매출과 열성 팬덤(우군)을 동시에 확보.
3. **P2P 핀 번호 기반 바이럴 확산 루프**
   - 초기 구매 유저에게 **「클린몬스터 지인 3회 무료 초대권 (1회용 PIN 번호 기반 P2P 연결)」**을 지급.
   - 지인이 초대 핀 번호를 입력하면 즉시 내 폰의 쓰레기 사진·연사 중복 다이어트를 상시 무료 진단하게 되어, 광고비 없이 앱 설치와 입소문이 꼬리를 무는 바이럴 루프 가동.

## 4. 콘텐츠 자동 생성 플랫폼 진화: '시간의 흐름' 숏폼 자동 생성 & 스마트 라운지 커스터마이징

> **기획 배경:** '시간의 흐름'을 압축해 보여주는 숏폼 콘텐츠는 유튜브와 틱톡 등에서 가장 높은 조회수와 공유(공감)를 이끌어내는 검증된 바이럴 포맷입니다. 귀신같이 라운지가 단순한 사진 저장소를 넘어, **가족을 울리고 동창들을 열광시키는 '콘텐츠 자동 생성 플랫폼'**으로 진화하기 위해 마스터 PC 기반의 로컬 처리 환경과 결합한 자동화 기능 및 비즈니스 모델입니다.

### 4.1 자동 생성 숏폼: '연도별 얼굴 변천사'와 '과거-현재 투샷'
가족 라운지에서는 **'감동'**을, 동호회·동창회(`사진 공유`) 라운지에서는 **'유쾌함'**을 타겟팅하여 자동으로 영상을 찍어냅니다.

1. **정면 얼굴 정렬 (Face Alignment):**
   - 마스터 PC의 안면 인식 모델(InsightFace 등)이 랜드마크를 분석해, 수천 장의 사진 중 유저의 시선이 카메라를 향한 **'정면 사진'만 연도별로 1장씩(10~20장)** 필터링합니다. (귀신같이 여권의 인물별 연도 바구니와 직결)
2. **로컬 영상 렌더링 (서버비 0원):**
   - 사진이 추려지면 서버를 거칠 필요 없이, 마스터 PC 백그라운드에서 **FFMPEG나 MoviePy** 같은 영상 처리 파이프라인이 즉시 가동됩니다.
   - 사진들을 부드러운 디졸브(Fade) 효과로 이어 붙이고, 우측 하단에 **`[Z-Eye]` 워터마크**를 박아 15초짜리 MP4 숏폼으로 구워냅니다.
3. **동창회 '비포 & 애프터' 투샷:**
   - 동창회 라운지에서는 1989년의 앳된 얼굴과 2026년 동창회 모임에서 찍힌 얼굴을 **좌우 분할(Split) 영상**으로 만들어 *"OOO의 37년 전과 오늘"*이라는 타이틀로 대기실에 자동 발행합니다.

### 4.2 푸시 알림을 통한 강력한 리텐션(재방문) 트리거
앱을 설치해 두고 잊고 지내던 가족들과 동창들을 다시 불러모으는 가장 확실한 재방문 트리거가 됩니다.

1. **감동의 알림:**
   - 영상 렌더링이 끝나면 가족 멤버 전체의 폰으로 알림이 발송됩니다:
     *"🚨 엄마의 30년 세월이 담긴 특별한 기록이 완성되었습니다."*
2. **SNS 바이럴 유도:**
   - 영상을 보고 눈시울이 붉어진 자녀가 **`[인스타그램 / 유튜브 쇼츠로 내보내기]`** 버튼을 누르게 만듭니다.
   - 귀신같이 로고가 박힌 감동적인 영상이 외부 SNS로 퍼져나가며 가장 강력한 오가닉 브랜드 마케팅 소재로 작동합니다.

### 4.3 '추억 생성기'를 활용한 프리미엄 수익 모델 (BM)
기본적인 슬라이드쇼는 마스터 PC 자원을 활용해 무료로 제공하되, 고품질의 스토리텔링 콘텐츠는 유료화하여 추가 수익을 창출합니다.

1. **기본 제공 (무료):**
   - 연도별 정면 사진 이어 붙이기 + 기본 BGM + `[Z-Eye]` 워터마크 포함.
2. **프리미엄 AI 다큐멘터리 영상 (1건당 결제 또는 상위 구독 혜택):**
   - **Gemma 2 LLM과 TTS(음성 합성) API**를 연동하여, 사진 속 상황을 바탕으로 한 감동적인 나레이션 대본을 자동 작성하고 자연스러운 목소리를 입혀주는 서비스입니다.
   - *"1989년 봄, 가장 빛나던 20대의 엄마..."* 같은 다큐멘터리급 숏폼을 만들어주며 별도 비용(또는 코인)을 청구합니다.

### 4.4 라운지 개설 시 '스마트 태그'와 맞춤형 탭 자동 생성
라운지를 만들 때 **"어떤 모임인가요?"**라는 단일 질문 하나로, 방의 성격과 상단 탭 UI를 완벽하게 자동 세팅합니다.

1. **동창회 선택 시:**
   - **'졸업 연도'**와 **'학교명'**을 입력받아 이원화 타임라인 UI를 즉시 적용합니다.
   - 상단 탭이 **`[성동 1989 응답하라!]`**와 **`[2026 우리의 오늘]`**로 자동 분리되어 생성됩니다.
2. **가족 선택 시:**
   - 상단 탭이 **`[우리 가족의 시간]`**과 **`[최근 일상]`**으로 자동 부여됩니다.
3. **CRM 데이터 축적 및 확장성 확보:**
   - 직장, 어린이집, 동아리 등 당장 특화 기능이 없는 유형이라도 개설 시 모임 유형 데이터를 수집해 둡니다.
   - 향후 Phase 2 업데이트 시, 해당 유형의 라운지들만 타겟팅하여 **'직장인용 문서/명함 자동 인식 기능'**, **'어린이집 알림장·성장 앨범 기능'** 등을 일괄 푸시할 수 있는 핵심 CRM 자산이 됩니다.

## 🏛️ 1. 생태계 4대 핵심 원칙 (Constitution)

1. **용어 단일화 ('쿠폰/티켓' 폐지 ➔ '선물'로 100% 통일)**:

   - 모든 선물은 외부 기프티콘이 아닌 **우리 패밀리 앱 내의 실제 디지털 상품(예: AI 설정몬스터, AI 클린몬스터, 사진 공유 (패밀리) 1개월, 패밀리 코인)**입니다.

   - 좁은 모바일 화면을 가려 스트레스를 유발하는 배너 광고를 모든 앱에서 영구 퇴출합니다.
   - 완전 무료로 풀거나, 100코인(100원)~수천 원대의 합리적인 소액 상품 및 선물하기로만 쾌적하게 운영합니다.
3. **썬드리머 포인트(P) 분리 원칙**:
   - 썬드리머 1호 앱의 오프라인 기기/소모품 전용 `포인트(P)`는 디지털 코인(C)과 절대 섞지 않습니다.
   - 대신 썬드리머 회원들에게 귀신같이 등 디지털 앱의 상품을 **`특별 선물`**로 쏴주는 방식으로 원가 0원의 교차 프로모션을 전개합니다.
4. **푸시 알림(1순위) + 이메일(2순위) 전달 체계**:
   - 번거로운 카톡 공유 대신, 선물하기 버튼을 누르는 즉시 수신자의 스마트폰으로 **네이티브 푸시 알림(`🔔 띠링! 선물이 도착했습니다`)**을 1순위로 쏘고, 이메일을 보조 알림으로 발송합니다.

## 12. 공식 온보딩 쇼룸 대문 & 세션 감지형 자동 패스스루(`Seamless Auto-Bypass`) 라우팅 및 실행 전제 원칙 (`App.tsx`, `GhostiShowroomLanding.tsx`, `setupMonsterTts.ts`)

### 12.1 출시 전(Pre-Launch) ➔ 정식 출시 후(Post-Launch) 하이브리드 온보딩 대문 생애주기
1. **출시 전 사전 빌드업 모드 (`OFFICIAL_LAUNCH_LIVE = false`):**
   - **일반 방문자 대상 내부 개발 화면 100% 비노출 잠금:** 일반 방문자가 `https://ghosti.sundreamer.app`에 접속하면 내부 워크스페이스는 렌더링되지 않으며, 오직 **『공식 쇼룸 & 하이브리드 온보딩 대문』**만 노출됩니다. 개발자 및 QA 진입은 오직 **`/?dev=true`** 단일 파라미터로만 허용됩니다.
   - **외부 이탈 방지 & 이메일 1초 인증 사전 가입 (`useHubAuth` + `syncHubUserToLocalSupabase`):** 검색해서 대문까지 들어온 방문자를 다시 유튜브나 블로그로 이탈시키지 않고, 대문 히어로에서 **6자리 이메일 OTP 인증**을 통해 **사전 회원가입(`family_users` + `public.users`)과 정식 출시 1순위 알림 예약을 동시에 완료**합니다.
   - **카페브레이커/스튜디오 쇼츠 자동 배치 피드 (`/data/ghosti_shorts_feed.json`):** 무인 쇼츠 공장에서 업로드된 영상의 `youtubeId`가 피드에 추가되면 대문 쇼룸에 즉시 자동 진열·재생됩니다.
2. **정식 출시 후 영구 온보딩 & 세션 감지형 자동 패스스루 (`OFFICIAL_LAUNCH_LIVE = true`):**
   - **① 비로그인 첫 방문자 (Guest):** 도메인 접속 시 **온보딩 쇼룸 대문**이 표시되어 3초 인터랙티브 프리뷰와 15초 영상 사용설명서를 경험한 뒤, 대형 **`[🚀 귀신같이 본 앱 바로 시작하기]`** 버튼 또는 이메일 인증으로 본진 워크스페이스에 진입합니다.
   - **② 로그인 완료 / 기존 진입 회원 (`Seamless Auto-Bypass`):** 이미 로그인 세션(`merlin_session_token`)을 보유했거나 온보딩을 거쳐 본 앱에 진입한 이력이 있는(`ghosti_onboarding_completed = 'true'`) 기존 회원이 재방문할 때는, **번거로운 온보딩 대문이나 버튼 클릭 과정을 0.001초 만에 자동 스킵(Bypass)하고 곧바로 본진 워크스페이스(`💻 내 기기`)로 직행 오픈**합니다.
   - **③ 기존 회원의 수동 쇼룸(15초 영상 설명서) 열람:** 본진 워크스페이스 상단 헤더의 **`[🏠 공식 쇼룸 대문]`** 버튼을 명시적으로 눌렀을 때만 온보딩 대문이 열리며, 다시 **`[🚀 귀신같이 본 앱 바로 시작하기]`**를 누르면 즉시 워크스페이스로 복귀합니다.

### 12.2 모든 액션 실행의 기본 전제 원칙 (`이메일 로그인 + 로컬 Z-코어 실행`) 및 성우 음성 표준
1. **`로그인 + Z-코어(127.0.0.1:5199) 실행` 선행 원칙:**
   - 내 기기(`찾기` · `치우기` · `고치기`)의 모든 실제 실행 액션은 **① 이메일 인증 로그인 완료 + ② 내 PC `멀린 Z-코어` 실행 연결**이 이루어진 상태에서 작동하는 것을 불변의 기본 원칙으로 합니다 (개인 1인 내 기기 사용은 평생 0원).
2. **모바일·PC 성우 일원화 (`현수 & 선희` MS 신경망 투톱) 및 구형 기계음(`Heami`) 원천 차단:**
   - 치우기·고치기 채팅 및 브리핑 음성은 로컬 Z-코어의 무료 무제한 MS 신경망 성우(**남성 `현수 ko-KR-HyunsuNeural` · 여성 `선희 ko-KR-SunHiNeural`**)를 기본 속도 **`+15%` (`1.15x`)**의 경쾌한 톤으로 출력하며, Z-코어 미연결 시 윈도우 구형 로봇 기계음(`Microsoft Heami`)으로 폴백되는 것을 원천 차단합니다.

3. **무소음 0.1초 자동 패스 & 부담 없는 자연스러운 로그인·코어 감지 (`/?dev=true` 포함):**
