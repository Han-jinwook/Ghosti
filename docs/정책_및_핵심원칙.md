## 2. 검색 탭 UX 원칙: 첫 검색 시 '동영상' 기본 오픈 & 재검색 시 '마지막 선택 탭 유지'

1. **첫 검색 시 임팩트 중심 자동 포커스:**
   - 처음 검색을 실행하면 3개 탭에 찾은 건수를 모두 배지로 표시하되(`🎬 동영상 (2)` · `🖼️ 사진 (7)` · `📁 문서 (1)`), 가장 시각적 임팩트가 큰 **`🎬 동영상` 탭을 기본(Default)으로 오픈**하여 어필/마케팅 목적을 달성합니다.
2. **재검색 시 마지막 선택 탭 유지:**
   - 유저가 특정 탭(예: `🖼️ 사진` 또는 `📁 문서`)을 클릭해 보다가 다시 검색을 실행하면, 각 탭의 결과 숫자는 배지에 갱신하되 **유저가 마지막으로 선택했던 탭이 디폴트로 열린 구조를 유지**합니다.
3. **검색 엔진 코어 Fix 보존 ("768차원 벡터 엑셀 + 온톨로지/지명 브레이크"):**
   - `runHybridCorpusSearch` 하이브리드 구조 및 복합 명사/지명 엄격 `AND` 교집합 원칙(일치 사진 없을 시 정직하게 `0장` 반환)을 철저히 유지합니다.

## 3. 만국공통 '귀신같이 여권(Ghosti Face Passport)' & 인물별 고유 타임라인 바구니 원칙

1. **다년도·다각도(정면·측면·야외·선글라스·야간) 최대 변별력 자동 추출:**
   - 동일 인물의 대표 시드를 뽑을 때 매년 똑같은 정면 사진만 뽑지 않고, 연도를 분산함과 동시에 촬영 조건과 각도가 최대한 다른 베스트 컷 조합(`정면·선명`, `측면·미소`, `야외·노을`, `선글라스·역광`, `야간·실내` 5대 슬롯)을 내부에서 자동 결합합니다.
2. **바구니 기준 연도는 '방(Room)'이 아닌 '각 인물(Person ID)의 최초 생성 연도'에 귀속:**
   - 10년(성인) / 5년(미성년자) 바구니의 기준 연도는 '각 인물의 시드가 최초 생성된 연도'로 고정합니다. 한 라운지 안에 2026년 세팅 기존 가족(`2026~2017`)과 2029년 신규 합류 처가 식구(`2029~2020`)가 섞여 있더라도 각 인물은 본인의 고유 연도 바구니를 독립 유지합니다.
   - 시간이 경과해 미래 연도(예: 2027년~) 사진이 들어오면 기존 바구니를 보존한 채 위로 **미래 바구니(`2027~2036` / `2027~2031`)를 자동 확장(Forward Bucket)**합니다.
3. **무질문 0.1초 자동 장착 & 방별 별명(Room Persona) 독립 매핑:**
   - 새 라운지 개설/입장 시 *"시드를 가져올까요?"* 질문 팝업 없이 이메일 계정에 귀속된 여권 시드가 0.1초 만에 자동 장착됩니다 (`[🛂 귀신같이 여권 자동 연동됨]`).
   - 시드(768차원 벡터 + 연도 바구니)는 100% 공유하되, 방마다 부르는 호칭(`우리집: 👑 멀린` ↔ `처가방: 👑 둘째사위` ↔ `본가방: 👑 큰아들(진욱)` ↔ `동호·동창회방: 지우짱`)만 독립 매핑됩니다.

## 4. 화면 정화(UI Diet) 4대 규칙 & `👑 방장` 호칭 통일 원칙

1. **`💻 내 기기`에서 얼굴/여권 박스 100% 제거 (완전 비노출):**
   - 내 기기는 나 혼자 내 기기를 검색·정리하는 공간이므로 `FaceMemberInlineBar` 및 얼굴 등록 박스를 아예 렌더링하지 않습니다.
2. **가로 6열 미니 아바타 나열 폐기 ➔ '1장씩 스무스 사각형 카드 (등록 완료 시 Auto-Hide 완전 소멸)':**
   - 이미 등록된 멤버는 상단 라운지 바의 깔끔한 별명 알약 버튼으로만 노출하고, 복잡한 연도 바구니 수치는 `[🛂 여권 관리]` 모달 안으로 숨깁니다.
   - 확인이 필요한 항목이 있을 때만 **큼직한 사각형 사진(`rounded-2xl`) 1장씩** 카드로 띄워 1줄 질문(`"😎 선글라스 낀 이 분도 [👑 멀린]님 맞죠?"` / `"👋 새로 등장한 이 분의 별명을 적어주세요"`)과 **`[⭕ 맞아요! 등록]`** 버튼으로 확인받으며, 확인이 모두 끝나면 **카드 박스 전체가 화면에서 완전히 사라집니다(`return null`)**.
3. **어르신·가족 친화적 문구 정돈:**
   - 화면에 기계적인 개발자 용어(`3단 집단지성 프로토콜`, `노약자 모드`)를 노출하지 않고, **`✨ AI 얼굴 자동 매칭 도우미`**와 **`⚡ 확인 건너뛰고 사진만 바로 올리기 (방장이 나중에 정리)`**로 다정하게 표기합니다.
4. **`호스트 ➔ 👑 방장` 교체 및 왕관(`👑`) 계급장 표시:**
   - 모든 `'호스트'` 표기를 **`👑 방장`**으로 통일하고, 방 개설자의 별명 알약 앞에 항상 **`👑` 왕관 아이콘**(`[👑 멀린]`, `[👑 둘째사위]` 등)을 표시합니다.

## 5. 3대 전략 메뉴 확정 요금제 · 공유방 동기화/권한/탈퇴 6대 원칙 (`v2.1`)

1. **내 기기(`💻 내 기기`) 3대 AI 몬스터 정의 및 ‘무료’ 워딩 제거 원칙:**
   - **개인 1인 (폰 + 주력 PC 1대 + 노트북 1대 = 총 3대):** **`언제나 0원`**. 단, `[내 기기]` 화면 내부에서는 '상시 무료 진단' 관련 워딩을 제거하고 이메일 로그인만 하면 누구나 바로 `🧹 클린몬스터 진단`을 실행할 수 있게 합니다.
   - **`투시검색`**: 사진·동영상 프레임별, 모든 서류파일의 내용을 투시하듯 1초 만에 찾아주며, 동일 내용 중복 파일 및 사진 연사 정리를 도와줍니다.
   - **`클린몬스터` / `설정몬스터`**: 무료 진단 후 유저가 선택한 수리/정리 항목에 한해 `100 ~ 500 코인 (1,000원 ~ 5,000원)` 에스크로 정산 (실패 시 100% 자동 환불).
2. **`⏳ AI 인덱싱 대기실` = 방장 사전 검수 없는 즉시 합류 & AI 꽃단장 버퍼:**
   - 수동 검열 공간이 아니라, 멤버들이 올린 사진·영상이 방장의 마스터 PC에서 Gemma 2 768차원 이름표 부착 및 13KB 썸네일 변환을 마치는 1~2분 동안 머무는 버퍼입니다.
3. **공유 라운지 초심플 기본 요금제 (방장 1인 결제 ➔ 초대 멤버/팀원 전원 무료):**
   - **`📸 사진 공유 (패밀리)`**: `🏠 우리집 단독` `월 5,900원 (10년 마스터권 59,000원)` / `👨‍👩‍👧‍👦 양가 통합권 (3방 분리)` `월 8,900원 (10년 마스터권 89,000원)` — *연구독 시 `[모임 라운지 3개월 무료 구독권 1장]` 증정*
   - **`⛳ 사진 공유 (동호회·동창회)`** *(인원수 무제한 단일가)*: `월 4,900원 (10년 마스터권 49,000원)` — *연구독 시 `[가족 라운지 1개월 무료 구독권 3장]` 증정*

4. **v2.1 공유방 데이터 흐름 · 동기화 · 권한 · 탈퇴 6대 확정 규칙:**
   - **① 방 개설 시 설정 옵션 (`24시간 내 올린 본인 삭제` + `방장 상시 숨기기 권한 보유 여부 선택 — 올라오는 처음부터 가능`):** 업로드 후 **24시간 내에는 올린 원본 주인이 언제나 직접 삭제 가능**하며, 멤버가 잘못된 사진을 올리는 것을 항상 감시·정리할 수 있도록 **방장이 올라오는 처음부터 상시 `[숨기기]` 권한을 가질지** 방 개설 시 설정 옵션으로 직접 선택합니다.
   - **② `64-bit dHash` 진짜 원본 검증 안전핀:** 중복 사진 감지 시 단순 바이트 용량 비교가 아니라 **`EXIF 촬영 원본 메타데이터`가 살아있고 `실제 픽셀 해상도(width × height)`가 더 큰 진짜 원본일 때만 자동 교체(댓글·좋아요 유지)**합니다.
   - **③ 평소 숨김 썸네일 DB & `[🔄 원본 동기화]` 경로 지정 자체 해결 (구 ‘원본 1초 소환 / 24시간 클라우드 도우미’ 완전 폐기):** 평소 멤버 기기에는 보이지 않는 시스템 영역(`%LOCALAPPDATA%\Merlin\thumb_db`)에 **13KB 썸네일 DB만 보관**하다가, Wi-Fi 및 여유 공간이 넉넉할 때 **`[🔄 원본 동기화]`**를 켜면 저장 경로를 지정·안내받고 내 기기에 원본을 복제하여 방장 PC 호출 없이 **내 기기에서 100% 자체 해결**합니다.
   - **④ 업무방(`S:`) 동시 편집 안내 단순화:** 윈도우 탐색기(`S:`)에서 열 때는 엑셀·오피스 기본 읽기 전용 규칙대로 작동하며, 웹/앱 검색에서 사용 중인 문서를 열 때는 **`"🔒 현재 [OOO]님이 사용 중입니다. 읽기 모드로 열립니다."`**로만 안내합니다.
