## 1. 코어 검색 엔진 아키텍처 (`vite.config.ts` — `runHybridCorpusSearch`) — **[100% 최종 확정]**

### 1.1 검색 파이프라인 구조 (768차원 벡터 엑셀 + 온톨로지/지명 브레이크 하이브리드)
현재 검색 엔진은 외부 LLM API 의존도 **0%**로 작동하며, **768차원 EmbeddingGemma 2 시맨틱 벡터 탐색(엑셀) + 인덱싱 시점의 온톨로지 상향 상속 및 핵심 명사/지명 `AND` 가드레일(브레이크)** 결합으로 동작합니다.

1. **한국어 토크나이저 및 조사/어미 분리 (`stripKoParticle`)**
   - 입력 쿼리에서 문장부호를 제거하고 공백 단위로 분리합니다.
   - `바닷가`, `창가`, `물가`, `휴가`, `아이`, `어린이`, `고양이`, `멍멍이`, `물놀이`, `목걸이`, `귀걸이`, `종로`, `을지로`, `다리`, `나무다리`, `선풍기`, `비행기` 등 끝글자가 조사와 겹치는 명사(`KEEP_NOUNS`)를 보호한 뒤, 한국어 조사(`에서, 으로, 이랑, 하고, 부터, 까지, 들, 의, 을, 를, 은, 는, 에, 와, 과, 도`)를 제거하여 어근 토큰을 추출합니다.
   - 수식어/불용어(`SOFT_WORDS`: `사진, 찾아줘, 보여줘, 모습, 분위기, 풍경, 장면, 한잔하는` 등)와 핵심 개념 토큰(`hardTokens`)을 분리합니다.

2. **한국어 부분 문자열 착시 차단 (`BLOCK_SUBSTRING_MAP`)**
   - 짧은 한국어 명사가 전혀 다른 복합어의 부분 문자열로 오탐되는 현상을 정규식 마스킹으로 원천 차단합니다 (`튜브 ➔ 유튜브/UV-B 제외`, `아이 ➔ 아이콘/아이폰 제외`, `다리 ➔ 사다리/책상다리 제외`, `불 ➔ 불안/불빛 제외` 등).

3. **768차원 EmbeddingGemma 2 시맨틱 벡터(엑셀) + 온톨로지 핵심 명사 가드레일(브레이크) 결합**
   - **핵심 명사/지명 가드레일 (`coreGuardrailTokens`):** 검색어 내 토큰 중 온톨로지에 등록된 핵심 명사·지명(`청라`, `보트`, `맥주`, `불쇼`, `구명조끼`, `아이`, `여의도`, `한강공원` 등)은 반드시 모두 만족해야 통과합니다 (`corePrimaryHits >= requiredCoreCount`).
   - **자연어 문장·맥락·감성 표현의 768차원 벡터 탐색:** `"코타키나발루 나무 다리 위에서 산책하는 모습"`, `"한밤중 바닷가 화려한 불쇼 퍼포먼스"`, `"야외 테라스에서 밤거리 보며 한잔하는 분위기"`, `"여의도 한강공원에서 친구들과 걷는 뒷모습"` 등 자연어 문장은 **768차원 EmbeddingGemma 2 벡터 유사도(`vecSim`)**가 사진 전체의 의미 공간을 탐색하여 `0.04초` 만에 랭킹합니다.

## 3. [탭 2: 🧹 주치의 정리] 무료 종합 진단서 헤더 & 3중 타임머신 안전망 Undo (`SmartTrashView.tsx`, `App.tsx`)

### 3.1 🩺 디지털 주치의 종합 진단 리포트 배너
- 정리 탭 최상단에 단순 장수 나열이 아닌 주치의 정밀 진단서 카드를 배치:
  - **`"진단 결과: 중복·연사(파일명 다른 카톡 사본 포함) OO장, 흔들린 사진 OO장, 일회성 메모·캡처 OO장 (총 OO MB 낭비 중) ➔ 처치 완료 시 기기 탐색 및 인덱싱 반응 속도 약 +OO% 향상 예상"`**
  - 현재 갤러리 건강도 점수 대비 처치 후 쾌적도(98점)를 보여주는 **시각적 2단 속도 향상 게이지**를 함께 렌더링합니다.
  - 상단에 *"모든 정리 파일은 영구 삭제되지 않고 `[세이씨_정리대기함]`에서 30일간 안전하게 보호되며, PC 연결 시 원본 블랙박스 보관이 가능합니다"* 안심 문구를 명시했습니다.

### 3.2 🛡️ 3중 타임머신 안전망 (1초 즉시 되돌리기 Undo 플로팅 바)
- 바둑판 Pick(`pickBestInDuplicateGroup`, `pickBestInBurstPhotos`)이나 일괄 격리(`moveSelectedToQuarantine`, `moveAllTrashToQuarantine`) 실행 직후, 스토어에 `lastUndoBatch`(`UndoQuarantineBatch`) 스냅샷을 기록합니다.
- 화면 하단(및 정리 탭 상단)에 플로팅 바 형태로 **`[↩️ 방금 정리한 항목 원래대로 되돌리기 (Undo)]`** 버튼을 즉시 띄워, 클릭 시 1초 만에 `restoreFromQuarantine`을 호출하여 원래 위치로 완벽히 원복합니다.

### 3.3 4대 쓰레기 탭 & PC 3×3 / 4×4 바둑판(Grid) Pick UI
- `① 동일한 복사본·연사` / `② 주차장·영수증·일회성 메모` / `③ 스크린샷` / `④ 심한 흔들림·오촬영` 4대 탭으로 구성.
- `① 동일한 복사본·연사` 탭에서는 초록색 **`[✓ 원본 1장 안전하게 보존됨]`** 배지와 함께 PC 3×3 / 4×4 바둑판 배열로 연사들을 펼쳐 보여주며, 베스트 컷 1장만 클릭(`Pick`)하면 나머지 사본들이 즉시 `[세이씨_정리대기함]`으로 격리됩니다.

   - **모드 B. `[👻 초경량 섀도우 캐시 모드]` (폰 용량 부족할 때 — 추천):** 무거운 원본(수십 GB)은 집 PC 하드디스크로 이관해 폰 용량을 비우고, 폰에는 **장당 13KB짜리 경량 WebP 썸네일 + 768d 벡터 인덱스**만 남김 (`550장 기준 단 7.1 MB`). 집 PC 전원이 꺼져 있어도 밖에서 내 폰으로 PC 속 10년 치 사진·서류를 `0.04초` 만에 100% 검색·열람 가능.
