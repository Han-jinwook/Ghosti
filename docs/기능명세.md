## 1. 코어 검색 엔진 아키텍처 (`vite.config.ts` — `runHybridCorpusSearch`) — **[100% 최종 확정]**

### 1.1 검색 파이프라인 구조 (768차원 벡터 엑셀 + 온톨로지/지명 브레이크 하이브리드)
현재 검색 엔진은 외부 LLM API 의존도 **0%**로 작동하며, **768차원 EmbeddingGemma 2 시맨틱 벡터 탐색(엑셀) + 인덱싱 시점의 온톨로지 상향 상속 및 핵심 명사/지명 `AND` 가드레일(브레이크)** 결합으로 동작합니다.

1. **한국어 토크나이저 및 조사/어미 분리 (`stripKoParticle`)**
   - 입력 쿼리에서 문장부호를 제거하고 공백 단위로 분리합니다.
   - `바닷가`, `창가`, `물가`, `휴가`, `아이`, `어린이`, `고양이`, `멍멍이`, `물놀이`, `목걸이`, `귀걸이`, `종로`, `을지로`, `다리`, `나무다리`, `선풍기`, `비행기` 등 끝글자가 조사와 겹치는 명사(`KEEP_NOUNS`)를 보호한 뒤, 한국어 조사(`에서, 으로, 이랑, 하고, 부터, 까지, 들, 의, 을, 를, 은, 는, 에, 와, 과, 도`)를 제거하여 어근 토큰을 추출합니다.
   - 수식어/불용어(`SOFT_WORDS`: `사진, 찾아줘, 보여줘, 모습, 분위기, 풍경, 장면, 한잔하는` 등)와 핵심 개념 토큰(`hardTokens`)을 분리합니다.

2. **한국어 부분 문자열 착시 차단 (`BLOCK_SUBSTRING_MAP`)**
   - 짧은 한국어 명사가 전혀 다른 복합어의 부분 문자열로 오탐되는 현상을 정규식 마스킹으로 원천 차단합니다.
     - `튜브` 검색 시 ➔ `유튜브`, `자외선램프`, `uv-b` 마스킹 제거
     - `아이` 검색 시 ➔ `아이콘, 아이폰, 아이패드, 아이디어, 아이템, 아이돌, 아이스, 아이라인` 마스킹 제거
     - `다리` 검색 시 ➔ `기다리, 사다리, 책상다리, 식탁다리` 마스킹 제거
     - `모자` 검색 시 ➔ `모자이크` 마스킹 제거
     - `고기` 검색 시 ➔ `물고기` 마스킹 제거
     - `불` 검색 시 ➔ `불안, 불편, 불가, 불구, 불빛` 마스킹 제거

3. **1글자 한국어 명사 및 다자간 토큰 대조**
   - 1글자 명사(`불, 물, 술, 밥, 차, 배, 산, 숲, 밤, 해, 눈, 비, 꽃, 집, 방, 길, 옷, 컵, 잔, 병, 탑, 섬, 강, 창, 문, 책, 글, 개` 등)는 사진의 `ontologyPrimaryTags` / `ontologyCaptionTags`에 독립 원소로 등록되어 있어 $O(1)$ 해시셋(`Set.has`)으로 즉시 매칭되며, 온톨로지 밖의 1글자도 어절 경계 정규식(`singleCharRegex`)으로 검증합니다.
   - 띄어쓰기 복합어(예: `"나무 다리"` ➔ `"나무다리"`, `"조립 설명서"` ➔ `"조립설명서"`)가 하나의 단어로 존재하는 경우 `compoundHit` 가점을 부여합니다.

4. **768차원 EmbeddingGemma 2 시맨틱 벡터(엑셀) + 온톨로지 핵심 명사 가드레일(브레이크) 결합**
   - **핵심 명사/지명 가드레일 (`coreGuardrailTokens`):** 검색어 내 토큰 중 온톨로지에 등록된 핵심 명사·지명(`청라`, `보트`, `맥주`, `불쇼`, `구명조끼`, `아이`, `여의도`, `한강공원` 등)은 반드시 모두 만족해야 통과합니다 (`corePrimaryHits >= requiredCoreCount`). 따라서 `"청라 보트"`처럼 존재하지 않는 명사 조합은 부분합(`OR`) 폴백 없이 즉시 `0장`을 반환합니다.
   - **자연어 문장·맥락·감성 표현의 768차원 벡터 탐색:** 반면 `"코타키나발루 나무 다리 위에서 산책하는 모습"`, `"한밤중 바닷가 화려한 불쇼 퍼포먼스"`, `"야외 테라스에서 밤거리 보며 한잔하는 분위기"`, `"여의도 한강공원에서 친구들과 걷는 뒷모습"`처럼 자연어 서술어·행동·분위기 표현이 포함된 문장은 **768차원 EmbeddingGemma 2 벡터 유사도(`vecSim`)**가 사진 전체의 의미 공간을 탐색하여 `0.04초` 만에 정확히 랭킹합니다.

5. **768차원 EmbeddingGemma 2 실시간 쿼리 임베딩 및 캐싱 (`embedQueryVector768`)**
   - 로컬 ONNX 런타임(`@huggingface/transformers`)을 통해 `onnx-community/embeddinggemma-2-ONNX` (`q4` 양자화) 모델을 구동합니다.
   - 쿼리를 `task: search result | query: {검색어}` 포맷으로 토크나이징한 뒤 768차원 L2 정규화 벡터를 추출합니다.
   - `queryVecCache` (`Map<string, number[]>`)를 통해 동일 검색어 재요청 시 `0ms` 만에 벡터를 반환합니다.

## 2. 한국어 시각 개념 족보 트리 및 인덱서 (`src/data/koreanPhotoOntology.json`, `poc/build_korean_photo_ontology.mjs`)

### 2.1 온톨로지 데이터 구조 (`src/data/koreanPhotoOntology.json`)
- **기반 데이터셋:** Open Multilingual WordNet (OMW-ko) + Google Open Images V7 시각 계층 + 한국인 일상 갤러리 빈출 어휘 + 행정구역 지명 계층 (71개 계층 노드, 약 700개 어휘 수록).
- **노드 스키마:**
  - `id`: 계층 식별자 (`alcohol.beer`, `alcohol.wine`, `clothing.swimwear`, `activity.fire_show`, `geo.incheon_cheongna` 등)
  - `category`: 도메인 (`beverage`, `food`, `clothing`, `people`, `animal`, `nature`, `vehicle`, `place`, `activity`, `document`, `object`, `location`)
  - `triggers`: 사진 캡션/키워드/태그에서 검출할 구체 단어 목록
  - `equivalents`: 100% 동일한 뜻의 1:1 동의어 (`['개', '강아지', '반려견', '애완견', '멍멍이', '강쥐', 'dog', 'puppy']`)
  - `parents`: **`Is-A`("A는 B의 일종이다") 단방향 상위 부모 개념어** 및 1글자 뿌리 명사 (`맥주 ➔ ['술', '주류', '음료', '술자리', '잔', '컵']`)
  - `blockWords`: 인덱싱 시 부분 문자열 착시를 일으키는 제외 단어 목록

### 2.2 인덱싱 시점 상·하위어 자동 상속기 (`poc/build_korean_photo_ontology.mjs`)
- **시각 필드 vs 지리 필드 분리 스캔:**
  - 일반 시각 사물/활동 노드(`category !== 'location'`)는 오직 시각 필드(`primaryTag`, `keywordsKo`, `captionKo`, `captionEn`)만 스캔합니다.
  - 지리 노드(`category === 'location'`)는 EXIF GPS 지명 필드(`locationTag`, `locationKo`, `locationKeywords`)까지 함께 스캔하여 상위 행정구역(`청라 ➔ 서구, 인천, 수도권`, `여의도 ➔ 영등포, 한강, 서울, 수도권`, `속초 ➔ 강원도, 동해`)을 자동 상속합니다.
- **산출물 (`poc/results/corpus_550_semantic_index.json`):**
  - 550장 각 사진 객체에 `ontologyPrimaryTags: string[]`과 `ontologyCaptionTags: string[]`를 영구 저장합니다.

## 4. 미니멀 3대 탭 네비게이션 & 검색 결과 연사 묶기 (`DesktopDashboard.tsx`, `MobileAppView.tsx`, `aiEngine.ts`)

### 4.1 미니멀 3대 탭 구조
- PC 상단 헤더 및 모바일 하단 바에 깔끔한 3대 탭을 배치:
  1. `🔍 AI 검색`: 자연어 문장/음성 검색 + 연사 묶음 결과 그리드
  2. `🧹 스마트 정리 (N)`: 클리어몬스터 Lite 4대 탭 및 바둑판 Pick 정리 화면 (`N`은 현재 정리 후보 장수)
  3. `⚙️ 내 기기 & 백업`: 로컬 사진 폴더(`D:\SaySee\test_photos`) 및 정리대기함 연결 상태, 휴대폰 QR 연결 및 Wi-Fi Direct P2P 자동 백업 옵션 설정

### 4.2 검색 결과 동일 연사 그룹 묶기 (`groupBurstSearchResults` — `[❐ N장 연사]`)
- 검색 결과(예: `"여의도 한강공원에서 친구들과 걷는 뒷모습"` 14장)에서 똑같은 연사 사진 5장이 나란히 도배되지 않도록, 다음 기준으로 인접 연사 그룹을 1장의 대표 카드로 묶어 표시합니다:
  1. 동일 `dupGroupId` 클러스터에 속한 사진
  2. 촬영 시각 차이 $\Delta t \le 6\text{초}$ 이고 64-bit Perceptual dHash 해밍 거리 $\le 10$인 연속 촬영 사진
  3. 동일 장면 클러스터(`clusterId`) 내에서 $\Delta t \le 4\text{초}$ 간격으로 연속 촬영된 사진
- 묶인 카드 좌측 상단에 **`[❐ 5장 연사]`** 배지를 표시하며, 카드 클릭 시 상세 모달(`PhotoDetailModal.tsx`) 상단에서 묶인 연사 전체를 한눈에 비교하고 **`[현재 사진 1장만 남기고 나머지 연사 정리대기함 격리 (Pick)]`**를 즉시 실행할 수 있습니다.
- 또한 사진 썸네일 하단 15%~20% 영역에 은은한 블랙 그라데이션(`from-black/90 via-black/55 to-transparent`)을 적용하여 날짜와 핵심 태그의 가독성을 확보했습니다.

## 5. 클리어몬스터 (스마트 정리) 4대 탭 & PC 바둑판 Pick UI (`src/services/aiEngine.ts`, `src/components/SmartTrashView.tsx`)

### 5.1 Bes2 쓰레기 정의 기준 이식 및 4대 탭 분류 (`TrashCategory`)
`D:\Bes2\분석로직.md`의 쓰레기 텍스트 정의(임시 기록용 사진, 부품·사물 접사, 스크린샷, 초점 붕괴 및 Positive Filter 보호 규칙)를 참고하여 4대 탭으로 정밀 분류합니다:
1. **`① 동일한 복사본·연사` (`duplicate`):**
   - 파일 바이너리 MD5 완전 일치 복사본(`(0)`, `(1)` 사본 파일) 및 Perceptual dHash + 연속 촬영 시각 기준 동일 연사 그룹.
2. **`② 주차장·영수증·서류 메모` (`memo`):**
   - 주차장 기둥 번호(`#주차장·기둥`), 종이 영수증/전표, 조립 설명서/문서(`#문서·설명서`), 신분증/여권 사본(`#문서·신분증`), 택배 송장/박스(`#택배·상자`), 현수막/안내판(`#현수막·안내`), 전자기기 어댑터·케이블·부품 접사(`#부품·접사`).
   - **Positive Filter (오탐 방지):** 식당 음식·와인병 라벨(`#식당·음식`, 예: 말벡 레드와인 병)은 글씨 밀도가 높아도 일상 추억 사진으로 보호하여 메모/서류 쓰레기에서 제외합니다.
3. **`③ 스크린샷` (`screenshot`):**
   - 카메라 EXIF 메타데이터가 없고 파일명(`Screenshot_`, `스크린샷`, `화면 캡처`, `KakaoTalk_`) 또는 화면 캡처 특성을 가진 이미지.
4. **`④ 심한 흔들림·오촬영` (`blurry`):**
   - 4x4 격자 16개 셀 전체의 라플라시안 선명도(`maxCellLap < 9.5`)가 무너진 초점 실패 사진 또는 평균 휘도가 극단적으로 어둡거나(`avgBrightness < 26`) 하얗게 날아간 노출 실패 사진.

### 5.2 연사/중복 PC 바둑판(Grid) 1-Click Pick UI (`SmartTrashView.tsx`)
- `① 동일한 복사본·연사` 탭 상단에 초록색 **`[✓ 원본 1장 안전하게 보존됨]`** 안심 배지를 표시합니다.
- 각 연사·중복 클러스터의 사진들을 PC 화면에서 **3×3 / 4×4 바둑판(Grid)** 배열로 시원하게 펼쳐 보여주며, 유저가 눈으로 비교해 마음에 드는 **베스트 컷 1장만 클릭(`Pick`)**하면 선택된 1장은 보존되고 나머지 사본들이 즉시 `[세이씨_정리대기함]`(`test_photos_quarantine`)으로 격리됩니다.
