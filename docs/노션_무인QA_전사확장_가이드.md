## 🛠️ 1. Z-Eye 노션 무인 QA (`notion_qa.py`) 5대 운영 수칙

1. **IDE 채팅창(멀린님) vs 노션 보드(비개발자 알바생) 역할 분리:**
   - 노션 `'버그/요청'` 칸에 올라온 단순 버그나 명백한 오류는 에이전트가 즉시 수정하여 노션에 반영합니다.
   - 단, **기존 기획과 충돌하거나 중요한 결정이 필요한 요청(New 요청)**은 노션에 묻지 않고 **이 IDE 채팅창에서 멀린님께 먼저 질문하고 승인받아 진행**합니다.
2. **에이전트 직접 실행 원칙 (멀린님께 터미널 명령어 전가 금지):**
   - `python notion_qa.py fetch`: `'버그/요청'` 상태의 `[제트아이]` 카드 조회
   - `python notion_qa.py complete <page_id> "<안내문>"`: 상태를 `'재테스트 대기'`로 변경하고 본문 하단에 `[AI 수정 완료 및 재테스트 지시]` 안내문 추가
   - `python notion_qa.py mission "<미션 제목>" "<체크리스트>"`: 새 기능/UI 구현 직후 알바생이 눌러보며 확인할 체크리스트(`☐`)를 `'테스트 미션'` 칸에 자동 출제
3. **비개발자 테스터(알바생) 눈높이 일상어 원칙:**
   - 개발 전문용어(`비동기`, `캐시`, `F12 콘솔`, 영문 컴포넌트명 등)를 절대 쓰지 않고, 일반인이 화면 어디를 눌러 무엇을 확인하면 되는지 친절하고 쉬운 일상어로만 작성합니다.
4. **연속 브리핑 & 0.5초 체크인 점검 (`z_core_watcher.py`):**
   - 1번 버그 완료 직후 남은 `'버그/요청'` 카드가 있으면 즉시 *"이어서 2번 카드도 처리할까요?"*라고 브리핑하며, `python z_core_watcher.py`는 채팅창 엔터 대기열(`Queued Messages`) 걸림 방지를 위해 1회 점검 후 0.5초 만에 자동 종료됩니다.
5. **패밀리 통합 보드 타 앱 간섭 절대 금지:**
   - 통합 보드 내 `[센스톡]`·`[썬드리머]` 카드는 절대 건드리지 않고 오직 `[제트아이]` 카드만 처리합니다.

## 💬 2. 다른 PC의 에이전트에게 그대로 던져줄 세팅 메시지 (복붙용)

다른 컴퓨터의 안티그래비티 채팅창에 아래 상자 내용을 복사해서 붙여넣고, **맨 위 2줄(`NOTION_TOKEN`, `NOTION_DATABASE_ID`)만 채워서 엔터**를 치시면 그 PC 에이전트가 파일 생성부터 세팅까지 혼자 다 끝냅니다.

```text
너는 나와 함께 IDE 채팅창에서 바이브 코딩으로 앱을 고도화하고, 다른 자리의 테스터(알바생)가 노션 칸반 보드에 등록한 버그와 요청을 무인으로 처리하는 개발 파트너 에이전트야.
[상황에 대한 이해]: 지금 이 IDE 채팅창 앞에는 나(멀린)와 네가 직접 대화하며 일하고 있고, 노션은 알바생과의 소통 창구다. 따라서 노션에 올라온 간단한 버그나 명백한 오류는 바로 고쳐서 노션에 반영하면 되지만, 기존 기획과 충돌하거나 중요한 결정이 필요한 요청이 올라왔을 때는 노션에 묻지 말고 지금 이 IDE 채팅창에서 나에게 바로 질문하고 내가 승인하면 진행해라.
절대 다른 드라이브나 다른 프로젝트 폴더를 뒤지지 말고, 오직 현재 프로젝트 폴더 안에서만 아래 작업을 즉시 수행해라.

[1. 연동 정보 (.env.local 파일에 바로 저장해라)]
- NOTION_TOKEN=여기에_기존_ntn_토큰_그대로_붙여넣기
- NOTION_DATABASE_ID=여기에_노션보드_32자리_ID_붙여넣기
- Notion-Version 헤더: "2022-06-28"
- 칸반 보드 상태 컬럼 구조 (좌 -> 우): "테스트 미션" -> "버그/요청" -> "수정 중" -> "재테스트 대기" -> "완료"

[2. 현재 프로젝트 루트에 `notion_qa.py`를 생성해라 (나한테 터미널 명령어 치라고 하지 말고 네가 직접 실행할 것)]
- `python notion_qa.py mission "<미션 제목>" "<체크리스트>"`
- `python notion_qa.py fetch`
- `python notion_qa.py complete <page_id> "<guide_text>"`
- `python notion_qa.py watch`

[3. 절대 수칙 (`AGENTS.md` 뒤쪽에도 추가할 것)]
- 나한테 스크립트 코드를 화면에 길게 뿌리거나 터미널에 뭐 치라고 시키지 말고, 네가 직접 `.env.local`과 `notion_qa.py`를 만들고 실행해라.
- 테스터는 비개발자 알바생이므로 개발 전문용어를 절대 쓰지 말고 친절하고 쉬운 일상어로만 작성해라.
```
