## 2. 검색 탭 UX 원칙: 첫 검색 시 '동영상' 기본 오픈 & 재검색 시 '마지막 선택 탭 유지'

1. **첫 검색 시 임팩트 중심 자동 포커스:**
   - 처음 검색을 실행하면 3개 탭에 찾은 건수를 모두 배지로 표시하되(`🎬 동영상 (2)` · `🖼️ 사진 (7)` · `📁 문서 (1)`), 가장 시각적 임팩트가 큰 **`🎬 동영상` 탭을 기본(Default)으로 오픈**하여 어필/마케팅 목적을 달성합니다.
2. **재검색 시 마지막 선택 탭 유지:**
   - 유저가 특정 탭(예: `🖼️ 사진` 또는 `📁 문서`)을 클릭해 보다가 다시 검색을 실행하면, 각 탭의 결과 숫자는 배지에 갱신하되 **유저가 마지막으로 선택했던 탭이 디폴트로 열린 구조를 유지**합니다.
3. **검색 엔진 코어 Fix 보존 ("768차원 벡터 엑셀 + 온톨로지/지명 브레이크"):**
   - `runHybridCorpusSearch` 하이브리드 구조 및 복합 명사/지명 엄격 `AND` 교집합 원칙(일치 사진 없을 시 정직하게 `0장` 반환)을 철저히 유지합니다.

## 3. 만국공통 '세이씨 여권(SaySee Face Passport)' & 인물별 고유 타임라인 바구니 원칙

1. **다년도·다각도(정면·측면·야외·선글라스·야간) 최대 변별력 자동 추출:**
   - 동일 인물의 대표 시드를 뽑을 때 매년 똑같은 정면 사진만 뽑지 않고, 연도를 분산함과 동시에 촬영 조건과 각도가 최대한 다른 베스트 컷 조합(`정면·선명`, `측면·미소`, `야외·노을`, `선글라스·역광`, `야간·실내` 5대 슬롯)을 내부에서 자동 결합합니다.
2. **바구니 기준 연도는 '방(Room)'이 아닌 '각 인물(Person ID)의 최초 생성 연도'에 귀속:**
   - 10년(성인) / 5년(미성년자) 바구니의 기준 연도는 '각 인물의 시드가 최초 생성된 연도'로 고정합니다. 한 라운지 안에 2026년 세팅 기존 가족(`2026~2017`)과 2029년 신규 합류 처가 식구(`2029~2020`)가 섞여 있더라도 각 인물은 본인의 고유 연도 바구니를 독립 유지합니다.
   - 시간이 경과해 미래 연도(예: 2027년~) 사진이 들어오면 기존 바구니를 보존한 채 위로 **미래 바구니(`2027~2036` / `2027~2031`)를 자동 확장(Forward Bucket)**합니다.
3. **무질문 0.1초 자동 장착 & 방별 별명(Room Persona) 독립 매핑:**
   - 새 라운지 개설/입장 시 *"시드를 가져올까요?"* 질문 팝업 없이 이메일 계정에 귀속된 여권 시드가 0.1초 만에 자동 장착됩니다 (`[🛂 세이씨 여권 자동 연동됨]`).
   - 시드(768차원 벡터 + 연도 바구니)는 100% 공유하되, 방마다 부르는 호칭(`우리집: 👑 멀린` ↔ `처가방: 👑 둘째사위` ↔ `본가방: 👑 큰아들(진욱)` ↔ `스쿨방: 지우짱`)만 독립 매핑됩니다.

## 4. 화면 정화(UI Diet) 4대 규칙 & `👑 방장` 호칭 통일 원칙

1. **`👤 개인 라운지`에서 얼굴/여권 박스 100% 제거 (완전 비노출):**
   - 개인 라운지는 나 혼자 내 기기를 검색·정리하는 공간이므로 `FaceMemberInlineBar` 및 얼굴 등록 박스를 아예 렌더링하지 않습니다.
2. **가로 6열 미니 아바타 나열 폐기 ➔ '1장씩 스무스 사각형 카드 (등록 완료 시 Auto-Hide 완전 소멸)':**
   - 이미 등록된 멤버는 상단 라운지 바의 깔끔한 별명 알약 버튼으로만 노출하고, 복잡한 연도 바구니 수치는 `[🛂 여권 관리]` 모달 안으로 숨깁니다.
   - 확인이 필요한 항목이 있을 때만 **큼직한 사각형 사진(`rounded-2xl`) 1장씩** 카드로 띄워 1줄 질문(`"😎 선글라스 낀 이 분도 [👑 멀린]님 맞죠?"` / `"👋 새로 등장한 이 분의 별명을 적어주세요"`)과 **`[⭕ 맞아요! 등록]`** 버튼으로 확인받으며, 확인이 모두 끝나면 **카드 박스 전체가 화면에서 완전히 사라집니다(`return null`)**.
3. **어르신·가족 친화적 문구 정돈:**
   - 화면에 기계적인 개발자 용어(`3단 집단지성 프로토콜`, `노약자 모드`)를 노출하지 않고, **`✨ AI 얼굴 자동 매칭 도우미`**와 **`⚡ 확인 건너뛰고 사진만 바로 올리기 (방장이 나중에 정리)`**로 다정하게 표기합니다.
4. **`호스트 ➔ 👑 방장` 교체 및 왕관(`👑`) 계급장 표시:**
   - 모든 `'호스트'` 표기를 **`👑 방장`**으로 통일하고, 방 개설자의 별명 알약 앞에 항상 **`👑` 왕관 아이콘**(`[👑 멀린]`, `[👑 둘째사위]` 등)을 표시합니다.

## 5. 개인 라운지 3대 AI 몬스터 정의 · `⏳ AI 인덱싱 대기실` · 4대 라운지 확정 요금제 정책

1. **개인 라운지 3대 AI 몬스터 정의 및 상단 가격 배지 비노출(하단 통합 배치) 원칙:**
   - 상단 3열 카드에는 가격을 표시하지 않고 하단 요금 섹션에 모아서 표시합니다.
   - **`AI 투시검색 몬스터`**: 사진·동영상 프레임별, 모든 서류파일의 내용을 투시하듯 1초 만에 찾아주며, 동일 내용 중복 파일 찾아 정리를 도와주며 사진 연사도 쉽게 정리할 수 있게 하는 부가서비스를 제공합니다.
   - **`AI 클린 몬스터`**: 모바일·PC 바탕화면 정리 및 전기·CPU·메모리 먹는 유령 모듈 제거를 종합검진하고 대화형 상담 가이드로 정리를 도와줍니다.
   - **`AI 설정 몬스터`**: 핸드폰의 특정 설정이나 앱의 어떤 기능으로 세팅하고자 할 때, 복잡한 설정 메뉴를 찾지 않고 **AI 음성으로 설정을 직접 찾아주고 세팅을 도와주는** 음성 도우미입니다.
2. **`⏳ AI 인덱싱 대기실` = AI 색인 시간 벌기용 안심 버퍼:**
   - 수동 검열 공간이 아니라, 멤버들이 올린 고화질 사진·영상이 방장의 마스터 PC(또는 24시간 GPU 서버 도우미)에서 Gemma 2 768차원 인덱싱 및 13KB 캐시 변환을 마치는 동안 머무는 버퍼입니다.
3. **5대 시크릿 라운지 초심플 기본 요금제 (마스터 1인 결제 ➔ 초대 멤버/팀원 전원 100% 무료):**
   - **`👤 개인 라운지`**: AI 클린 몬스터 `기기 1대당 1,900원` / AI 투시검색 몬스터 `월 1,900원 (연 19,000원 · 초기 100명 평생권)` / AI 설정 몬스터 `구독 시 무제한 포함`
   - **`👨‍👩‍👧‍👦 패밀리 라운지`** *(최대 인원수 제한 문구 삭제)*: `🏠 우리집 단독` `월 5,900원 (연 59,000원)` / `👨‍👩‍👧‍👦 양가 통합권 (3방 분리)` `월 8,900원 (연 89,000원)`
   - **`⛳ 클럽 라운지`** *(방 1개 기준)*: 소형(~20명) `월 4,900원 (연 49,000원)` / 중형(~100명) `월 7,900원 (연 79,000원)` / 대형(무제한) `월 14,900원 (연 149,000원)`
   - **`🎒 스쿨 라운지 (초·중·고 반/동아리 특가 월 900원)`**: 인원 무제한 단일가 `월 900원 (연 9,000원)` *(학생증 로컬 RAM 0.1초 OCR 판독 후 즉시 폐기)*
   - **`💼 업무 라운지 (SOHO · 기업 팀 유료 클라우드 100% 대체)`**: SOHO 팀(10인) `월 9,900원 (연 99,000원 · 초기 100명 평생권)` / 기업 무제한 `월 19,900원 (연 199,000원 · 초기 100명 평생권)` — 듀얼 뷰(`🔍 AI 투시검색 뷰` vs `🗂️ 윈도우 폴더 트리 뷰`) + 마스터 PC 오프라인 시 0.1초 만에 열리는 `30KB 선행 캐싱 프리뷰` + `[💽 내 PC 윈도우 탐색기에 ‘업무 드라이브(S:)’ 자동 마운트]` + `[🔒 편집 중 (이름)]` 동시 편집 충돌 방지(File Lock) 기본 제공.
4. **`⚡ 24시간 GPU 클라우드 서버 도우미`:**
   - 방장 PC OFF 시 24시간 동안 클라우드 GPU가 실시간 인덱싱·배포를 대행하고, 방장 PC가 켜지면 원본 이관 후 클라우드에서 100% 자동 소각합니다 (`개인·패밀리·스쿨·소형클럽 일 1,000원` / `중형클럽 일 2,000원` / `대형클럽 일 3,000원`).
