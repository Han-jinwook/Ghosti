PART 1 · CORE DEFINITION

1. 귀신같이(Ghosti) 핵심 정의 및 원엔진·투도어 구조

공식 카테고리 및 슬로건
  • • 카테고리: PC·모바일 초능력
  • • 메인 슬로건(H1): 내 PC와 모바일에 1초 초능력을
  • • 서브 슬로건(H2): 느려진 PC는 새것처럼 깨우고, 숨은 파일·사진·영상은 열지 않고 1초 만에 찾아냅니다.
  • • 한 줄 정의: 지금 쓰는 내 PC와 모바일의 모든 답답함을 1초 만에 풀어내는 광고 0%·클라우드 월세 0원 초능력입니다.
원엔진 · 투도어 (One-Engine · Two-Door) 분리 원칙
  • • 단일 엔진 공유: 로컬 PC 엔진(Merlin_Z_Core, 포트 127.0.0.1:5199) 1개를 두 서비스가 공유합니다.
  • • Door 1 — 귀신같이 본체 (ghosti.sundreamer.app): 기기 청소·문서/사진/영상 1초 내용 검색·무제한 사진 공유·내 기기 통합 Pro·팀 공용 폴더(S:) 전담. (본체 단독 사용 시 Ctrl+0은 귀신검색창 소환)
  • • Door 2 — 귀신Key (ghostkey.sundreamer.app): 무버튼 한영 오타 자동 교정, 1→2→3 순차 붙여넣기, [1]~[5] 텍스트·PDF·번호 성형, F1~F12 상용구, 7일 클립보드 전담 스핀오프 앱. (단독 월 1,900원 · 본체 Pro 구독 시 무료 자동 합체)
PART 2 · WORKSPACE & 5-MENU SUMMARY

2. 화면 구성 (3단 워크스페이스) 및 본체 5단 메뉴 요약표

좌측 사이드바

상단 3대 무료 메뉴(1~3번) + 하단 유료 확장 2종(4~5번) + 최하단 패밀리 앱 런처(귀신팸).

중앙 메인 작업창 & 우측 비서 채팅창

중앙에는 선택한 메뉴의 작업 화면이 열리고, 우측에는 실적을 모아 1회성 대답 칩으로 보고하는 귀신비서 채팅창이 배치됩니다.

우측 상단 프로필 & 귀신여권

이메일 6자리 OTP 통합 로그인(SSO), 가족 얼굴 실명 등록(귀신여권), 코인 지갑·선물함·1:1 문의방 통합 모달.

메뉴 번호·명칭 요금 구분 핵심 기능 요약
1. 귀신비서 평생 무료 사진 용량 정리 4대 탭(중복·문서·캡처·흔들림), 은행 보안프로그램 비삭제 절전, 무광고 1초 압축, 휴지통 복원.
2. 귀신검색 내 PC 평생 무료 Ctrl+0 / Ctrl+우클릭 소환. 파일 열지 않고 문서 본문·사진 속 글자(OCR)·동영상 장면·구글독스(G:) 1초 검색 및 무료 음성 낭독(현수·선희).
3. 사진 공유 인원·장수 무제한 0원 가족(우리집·본가·처가)·동호회·동창회 원본 화질 앨범. 카톡 만료 없이 얼굴(귀신여권)·날짜별 자동 분류. (개인 사진·영상 전용)
4. 내 기기 통합 Pro 월 3,900원 (30일 무료체험) 내 폰·집컴·회사컴 실시간 원격 통합 검색 및 파일 전송 + 별도 사진·표 OCR 창 & 귀신 라벨러(YYMMDD 자동 작명) 단독 해금 + 귀신Key 무료 합체.
5. 업무 공유 (공용 폴더 S:) ~5인 월 9,900원~ (팀원 0원) 비싼 NAS·클라우드 인당 요금 없이 사무실 대장 PC를 전 직원 탐색기 S: 드라이브로 연결. 예비 서버 이중화·권한 관리·사내 통합 검색. (30일 무료체험)
PART 3 · OFFICIAL QA RULES & SPECIFICATIONS

3. 귀신같이 작동 규칙·기준표 (QA 판정 기준)

[기준 1] 전사·노션 QA 3단 공식 호칭 분리 (모바일을 ‘엔진’이라 부르는 것 금지)
구분 공식 고정 호칭 대상 실체 담당 범위 및 반영 방식
1. PC PC 엔진 (Z코어) Merlin_Z_Core.exe (127.0.0.1:5199) PC 로컬 기능(PP-OCRv5, PDFium·HWP 해독, Ctrl+0 귀신검색창, G:/S: 드라이브, 보안모듈 절전·압축·복구) 담당
2. 웹 웹 화면 (웹 UI) https://ghosti.sundreamer.app 웹 UI 레이아웃, 문구, 채팅 라우터, 공유방 화면, 요금제 안내·결제 모달 담당 (배포 즉시 반영)
3. 모바일 모바일 앱 (안드로이드 앱 / 아이폰 앱) Google Play (.aab) / Apple TestFlight (.ipa) 스마트폰 갤러리 공식 휴지통 이동, 포토 피커, 안드로이드 클리너 삭제 인텐트, 모바일 푸시 담당
[기준 2] 안드로이드 앱 vs 아이폰 앱 영구 작동 규칙 (QA = 정식 출시 100% 동일)
1) 악성 클리너(CleanX 등 100종) 3단 구출: 안드로이드 전용 / 아이폰 비노출

• 안드로이드 앱: 주간 자동결제 유도 악성 청소앱 감지 시 [① 앱 즉시 삭제 · ② Google Play 정기구독 해지 · ③ 계정 권한 끊기] 3단 구출 배너가 정상 노출됩니다.

• 아이폰 앱 (비노출 = 정상): Apple iOS 샌드박스 정책(Guideline 2.5.2)상 타사 설치 앱 스캔이 불가하므로 클리너 구출 배너가 뜨지 않는 것이 정상입니다. 채팅으로 질문 시 [아이폰 설정 > 내 이름(Apple 계정) > 구독] 경로를 안내합니다.

2) 모바일 앱 내 요금표·결제창 상시 비노출 & OS 공식 휴지통 이동

• 모바일 요금표 비노출: 안드로이드 앱과 아이폰 앱 모두 앱 내부에서는 요금표 모달(PricingModal), 월 구독료 배지, 외부 결제 유도 버튼을 상시 100% 비노출합니다 (요금 확인·결제는 PC 웹 화면 전담).

• OS 공식 휴지통 이동: 사진 정리 승인([OK]) 시 안드로이드(MediaStore.createTrashRequest)와 아이폰(PHAssetChangeRequest.deleteAssets) 모두 OS 공식 확인창을 거쳐 스마트폰 기본 갤러리 휴지통(30일 보관)으로 이동합니다.

메뉴 1. 귀신비서 (평생 무료)

담당: 1귀신
  • • 좌측 작업창 (사진 정리 4대 탭): ① 중복 사진 & 연사(베스트 1장만 남김), ② 문서·메모·영수증, ③ 스크린샷·캡처, ④ 흔들린 사진. 삭제 파일은 영구 삭제되지 않고 OS 휴지통 및 복원 기록으로 이동합니다.
  • • 우측 비서 채팅창: 뒤에서 수행한 실적을 모아 보고하며, 말풍선 하단 1회성 대답 칩은 클릭 즉시 소멸됩니다.
  • • PC 상시 케어 3종: ① 은행·관공서 보안프로그램 비삭제 자동 절전(은행 접속 시에만 기상), ② 다운로드 파일 무소음 보호(Windows 기본 보안 엔진 직결 · 광고 0%), ③ 무광고·한글 깨짐 방지 1초 압축 풀기(탐색기 더블클릭 / 우클릭 [귀신같이로 깔끔하게 풀기]) 및 휴지통 $I 헤더 즉시 복원.

메뉴 2. 귀신검색 및 귀신검색창 (내 PC 평생 무료)

담당: 2귀신
  • • 호출 방식 (2종 단일화): ① 키보드 Ctrl + 0, ② 마우스 Ctrl + 우클릭. (구형 우클릭 0.35초 꾹 제스처는 영구 폐기)
  • • 창 크기 전환: 상단 [크게(갤러리) / 작게] 2모드로 전환되며, 작게 모드에서는 결과 양과 미리보기에 따라 슬림 바(520px) ↔ 중형(960×640)으로 자동 조절됩니다.
  • • 검색 및 낭독 범위: 내 PC 문서(PDF·엑셀·워드·HWP 5만자)·사진 속 글자(PP-OCRv5)·동영상 장면·탐색기 G: 드라이브(구글독스·시트) 본문을 열지 않고 1초 검색하며, 무료 신경망 음성(현수 기본 안내 · 선희 문서 낭독)으로 횟수 제한 없이 읽어줍니다.
  • • 카톡 직행 장전 & 단골 AI 바톤터치: 파일 검색 후 카카오톡 대상 대화방에 파일을 자동 장전해 주거나(전송은 사용자가 클릭), 고난도 질문 시 사용자의 단골 AI(Gemini 등) 입력창에 문서 전문과 질문을 자동 세팅해 연결합니다.

메뉴 3. 사진 공유 (인원·장수 무제한 평생 0원)

담당: 3귀신
  • • 3대 공유방: ① 가족(우리집·본가·처가 분리), ② 동호회·모임, ③ 동창회.
  • • 작동 규칙: 개인 사진·영상 전용이며, 카톡 유효기간 만료나 화질 압축 없이 원본 그대로 공유됩니다. 귀신여권 얼굴 인식으로 특정 인물이 나온 사진만 즉시 모아볼 수 있습니다.

메뉴 4. 내 기기 통합 Pro (월 3,900원 / 연 39,000원 · 카드 없는 30일 무료체험)

담당: 2귀신(OCR·라벨러) · 3귀신(기기 통합)
  • • 내 모든 기기 원격 통합 검색 & 전송: 동일 이메일로 로그인한 스마트폰·집 PC·회사 PC의 사진과 문서를 귀신검색창 하나에서 통합 검색하고 1초 만에 주고받습니다.
  • • Pro 단독 해금 기능 2종: ① 별도 사진·표 OCR 창(폰 영수증·서류 촬영 시 표와 글자를 즉시 추출·복사), ② 귀신 라벨러(YYMMDD_ 날짜 3원칙 자동 파일명 정리).
  • • 귀신Key 무료 합체 & 체험 만료 규칙: 본체 Pro 구독 시 자매 앱 귀신Key(월 1,900원)의 모든 기능이 추가 요금 없이 자동 해금됩니다. 30일 무료체험(Opt-in) 만료 시 자동 결제 없이 원격 기기 노출만 OFF되며, 이미 로컬 PC로 복사·정리해 둔 원본 파일은 영구 보존됩니다.

메뉴 5. 업무 공유 — 공용 폴더 S: 드라이브 (~5인 소호 월 9,900원~ · 팀원 인당 과금 0원 · 30일 무료체험)

담당: 4귀신
  • • 사내 S: 드라이브 생성: 별도 NAS나 인당 클라우드 요금 없이 사무실 메인(대장) PC를 거점으로 전 직원 윈도우 탐색기에 S: 드라이브를 마운트하고 사내 전체 문서·도면·현장 사진을 1초 통합 검색합니다.
  • • 데이터 이중화 및 보안: 사내 예비 서버(1·2호) 실시간 증분 백업, 직급·팀원별 폴더 권한 제어, 퇴근 후 야간 초절전 무중단 터널(외부 서버 저장 0 Byte, 종단간 암호화 E2EE)을 기본 탑재합니다.
