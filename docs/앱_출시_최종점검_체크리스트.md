## 2. Windows 데스크톱 원 코어 (`Merlin_Z_Core_Setup.exe`) 배포 & MS 코드 서명 체크리스트

- [x] **단일 표준 포트(`127.0.0.1:5199`) 원 코어 통합:** `merlin_z_core_daemon.py` 내부에 `plugin_zeye_os`, `plugin_senstalk`(2,439줄), `plugin_aggrofilter` 3종 소프트웨어 플러그인 기본 내장.
- [x] **MS EV/OV 코드 서명 파이프라인 (`build_signed_merlin_z_core.py`):** PyInstaller 빌드 직후 `signtool.exe` SHA-256 + RFC3161 타임스탬프 서명 및 `signtool verify /pa` 자동 검증으로 Windows SmartScreen 경고 원천 제거.
- [x] **온디바이스 모델 가중치 자체 R2 CDN 마스터 사본 배포:** 외부 HuggingFace 의존 없이 당사 스토리지 마스터 사본(SHA-256 검증)으로 고속 배포.
