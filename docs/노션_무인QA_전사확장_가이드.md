# 📋 노션(Notion) 무인 QA 파이프라인 — 다른 알바생 & 타 프로젝트 에이전트 확장 가이드

> **핵심 결론:** **노션 API 토큰(`NOTION_TOKEN`)은 새로 발급받으실 필요가 전혀 없습니다!**  
> 어제 발급받으신 마스터 토큰(`ntn_...`) **딱 1개**로 16개 모든 패밀리 앱과 여러 명의 알바생(테스터)을 무제한 연결할 수 있습니다.

---

## 🔑 1. 왜 노션 API 토큰을 새로 안 파도 되나요?

- 노션에서 발급받은 `ntn_...` 토큰은 특정 페이지 1개 전용이 아니라, **멀린님이 `[연결(Connections)]`을 허용해 준 모든 노션 보드를 읽고 쓸 수 있는 만능 열쇠**입니다.
- 따라서 다른 앱(`센스톡`, `어그로필터`, `카페브레이커` 등)이나 새로운 알바생을 붙일 때도 **기존 토큰(`ntn_...`)을 그대로 똑같이 복사해서 쓰시면 됩니다.**

---

## 🚀 2. 다른 알바생 & 다른 에이전트 연결하는 3단계 (1분 컷)

알바생별로 담당 앱이 다를 때 가장 깔끔하고 안 섞이는 방법은 **노션 칸반 보드 페이지만 1초 만에 복제해서 나눠주는 방식**입니다.

### [Step 1] 노션에서 칸반 보드 페이지 복제하기 (멀린님 30초 작업)
1. 어제 만든 노션 QA 칸반 보드 페이지 왼쪽 메뉴에서 **`[···]` ➔ `[복제(Duplicate)]`**를 누릅니다.
2. 복제된 페이지 제목을 새 앱 이름(예: **`센스톡 QA 보드`**)으로 바꾸고, 새로 온 알바생에게 그 페이지 공유 링크만 줍니다.
3. 우측 상단 **`[···]` ➔ `[연결(Connections)]`**에 기존 노션 API 통합 앱이 연결되어 있는지 확인합니다 *(없으면 검색해서 클릭 1번으로 추가)*.
4. 브라우저 주소창(URL)에서 **`https://www.notion.so/` 뒤에 나오는 32자리 영문+숫자 ID**를 복사합니다.
   - *(💡 팁: 보드 전체 주소든, 보드 안의 첫 번째 카드 주소든 아무거나 복사하셔도 스크립트가 알아서 보드 ID를 찾아냅니다!)*

### [Step 2] 연결할 다른 앱 에이전트에게 말로 지시하기 (복붙용 메시지)
새로 연결할 프로젝트(예: `센스톡`, `어그로필터` 등) 채팅창을 열고 아래 메시지만 복사해서 던져주시면, 그 앱의 AI 에이전트가 알아서 세팅을 끝냅니다:

```text
우리 전사 표준 노션 무인 QA 파이프라인인 `D:\Z-Eye\notion_qa.py`를 이 프로젝트에도 연동해라.

1. `D:\Z-Eye\.env.local`에 있는 `NOTION_TOKEN` 값을 그대로 가져오고, 이 프로젝트의 `.env.local`에는 아래 보드 ID를 설정해라:
   - NOTION_DATABASE_ID=[여기에_새로_복제한_노션페이지_32자리_ID_붙여넣기]
2. 내가 터미널 명령어를 치지 않게 네가 직접 `python D:\Z-Eye\notion_qa.py fetch` 및 `complete`를 실행해서 처리해라.
3. 노션 카드 상태를 '재테스트 대기'로 바꾸고 하단에 `[AI 수정 완료 및 재테스트 지시]`를 적을 때는, 개발 전문용어를 절대 쓰지 말고 비개발자 알바생(일반인 테스터)이 화면 어디를 눌러 무엇을 확인하면 되는지 친절하고 쉬운 일상어로만 작성해라.
```

---

## 💡 3. (선택) 보드 1개에서 여러 앱·알바생을 한꺼번에 관리하고 싶을 때

만약 노션 페이지를 앱마다 따로 만들지 않고 **지금 보드 1개에 모든 버그를 다 모으고 싶으시다면**:
- 아무것도 새로 설정할 필요 없이, 알바생들에게 카드 제목 앞에 **`[센스톡] 로그인 버튼 안 눌림`**, **`[제트아이] 검색 멈춤`**처럼 **말머리(`[앱이름]`)**만 붙여서 등록하라고 하시면 됩니다.
- 그러면 각 앱 에이전트에게 *"노션에서 `[센스톡]` 버그만 읽어서 고쳐"*라고 한 마디만 하시면 기존 보드와 기존 토큰 그대로 즉시 돌아갑니다!

|---|---|---|
| **노션 API 토큰 (`NOTION_TOKEN`)** | **❌ 새로 안 파도 됨 (평생 1개 재사용)** | `D:\Z-Eye\.env.local`에 있는 `ntn_...` 토큰 그대로 사용 |
