# 📋 노션(Notion) 무인 QA 파이프라인 — 사무실 다른 PC · 다른 알바생 · 다른 에이전트 연결 가이드

> **핵심 요약:**
> 1. **노션 API 토큰(`NOTION_TOKEN`):** 새로 발급받으실 필요 없습니다! 어제 발급받으신 `ntn_...` 토큰 **1개를 다른 PC에도 그대로 전달**해 쓰시면 됩니다.
> 2. **파이썬 파일(`notion_qa.py`):** PC가 다르므로 각 PC의 프로젝트 폴더마다 있어야 합니다. 단, 멀린님이 파일을 USB나 카톡으로 옮기실 필요 없이 **아래 [Step 2] 메시지를 그 PC 에이전트에게 복붙해 주시면 에이전트가 스스로 `notion_qa.py`와 `.env.local`을 자기 폴더에 바로 생성**합니다. (남의 `D:\` 드라이브를 뒤지지 않습니다!)

---

## 🚀 [Step 1] 노션에서 새 알바생용 보드 만들기 (멀린님 30초 작업)

1. 노션에서 어제 만든 QA 칸반 보드 페이지를 **`[···]` ➔ `[복제(Duplicate)]`**로 복사합니다 (예: `센스톡 QA 보드`).
2. 복제된 새 노션 페이지 우측 상단 **`[···]` ➔ `[연결(Connections)]`**에 어제 만든 노션 API 통합 앱이 연결되어 있는지 확인합니다 *(안 되어 있으면 검색해서 클릭 1번으로 추가)*.
3. 새 알바생에게는 이 노션 페이지 링크를 주고, 멀린님은 **주소창(URL) 가운데 있는 32자리 영어+숫자 ID**를 복사합니다.

---

## 💬 [Step 2] 다른 PC의 에이전트에게 그대로 던져줄 메시지 (복붙용)

다른 컴퓨터의 안티그래비티 채팅창에 아래 상자 내용을 복사해서 붙여넣고, **맨 위 2줄(`NOTION_TOKEN`, `NOTION_DATABASE_ID`)만 채워서 엔터**를 치시면 그 PC 에이전트가 파일 생성부터 세팅까지 혼자 다 끝냅니다!

```text
너는 나와 함께 IDE 채팅창에서 바이브 코딩으로 앱을 고도화하고, 다른 자리의 테스터(알바생)가 노션 칸반 보드에 등록한 버그와 요청을 무인으로 처리하는 개발 파트너 에이전트야.
[상황에 대한 이해]: 지금 이 IDE 채팅창 앞에는 나(멀린)와 네가 직접 대화하며 일하고 있고, 노션은 알바생과의 소통 창구다. 따라서 노션에 올라온 간단한 버그나 명백한 오류는 바로 고쳐서 노션에 반영하면 되지만, 기존 기획과 충돌하거나 중요한 결정이 필요한 요청이 올라왔을 때는 노션에 묻지 말고 **지금 이 IDE 채팅창에서 나에게 바로 질문하고 내가 승인하면 진행**해라.
절대 다른 드라이브나 다른 프로젝트 폴더를 뒤지지 말고, 오직 현재 프로젝트 폴더 안에서만 아래 작업을 즉시 수행해라.

[1. 연동 정보 (.env.local 파일에 바로 저장해라)]
- NOTION_TOKEN=여기에_기존_ntn_토큰_그대로_붙여넣기
- NOTION_DATABASE_ID=여기에_새로_복제한_노션보드_32자리_ID_붙여넣기
- Notion-Version 헤더: "2022-06-28"
- 칸반 보드 상태 컬럼 구조 (좌 -> 우): "테스트 미션" -> "버그/요청" -> "수정 중" -> "재테스트 대기" -> "완료"
  (* 1번 '테스트 미션'은 네가 알바생에게 테스트할 체크리스트를 출제하는 칸이고, 2번 '버그/요청'은 알바생이 테스트 중 발견한 버그나 새로운 개선 요청(New 요청)을 적는 칸이다.)

[2. 현재 프로젝트 루트에 `notion_qa.py`를 생성해라 (나한테 터미널 명령어 치라고 하지 말고 네가 직접 실행할 것)]
- 스키마 자동 감지: 데이터베이스 조회 시 상태 컬럼('상태' 또는 'Status', status/select 타입)과 제목 컬럼(title 타입)을 자동 감지하도록 짜라. 만약 `NOTION_DATABASE_ID`에 카드(Page) ID가 들어오면 상위 `parent.database_id`를 자동 추적해라.
- `python notion_qa.py mission "<미션 제목>" "<체크리스트>"`: 새 기능/화면 작업이 끝났을 때 알바생이 순서대로 눌러보며 확인할 수 있도록 '테스트 미션' 칸에 체크리스트(☐) 카드를 자동 생성한다.
- `python notion_qa.py fetch`: 상태가 '버그/요청'(또는 기존 '발견된 버그')인 카드의 ID, 제목, 본문 블록 내용을 출력한다.
- `python notion_qa.py complete <page_id> "<guide_text>"`:
  1) 해당 카드 상태를 '재테스트 대기'로 변경한다.
  2) 카드 본문 맨 아래에 구분선과 함께 `"[AI 수정 완료 및 재테스트 지시]\n" + guide_text` 블록을 추가한다.
  3) 완료 직후 남은 '버그/요청' 카드가 있으면 자동으로 조회해 "이어서 2번 카드도 처리할까요?"라고 나에게 브리핑한다.
- `python notion_qa.py watch`: 평상시 AI 토큰 소모 0으로 파이썬이 15초마다 노션 '버그/요청' 컬럼만 감시하다가, 새 카드가 등록되는 순간에만 출력 후 종료(Exit 0)하여 너(AI)를 깨우게 해라.

[3. 절대 수칙 (`AGENTS.md`에도 반드시 박아둘 것)]
- 나한테 스크립트 코드를 화면에 길게 뿌리거나 터미널에 뭐 치라고 시키지 말고, 네가 직접 `.env.local`과 `notion_qa.py`를 만들고 실행해라.
- 알바생이 '버그/요청'에 올린 카드 중 단순 버그는 즉시 고치고, 기획 충돌이나 중요 결정이 필요한 건은 이 IDE 채팅창에서 나에게 먼저 물어보고 승인받은 뒤 진행해라.
- 테스터는 비개발자 알바생이므로, 노션 카드에 미션이나 `[AI 수정 완료 및 재테스트 지시]`를 적을 때는 개발 전문용어(비동기, 캐시, F12 콘솔, 영문 컴포넌트명 등)를 절대 쓰지 말고, 일반인이 화면 어디를 눌러 무엇을 확인하면 되는지 친절하고 쉬운 일상어로만 작성해라.

지금 바로 `.env.local`과 `notion_qa.py`, `AGENTS.md` 세팅을 끝내고, 노션 보드 연동이 잘 되는지 테스트해서 간단히 보고해!
```
