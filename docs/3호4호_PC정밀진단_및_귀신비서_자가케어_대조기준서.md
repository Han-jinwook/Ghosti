### ✅ 3.1 현재 귀신비서가 문답으로 **이미 완벽하게 처리할 수 있는 것 (약 70% 커버)**
1. **4호기의 악성 애드웨어 프로세스·서비스·스케줄러 1초 일괄 박멸 (`boot-lag-care` ➔ `clean_bloatware`)**:
   - 놀랍게도 `merlin_z_core_os.py`의 `KNOWN_SECURITY_PLUGIN_KEYWORDS` 및 `revival_task_names` / `revival_exe_names`에 이미 4호기의 감염 항목들(`CacheCloud`, `CacheConsole`, `CacheService`, `CloudTaskModule`, `CloudTaskUpdater`, `FrontServiceUpdater`, `StorageServiceManager`, `PCAppStore`, `febjb`, `MSLoad`, `NGPlus`, `RayItemGate`, `Task_DataSharingServices`, `Task_ShellExecuteAs`, `{E0477272-850C-4E8D-9C5C-A638D4800D1D}` HanCapturePlus Toast, `yoondisk`, `pennyroyal`, `clipdown`, `hncupdate`)이 **정확히 타겟팅되어 등록**되어 있습니다!
   - 알바생이 귀신비서에게 *"요즘 컴퓨터가 좀 느린데 상태 봐줘"* ➔ *"응 정리해줘"*라고 답하면 위 스케줄러 Disable + 서비스 중지 + 프로세스 강제 종료가 1초 만에 실행됩니다.
2. **은행·관공서 보안 프로그램 스마트 절전 및 기상 (`sleep_security_services` / `wake_security_services`)**:
   - `nProtect (nossvc/nosstarter)`, `AnySign`, `Delfino`, `CrossEX`, `MagicLine4NX`, `TouchEn`, `Veraport`, `Wizvera`, `IPinside`, `KeySharp`, `CrossCert` 등을 삭제하지 않고도 평시 CPU/RAM 점유율 0%로 재워두는 기능이 작동합니다.
3. **크롬 메모리 과점유 병목 안내 (`browserMemoryBottleneck`)**:
   - 3호기(크롬 5.6GB)와 4호기(크롬 5.6GB, 27개 프로세스)에서 크롬이 전체 RAM의 35% 이상을 먹고 있다는 사실을 정확히 실측하여 *"안 쓰는 크롬 탭을 닫아달라"*고 수치로 안내합니다.
4. **시작프로그램 개별 스위치 ON/OFF (`startup-list` / `startup-toggle`) & 개별 앱 심층 적출 (`deep-uninstall/scan` & `execute`)**:
   - 설치된 앱 목록을 띄워주고 유저가 고른 앱의 공식 언인스톨러 실행 + 잔여 캐시 폴더를 Windows 기본 **[휴지통]**으로 안전 이동시킵니다.

### 🚨 3.2 현재 귀신비서만으로는 **스스로 해결 못 하는 빈틈 (Gap 6가지 — 보강 필수!)**
