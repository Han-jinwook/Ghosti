## 🚀 완료 내역 (2026-11-27)

### 1. 귀신비서 추천 칩 문맥 정밀화 & 계약서 해지 조항 FAQ 가로채기 원천 차단 (`6ba6ffc`, `32023c3`)
- **도입 배경**:
  - 추천 칩에서 `"계약서에서 위약금이나 해지 나오는 문장 다 읽어줘"` 클릭 시, '해지' 단어로 인해 유료 구독 환불/해지 FAQ가 엉뚱하게 가로채는 문제 발생.
  - 전사 호칭 표준에 따라 가상 인물 예시 호칭 `'이쁜이'`를 현실적 비즈니스 호칭인 `'김 대리님'`으로 일괄 정규화.
  - LLM 연결 없이는 대답할 수 없는 비현실적 외부 AI 바통터치 질문 칩 배제.
- **구현 내용**:
  1. `CARE_COMMAND_RE` 및 `matchesPlaybookKeyword`에서 단순 '해지'가 계약서/문서 본문 읽기 질의와 결합된 경우 FAQ 트리거를 제외하도록 가드 구축.
  2. 견적서/계약서/세금계산서 질의 후 이어지는 추천 칩을 해당 문서 문맥(위약금, 공급가액, 입금계좌 등)에 맞춤형으로 동적 연동.
  3. `이쁜이` 예시를 `김 대리님`으로 단일 SSOT 통일.

### 2. 파일 부분 검색어(복합어) 매칭 및 사진 상세 폴더 열기 OS 연동 안정화 (`38adfd6`)
- **도입 배경**:
  - 검색창에서 `"종이세금계산서"`로 검색 시 `"종이"`, `"세금"`, `"계산서"` 중 일부만 입력하거나 띄어쓰기 유무에 따라 비서가 파일을 찾지 못하던 현상.
  - 사진 상세 모달에서 `[폴더 열기]` 클릭 시 OS 파일 열기 실패 시 모달이 닫히거나 사진이 사라지는 깜빡임 현상.
- **구현 내용**:
  1. `ghostSecretaryEngine.ts`와 검색 엔진 전반에 한국어 복합명사 부분 문자열 검색 로직 보강.
  2. 사진 상세 뷰어에서 폴더 열기 시 모달을 유지하며 백그라운드 Z-코어 `/__quarantine/open-folder` 및 `explorer.exe /select`로 100% 안전하게 위치 안내.

### 3. 파일 스마트 압축·해제 시 임의 압축 방지 및 대상 명시적 선택 절차 탑재 (`8c30211`, `73d91af`)
- **도입 배경**: 사용자가 비서에게 단순히 "파일 압축해줘"라고 했을 때 바탕화면이나 다운로드의 임의 파일을 무작정 압축해버리는 현상 방지.
- **구현 내용**:
  1. 압축 대상이 지정되지 않은 경우, 탐색기에서 선택된 파일이 있는지 확인하거나 압축할 파일/폴더를 먼저 선택하도록 확인 인터랙션 제공.
  2. 압축 풀기 시에도 대상 압축파일을 명시하고, 압축 해제 후 생성된 폴더명, 풀린 파일 목록, 저장 경로를 투명하게 브리핑하며 폴더 오픈.

### 4. 사내 보안앱 잠재우기 vs 완전 삭제 2트랙 분기 및 스토어 부품 링크 거절 (`bd92150`, `05ce21b`)
