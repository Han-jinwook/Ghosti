## 1. 체험판 아키텍처 & 무저장 휘발성(Zero-Retention) 보안 파이프라인 (`OnboardingModal.tsx`, `VoiceHeroStage.tsx`, `aiEngine.ts`)

### 1.1 자체 로컬 GPU 서버 '원본 미전송 & 0.1초 즉시 휘발(Zero-Retention)' 구조
- 무료 체험판 AI 인덱싱은 유저 기기에 무거운 Gemma 2 모델을 설치하지 않고, 경량 에이전트(APK/EXE)가 추출한 초경량 특징 데이터만 **자체 로컬 GPU 서버**로 보내 고속으로 768차원 벡터화한 뒤 인덱스만 돌려받는 구조로 작동합니다.
- **"전송 0건 / 비행기 모드 작동" 문구 전면 폐기 ➔ 정직하고 강력한 무저장 휘발성 보안 배지 적용:**
  - 스캔 화면 및 상단 글로벌 보안 바에 **`[🔒 안심 보안 파이프라인 가동 중: 무거운 원본 파일 미전송 / AI 분석 서버 하드디스크 저장 0건 (RAM 연산 후 0.1초 내 즉시 자동 파기)]`** 배지를 상시 표시합니다.

### 1.2 스캔 전 `[검진 구역 직접 허용]` 3대 안전 폴더 체크박스 (`trialScanPermissions`)
- 스캔 시작 전 온보딩 모달(`OnboardingModal.tsx`)에서 기본 3대 안전 폴더만 체크된 상태로 유저가 직접 허용하고 시작합니다:
  1. **`☑️ 사진첩 (DCIM / 카메라 앨범)`** — 중복·연사(dHash) 진단 + 최신 동영상 10개 키프레임 + 촬영 서류 스캔
  2. **`☑️ 다운로드 (Downloads)`** — 최근 다운로드된 보험 증권·영수증·계약서·매뉴얼 PDF/문서 스캔
  3. **`☑️ 바탕화면 (Desktop / 주요 문서)`** — 바탕화면 내 주요 문서 파일 및 스캔본 역추적 색인

### 1.3 체험판 1분 컷 3대 집중 타겟팅 (`[청소 진단 + 최신 서류 20건 + 최신 동영상 10개]`)
일반 사진 수백 장을 인덱싱하느라 시간을 허비하지 않고, 삼성 기본 갤러리가 절대 따라올 수 없는 **3대 핵심 타겟**만 1분 이내에 정밀 분석합니다:
1. **🧹 [기기 자체 연산] 중복·연사(dHash) 및 흔들림 진단:** 사진첩 전체의 파일명 다른 중복 사본/연사 그룹과 흔들린 사진 개수는 서버 전송 없이 에이전트 자체에서 빛의 속도로 계산합니다.
2. **📄 [로컬 서버 Gemma 2 인덱싱 ①] 최신 서류/문서 20건 역추적 (`LOCAL_DOCUMENT_FILES` 12건 + 갤러리 서류 촬영본 8장 = 총 20건):** 오늘 날짜부터 역순으로 허용된 폴더(다운로드/바탕화면/사진첩)를 뒤져 로컬 문서 파일(`PDF, TXT, DOCX` 12건)과 사진첩 속 서류 형태 이미지(영수증, 계약서, 조립 설명서, 여권·신분증 등 8장) **딱 20건**을 찾아내어 텍스트와 의미를 768차원으로 인덱싱합니다.
3. **🎬 [로컬 서버 Gemma 2 인덱싱 ②] 최신 동영상 10개 역추적 (`VIDEO_SCENE_ITEMS` 10개):** 사진첩의 최신 동영상(`test_photos` 내 실제 `.mp4`/`.MP4` 파일) **딱 10개**에서 핵심 프레임(썸네일)만 쏙 뽑아내어 영상 속 장면과 행동을 768차원으로 인덱싱합니다.

## 2. 코어 검색 엔진 아키텍처 (`vite.config.ts` — `runHybridCorpusSearch`) — **[100% 최종 확정]**

### 2.1 검색 파이프라인 구조 (768차원 벡터 엑셀 + 온톨로지/지명 브레이크 하이브리드)
현재 검색 엔진은 **768차원 EmbeddingGemma 2 시맨틱 벡터 탐색(엑셀) + 인덱싱 시점의 온톨로지 상향 상속 및 핵심 명사/지명 `AND` 가드레일(브레이크)** 결합으로 동작합니다.

1. **한국어 토크나이저 및 조사/어미 분리 (`stripKoParticle`)**
   - 입력 쿼리에서 문장부호를 제거하고 공백 단위로 분리합니다.
   - `바닷가`, `창가`, `물가`, `휴가`, `아이`, `어린이`, `고양이`, `멍멍이`, `물놀이`, `목걸이`, `귀걸이`, `종로`, `을지로`, `다리`, `나무다리`, `선풍기`, `비행기` 등 끝글자가 조사와 겹치는 명사(`KEEP_NOUNS`)를 보호한 뒤, 한국어 조사(`에서, 으로, 이랑, 하고, 부터, 까지, 들, 의, 을, 를, 은, 는, 에, 와, 과, 도`)를 제거하여 어근 토큰을 추출합니다.
   - 수식어/불용어(`SOFT_WORDS`: `사진, 찾아줘, 보여줘, 모습, 분위기, 풍경, 장면, 한잔하는` 등)와 핵심 개념 토큰(`hardTokens`)을 분리합니다.

2. **한국어 부분 문자열 착시 차단 (`BLOCK_SUBSTRING_MAP`)**
   - 짧은 한국어 명사가 전혀 다른 복합어의 부분 문자열로 오탐되는 현상을 정규식 마스킹으로 원천 차단합니다 (`튜브 ➔ 유튜브/UV-B 제외`, `아이 ➔ 아이콘/아이폰 제외`, `다리 ➔ 사다리/책상다리 제외`, `불 ➔ 불안/불빛 제외` 등).

3. **768차원 EmbeddingGemma 2 시맨틱 벡터(엑셀) + 온톨로지 핵심 명사 가드레일(브레이크) 결합**
   - **핵심 명사/지명 가드레일 (`coreGuardrailTokens`):** 검색어 내 토큰 중 온톨로지에 등록된 핵심 명사·지명(`청라`, `보트`, `맥주`, `불쇼`, `구명조끼`, `아이`, `여의도`, `한강공원` 등)은 반드시 모두 만족해야 통과합니다 (`corePrimaryHits >= requiredCoreCount`).
   - **자연어 문장·맥락·감성 표현의 768차원 벡터 탐색:** 자연어 문장은 **768차원 EmbeddingGemma 2 벡터 유사도(`vecSim`)**가 의미 공간을 탐색하여 `0.04초` 만에 랭킹합니다.
