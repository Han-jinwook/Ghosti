# 🛡️ SaySee & ClearMonster 핵심 정책 및 엔지니어링 원칙 (`정책_및_핵심원칙.md`)

> **최종 업데이트:** 2026-10-17  
> **목적:** 대표님과 확정된 서비스 정책, 무저장 휘발성(Zero-Retention) 보안 원칙, 체험판 3대 집중 타겟팅(중복 청소 + 서류 20건 + 동영상 10개), 프라이빗 싱크 및 카페 런칭 과금 퍼널 원칙을 명문화하여 모든 개발 세션에서 일관되게 준수하도록 합니다.

## 1. 보안 안심 UI 원칙: "원본 미전송 & 0.1초 즉시 휘발(Zero-Retention)"

1. **과장 문구("전송 0건 / 외부 전송 0 Byte / 비행기 모드 작동") 절대 금지**
   - 무료 체험판 AI 인덱싱은 유저 기기에 무거운 Gemma 2를 설치하는 대신, 경량 에이전트(APK/EXE)가 추출한 경량 데이터를 **자체 로컬 GPU 서버**로 보내 고속으로 벡터화한 뒤 인덱스만 돌려받는 구조입니다.
   - 따라서 `'전송 0건'`, `'외부 전송 0 Byte'`, `'비행기 모드 작동'` 같은 부정확한 문구는 절대 사용하지 않으며, 정직하고 강력한 **'원본 미전송 & 휘발성 메모리 연산(무저장 원칙)'**으로 신뢰를 줍니다.
2. **필수 보안 배지 및 검진 구역 직접 허용 UI**
   - **스캔 전 `[검진 구역 직접 허용]`:** 기본 3대 안전 폴더(`☑️ 사진첩`, `☑️ 다운로드`, `☑️ 바탕화면`)만 체크된 상태로 유저가 직접 허용하고 시작하게 합니다.
   - **스캔 중 및 상단 `[무저장 휘발성 보안 배지]`:** `[🔒 안심 보안 파이프라인 가동 중: 무거운 원본 파일 미전송 / AI 분석 서버 하드디스크 저장 0건 (RAM 연산 후 0.1초 내 즉시 자동 파기)]` 배지를 명확히 표시합니다.

## 2. 체험판 스캔 대상 혁신 & 체험 완료 브리핑 보드 정책

1. **체험판 1분 컷 3대 집중 타겟팅 (`[청소 진단 + 최신 서류 20건 + 최신 동영상 10개]`)**
   - 일반 사진 검색은 기본 갤러리와 변별력이 약하므로, 체험판은 일반 사진 수백 장을 인덱싱하느라 시간을 쓰지 않고 삼성 갤러리가 절대 못 하는 3대 핵심 타겟에 100% 화력을 집중합니다:
     1. **🧹 [기기 자체 연산] 중복·연사(dHash) 및 흔들림 진단** (서버 전송 없이 기기 자체 고속 계산)
     2. **📄 [로컬 서버 Gemma 2 인덱싱 ①] 최신 서류/문서 20건 역추적** (로컬 PDF/TXT/DOCX 12건 + 사진첩 속 서류 촬영본 8장 = 최신 20건)
     3. **🎬 [로컬 서버 Gemma 2 인덱싱 ②] 최신 동영상 10개 역추적** (최신 동영상 10개에서 핵심 키프레임만 추출하여 장면·행동 768차원 인덱싱)
2. **체험 완료 브리핑 보드 ("기본 갤러리에선 절대 안 찾아지는 동영상과 서류, 직접 눌러보세요!")**
   - 스캔 직후 상단에 `"🎉 무료 체험 분석 완료! (🧹 정리 대상 중복/연사 OO장 발견 | 📄 최근 서류 20건 및 🎬 동영상 10개 AI 정밀 색인 완료)"` 및 분석된 파일의 실제 날짜 범위를 노출합니다.
   - 인덱싱된 20건의 서류와 10개의 동영상 내용에서 자동 추출된 **📄 `[서류 내용 힌트 칩]` 3개**와 **🎬 `[동영상 장면 힌트 칩]` 3개**를 나란히 배치하여, 클릭 즉시 0.04초 만에 서류(PDF+사진)와 동영상 해당 장면이 튀어나오는 충격을 선사합니다.
   - 브리핑 보드 바로 아래에 *"내 폰과 PC의 나머지 10년 치 모든 사진·동영상·서류를 전부 연결하고 깨끗이 청소하시겠습니까?"* 유료 전환 CTA를 연결합니다.

## 3. 검색 엔진 코어 확정 원칙 ("768차원 벡터 엑셀 + 온톨로지/지명 브레이크")

1. **검색 엔진 코어 100% Fix 보존**
   - `vite.config.ts`의 `runHybridCorpusSearch` 하이브리드 구조(768차원 EmbeddingGemma 2 벡터 유사도 + 한국어 개념 족보 `Is-A` 상속 및 EXIF GPS 지명 가드레일)는 최종 확정(Fix)되었습니다.
   - 어휘 확장이 필요할 때는 오직 `src/data/koreanPhotoOntology.json`의 `Is-A` 계층 트리만 업데이트합니다.
2. **엄격한 `AND` 교집합 원칙 (억지 `OR` 결과 노출 금지)**
   - 복합 명사/지명 검색어(예: `"청라 보트"`) 입력 시 핵심 명사 조건을 동시에 만족하는 사진이 없으면 **정직하게 `0장`을 반환**합니다.

## 4. 디지털 주치의 진단서 & 3중 타임머신 안전망 정책

1. **🩺 무료 종합 진단서 리포트**
   - 정리 탭 최상단에 중복·연사, 흔들린 사진, 일회성 메모 장수 및 총 낭비 용량(MB)과 함께 **처치 완료 시 예상 탐색·인덱싱 반응 속도 향상률(%)**을 시각적 게이지로 제시합니다.
2. **🛡️ 3중 타임머신 안전망**
   - **1단계 (1초 즉시 Undo):** 바둑판 Pick이나 일괄 격리 직후 화면 하단 플로팅 바로 `[↩️ 방금 정리한 항목 원래대로 되돌리기 (Undo)]`를 제공하여 실수 시 1초 만에 원복합니다.
   - **2단계 (30일 정리대기함 보호):** 모든 정리 파일은 영구 삭제되지 않고 `[세이씨_정리대기함]`에서 30일간 안전하게 보호됩니다.
   - **3단계 (PC 블랙박스 보관):** PC 연결 시 원본 블랙박스 영구 보관이 가능합니다.

## 5. 클라우드 대체 '프라이빗 싱크' 2-Track 및 배터리 보호 정책

1. **배터리/OS 제재 방어 원칙**
   - 세이씨 모바일 에이전트(1MB APK)는 배터리를 소모하는 상시 통신을 하지 않으며, **`[집 Wi-Fi 연결 + 충전 중]`**이거나 **`[지금 일치시키기]`** 버튼을 누를 때만 작동합니다.
2. **프라이빗 싱크 모드 이원화**
   - **모드 A (`[🔄 100% 원본 미러링 모드]`):** 여유 공간이 넉넉할 때 폰과 PC 양쪽에 동일한 무손실 원본을 유지하여 상호 백업 보험 구축.
   - **모드 B (`[👻 초경량 섀도우 캐시 모드]`):** 폰 용량이 부족할 때 무거운 원본은 집 PC 하드디스크로 이관하고, 폰에는 **장당 13KB짜리 WebP 썸네일 + 768d 벡터 인덱스**만 남겨 집 PC 전원이 꺼져 있어도 밖에서 `0.04초` 만에 100% 검색·열람 가능.

## 6. 카페 런칭용 심플 과금 퍼널 & 선착순 기간 뻥튀기 정책

1. **4단 과금 퍼널**
   - **입문 무료 체험 (`0원`):** 전체 정밀 진단서 확인 + 최신 서류 20건 & 동영상 10개 색인 체험 + 연사 바둑판 Pick 1묶음 무료 정리 체험 (`freeTrialUsed`).
   - **단기 유입 패스 (`990원`):** `[⚡ 24시간 자유 해결 패스]` — 월 구독 부담 없이 오늘 하루 동안 모든 청소·동영상·서류함·갤러리 무제한 사용.
   - **1회 완치 단품:** 모바일 단독 1회 대청소 (`1,900원`) / PC+모바일 양쪽 대청소 및 최초 1회 일치화 (`3,800원`).
   - **정기 주치의 멤버십:** 모바일 단독 월 `1,100원` (연 `11,000원`) / PC+모바일 통합 월 `2,900원` (연 `29,000원`, 기기 추가 시 50% 반값).
2. **창립 멤버 선착순 기간 뻥튀기 (FOMO)**
   - 1년 요금 결제 시 ➔ 최초 100명 **'평생권'** / ~500명 **'10년권'** / ~1,000명 **'5년권'** 자동 승격 (현재 10년 특전 잔여 좌석 카운트다운 노출).
