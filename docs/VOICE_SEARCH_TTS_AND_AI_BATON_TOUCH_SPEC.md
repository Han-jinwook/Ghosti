## 1. 💡 도입 배경 및 기획 취지 (`Why — 왜 이렇게 설계했는가?`)

### 1.1 유료 Typecast 원가 역전 원천 차단 & 대외 슬로건 `"내 폰·PC 속 AI 주치의는 언제나 0원"` 완벽 수호
- 기존 설정몬스터에 일부 적용되었던 유료 Typecast(`필재`/`유진`) 성우는 고정 멘트 캐시 외에 실시간 문서 낭독이나 가변 검색 결과를 읽을 때마다 클라우드 API 종량제 과금이 발생하는 치명적 원가 리스크가 있었습니다.
- 또한 원가 방어를 위해 `'일일 10회 제한'` 같은 횟수 제한을 둘 경우, 제트아이의 대외 핵심 슬로건인 **`"내 폰·PC 속 AI 주치의는 언제나 0원"`**과 정면으로 배치되어 유저 신뢰를 깎아먹게 됩니다.
- 이에 따라 유료 Typecast를 100% 전면 배제하고, **실시간 합성 시에도 API 비용이 평생 0원이며 음질이 뛰어난 MS 신경망(`edge-tts`) 한국어 남녀 투톱 체제(`현수` & `선희`)**로 전 영역을 통일하여 **일일 횟수 제한 없는 100% 완전 무제한 무료**를 실현했습니다.

### 1.2 구 ‘세이씨(SaySee)’의 음성 중심 감성 계승 + LLM 토큰 비용 0원(`Zero-LLM`) 달성
- 운전 중이거나 이동 중인 유저, 또는 작은 스마트폰 글씨를 읽기 불편한 시니어 유저가 **말 한마디로 내 문서를 찾고, 요약을 듣고, 특정 단어가 들어간 조항만 골라 듣고, 카톡으로 바로 전달**할 수 있어야 합니다.
- 이 과정에서 매번 유료 클라우드 LLM을 호출하면 평생 무료 모델이 무너지므로, **로컬 정규식·형태소 파서 + 온디바이스 `EmbeddingGemma 2`(768차원) + 로컬 사전 요약 인덱스**만으로 100% 무토큰(`0원`) 작동하도록 설계했습니다.

### 1.3 “진짜 그 카톡방이 맞나?” 불안감 해소 — 실제 카카오톡 대화방 직행 장전 후 복귀
- *"계약서 찾아서 카톡 '이쁜이'에게 전달해줘"*라고 말했을 때 제트아이 앱 내부의 가상 확인창만 띄우면, 유저는 *"동명이인한테 잘못 가는 거 아냐?"* 하고 불안해합니다.
- 따라서 반드시 **실제 카카오톡의 `'이쁜이'` 대화방 화면을 직접 열어 파일을 입력창에 장전**해 주고, 유저가 눈으로 상대방 프로필과 대화방을 확인한 뒤 **`[확인/Enter]`만 딱 1번** 누르면 전송 결과를 1~2초 보여준 뒤 다시 제트아이 화면으로 자동 복귀시킵니다.

### 1.4 무료 범위를 넘는 고난도 질문 시 — 거절이나 API 키 요구 없이 ‘유저 단골 AI(기본값: 제미나이)’ 라이브 음성으로 무학습 바톤터치
- 유저는 어디까지가 무료 로컬 검색이고 어디부터가 고비용 AI 추론인지 구분하지 못하므로, 제트아이에게 바로 *"이 계약서에서 나한테 불리한 독소조항 있어?"*라고 물어봅니다.
- 이때 *"무료 버전에서는 지원하지 않습니다"*라고 차갑게 거절하거나 일반인이 극도로 싫어하는 `'OpenAI API 키를 입력해 주세요'` 같은 요구를 하는 대신, **어그로필터(AggroFilter)의 바톤터치 철학**을 적용합니다:
  1. 유저가 평소 쓰던 단골 AI(`ChatGPT` / `Gemini` / `Claude`)를 코어가 0.01초 만에 찾아내고 (**열어본 기록이 전혀 없는 초기 유저는 구글 계정으로 즉시 연동되는 `제미나이(Gemini)`를 기본 오픈!**),
  2. 유저가 번거롭게 복사·붙여넣기를 할 필요 없이 **입력창에 `[찾은 문서 본문 + 유저 질문]`을 자동으로 꽉 채워 띄운 뒤**,
  3. 설정몬스터의 손가락 화살표(`👆`)로 **`① [전송 ↑]` ➔ `② 바로 옆 [라이브 음성 🎧]`** 버튼만 콕 집어 안내하여, 우리 서버 토큰 비용 0원으로 최고급 AI 실시간 음성 상담까지 막힘없이 이어줍니다.

## 3. ⚡ 4대 핵심 시나리오 상세 작동 플로우

### 시나리오 A — 문서 사전 요약본 무토큰 즉시 낭독 (*"이 문서 요약해서 읽어줘"*)
1. 문서를 최초 인덱싱할 때 로컬에서 미리 생성해 둔 `2~3줄 핵심 요약문`을 로컬 DB에서 0.001초 만에 로드합니다 (실시간 LLM 호출 0회).
2. **`선희(ko-KR-SunHiNeural)`** 아나운서 음성으로 요약본을 즉시 또렷하게 낭독합니다.

### 시나리오 B — 특정 단어가 나오는 문장 전수 발췌 낭독 (*"계약서에서 '위약금'이나 '해지' 나오는 문장 다 읽어줘"*)
1. 로컬 정규식/문자열 파서(`extractKeywordSentencesZeroLlm`)가 0.001초 만에 문서 본문 전체에서 `'위약금'`, `'해지'`가 포함된 문장들만 모두 발라냅니다.
2. 화면에는 해당 문장들을 **노란 형광펜으로 하이라이팅**하여 즉시 보여줍니다.
3. 음성으로는 먼저 **`현수`**가 *"요청하신 위약금, 해지 단어가 포함된 문장 총 N개를 찾았습니다. 선희 아나운서가 차례대로 읽어드립니다"*라고 브리핑한 뒤, 곧바로 **`선희`**가 매칭된 문장들을 순서대로 읽어줍니다.

### 시나리오 C — 실제 카톡 대화방 직행 장전 & 제트아이 자동 복귀 (*"계약서 찾아서 카톡 '이쁜이'에게 전달해줘"*)
1. **PC (`멀린 Z 코어` 내장 `plugin_senstalk.py`)**: 0.1초 만에 파일을 찾은 뒤 카카오톡을 활성화하여 `'이쁜이'` 대화방 창을 화면 최상단에 띄우고 파일을 장전합니다.
2. **모바일 (`1MB APK`)**: 카톡 공유(`Intent.ACTION_SEND`) 호출 후 설정몬스터 `AccessibilityService`로 검색창에 `'이쁜이'`를 자동 입력·선택하여 실제 `'이쁜이'` 채팅방 전송 확인 화면까지 직행시킵니다.
3. **유저 1-Tap 승인 (`Zero-Auto-Action`) & 자동 복귀**: 유저가 실제 카톡방임을 눈으로 확인하고 `[Enter]`/`[전송]`을 누르면, 카톡방에 파일이 올라간 모습을 **1~2초간 확인시켜 준 뒤 원래 보던 제트아이 화면으로 자동 복귀**(화면 상단 `[⬅️ 제트아이로 복귀]` 플로팅 알약 버튼 동시 제공)합니다.

### 시나리오 D — 고난도 질문 시 유저 단골 AI(기본값: `제미나이`) 입력창 자동 채움 & `[라이브 음성 🎧]` 바톤터치 (*"이 계약서에서 나한테 불리한 조항 있어?"*)
1. **자율 난이도 감지 & `현수` 음성 안내**:
   - 단순 검색/발췌를 넘어서는 심층 분석·자문 질문임을 0.001초 만에 감지하고 `현수` 목소리로 안내합니다:
     > *"깊은 분석이 필요한 질문이네요! 평소 쓰시는 제미나이(또는 챗GPT) 입력창에 이 문서와 질문을 바로 넣어 띄워드릴게요. `[전송]` 버튼을 누르신 뒤, 바로 옆 `[라이브 음성]` 버튼을 누르시면 말로 편하게 상담하실 수 있습니다!"*
2. **최근 사용한 AI 0.01초 자동 판별 (`detect_most_recent_ai_and_baton_touch`)**:
   - **1순위**: 현재 PC 화면에 열려 있는 브라우저 탭/창 제목(`ChatGPT`, `Gemini`, `Claude`) 스캔.
   - **2순위**: 크롬(`Chrome`)·엣지(`Edge`)·웨일(`Whale`) 로컬 방문 기록(`History` SQLite DB)에서 `last_visit_time`이 가장 최신인 AI 1위 자동 선택.
   - **3순위 (열어본 기록이 0건인 초기 유저 기본값 — 멀린님 확정)**: 구글 계정으로 즉시 로그인되는 **`제미나이 (Gemini, https://gemini.google.com/app)`**를 기본으로 오픈!
3. **입력창 자동 채움 & 2단계 손가락 가이드(`👆`) + 제트아이 복귀 알약 버튼**:
   - 유저가 수동으로 붙여넣기할 필요 없이 `[찾은 문서 전체 텍스트 + 유저 질문]`을 입력창에 자동 장전합니다.
   - 화면 위에 **`① [전송 (↑)] 버튼 클릭` ➔ `② 바로 옆 [라이브 음성 🎧] 버튼 클릭`** 손가락 가이드를 띄우고, 구석에는 **`[⬅️ 대화 종료 후 제트아이 복귀]`** 플로팅 알약 버튼을 배치하여 상담 종료 후 원터치로 복귀시킵니다.
