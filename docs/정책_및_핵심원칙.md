# 🛡️ SaySee & ClearMonster 핵심 정책 및 엔지니어링 원칙 (`정책_및_핵심원칙.md`)

> **최종 업데이트:** 2026-10-16  
> **목적:** 대표님과 확정된 서비스 정책, 검색 정밀도 원칙, 과금 UX 규칙, 클리어몬스터 안전 기준을 명문화하여 모든 개발 세션에서 일관되게 준수하도록 합니다.

---

## 1. 검색 정밀도 및 언어 처리 정책

1. **수동 눈대중 땜질 금지 & 엔진/온톨로지 기반 해결 원칙**
   - 특정 사진이나 특정 검색어가 안 나온다고 해서 개발자가 개별 파일명을 예외 처리하거나 검색창에 임시 평면 정규식 묶음을 추가하는 행위를 금지합니다.
   - 반드시 **인덱싱 파이프라인(`poc/build_korean_photo_ontology.mjs`, `src/data/koreanPhotoOntology.json`)**의 `Is-A` 상·하위 계층 규칙 또는 물리·시맨틱 인덱서를 통해 구조적으로 해결해야 합니다.
2. **`Is-A` 단방향 상향 상속 원칙 ("자식 ➔ 부모만 허용, 역방향·형제 오염 금지")**
   - 사진에 구체어(`"생맥주"`, `"수영복"`, `"불쇼"`, `"청라"`)가 검출되면 그 부모 상위어(`"술"`, `"옷"`, `"공연"`, `"인천"`)만 사진 인덱스에 상속합니다.
   - 하위 구체어를 검색했을 때 형제 개념(`"맥주"` 검색 시 `"와인"`, `"불쇼"` 검색 시 `"박물관 공연"`)이 절대 섞여 나오면 안 됩니다.
3. **엄격한 `AND` 교집합 원칙 (억지 `OR` 결과 노출 금지)**
   - 복합 검색어(예: `"청라 보트"`) 입력 시 모든 핵심 조건을 동시에 만족하는 사진만 반환합니다.
   - 조건을 모두 만족하는 사진이 없으면 **정직하게 `0장`을 반환**해야 하며, 하나만 일치하는 사진들을 억지로 나열해 유저를 당황하게 해서는 안 됩니다.

## 2. Zero-Cloud 프라이버시 정책

1. **원본·썸네일·메타데이터 외부 서버 전송 금지**
   - 사용자의 사진 원본, 썸네일, EXIF 위치 정보, 로컬 벡터 DB는 어떠한 경우에도 중앙 클라우드 서버에 업로드하거나 저장하지 않습니다.
2. **외부 LLM API 연동 시 프라이버시 보호**
   - 온보딩 문장 생성이나 스무고개(티키타카) 라우팅을 위해 Gemini API를 호출할 때도 사진 이미지 바이너리를 전송하지 않고, 기기 내부에서 추출된 **비식별 팩트 키워드와 날짜/통계 텍스트만** 전송합니다.

## 3. 클리어몬스터 (ClearMonster) 삭제·격리 안전 정책

1. **물리·광학 엔진 교차 검증 필수**
   - 순수 AI 임베딩 점수만으로 사진을 '쓰레기'로 분류하지 않습니다.
   - 반드시 **Perceptual dHash(픽셀 구조 해시)**, **Laplacian Variance(초점·블러 수치)**, **Sobel Edge Density(문서·글자 밀도)**, **EXIF 카메라 메타데이터 유무**를 교차 검증해야 합니다.
2. **중복 사진 `[원본 1장 안전 보관]` 보장 원칙**
   - 동일·유사 중복 사진 클러스터에서는 해상도·용량·파일명 기준 가장 원본에 해당하는 **1장은 반드시 활성 갤러리에 안전하게 남기고**, 나머지 복사본(`(0)`, `(1)` 등)만 정리 대상으로 분류합니다.
   - UI 노출 시 유저가 "멀쩡한 가족사진을 지우라고 한다"며 놀라지 않도록 **`[원본 1장 안전 보관 · 사본 정리]`** 안심 배지를 명확히 표시해야 합니다.
3. **즉시 영구 삭제 금지 ➔ 안전 격리 보관함(Quarantine) 경유**
   - 정리 실행 시 파일을 즉시 삭제하지 않고 격리 보관함(`test_photos_quarantine`)으로 먼저 이동시키며, 언제든 원클릭 복원이 가능해야 합니다.

## 4. 스무고개(티키타카) 노출 및 하이패스 과금 정책

1. **기능 노출 시점 제어 (Feature Flag + 사용자 설정 토글)**
   - 신규 유저가 기본 세이씨(0초 오프라인 음성·텍스트 검색)에 완전히 익숙해진 뒤(약 1개월 후 또는 조건 달성 시)에 출현하도록 플래그(`featureFlagUnlocked`)로 제어합니다.
   - 유저가 `[프로필/설정]`에서 직접 **‘AI 티키타카(스무고개) 토글’을 `ON`으로 켠 상태에서만** 작동합니다.
2. **맥을 끊지 않는 무알림 과금 & 일일 마감 1건 합산 정산**
   - 유저가 대화하고 사진을 찾는 도중에는 코인 차감 팝업이나 과금 알림을 절대 띄우지 않습니다.
   - 과금 이력(로그)에 건건이 지저분하게 찍히지 않도록, 하루 동안 사용한 스무고개 내역을 모아 **일일 마감 시점(또는 세션 종료 시점)에 단 1건으로 깔끔하게 합산 차감**하여 기록합니다.
