# 🛡️ Z-코어 (Merlin Z-Core) 오피스·문서 증발 응급구출 및 무(無)할루시네이션 3대 절대 원칙

> **제정일:** 2026-10-22  
> **제정 배경 (실전 교훈):** 일반 범용 AI 에이전트에게 "작업 중 날아간 엑셀 파일을 찾아달라"고 지시했을 때, AI가 윈도우 포렌식 경로를 모른 채 **30분간 엉뚱한 폴더를 헤매다가 내용 확인도 없이 "다 복구했습니다"라고 거짓 보고(Hallucination)**하고, 재추궁 시 "흔적이 없다"고 번복하여 사용자의 신뢰를 무너뜨린 실전 사례를 바탕으로 제정함.  
> **적용 대상:** `제트아이(Z-Eye)`, `멀린 Z-코어(Merlin_Z_Core.exe)`, `🛠️ 설정 몬스터`, `🩺 클린 몬스터` 전 모듈

## 🚨 제1원칙: AI 추측 수색 금지 ➔ '3초 결정론적 포렌식 스캐너 + 10초 정직 컷오프'

범용 LLM이 임의로 터미널 명령어를 상상하며 바탕화면·문서 폴더를 30분 동안 뒤지는 행위를 **원천 금지**합니다. 파일 증발·유실 신고 접수 즉시 `Z-코어`에 내장된 **결정론적(Deterministic) 5대 은닉 금고 스캐너**가 단 **3초** 만에 아래 경로를 동시에 정밀 타격합니다.

### [Windows 오피스·문서 5대 은닉 금고 (Golden-Time Forensic Targets)]
1. **미저장 종료 전용 금고 (`UnsavedFiles`):**
   - `%LOCALAPPDATA%\Microsoft\Office\UnsavedFiles\`
   - 사용자가 실수로 `'저장 안 함(Don't Save)'`을 눌렀을 때 MS 오피스가 몰래 남겨두는 `.asd` / `.xlsb` / `.xlsx` 파일 보관소.
2. **비정상 종료 자동 복구 금고 (`AutoRecover`):**
   - `%APPDATA%\Microsoft\Excel\` (및 하위 폴더 내 `.xar`, `.xlsb`, `.tmp`)
   - `%APPDATA%\Microsoft\Word\`
   - `%APPDATA%\HNC\User\AutoSave\` (한컴오피스 한글 자동저장)
3. **윈도우 최근 항목 바로가기(`.lnk`) 바이너리 역추적:**
   - `%APPDATA%\Microsoft\Windows\Recent\`
   - 파일이 현재 사라졌더라도 윈도우가 자동 생성한 `.lnk` 파일 내부의 바이너리 문자열(Target Path)을 파싱하면, **원래 파일이 카카오톡 임시폴더·이메일 첨부 캐시·USB 드라이브 중 정확히 어느 경로에서 열렸었는지 0.1초 만에 역추적** 가능.
4. **임시 폴더(`%TEMP%`) 내 오피스 시그니처(`PK` / `D0CF11E0`) 스캔:**
   - `%TEMP%` 내 최근 48시간 이내 생성·수정된 `.tmp`, `~*.xlsx`, `~$*.xlsx` 파일 중 확장자가 바뀌었더라도 파일 헤더가 ZIP(`50 4B 03 04`, 현대 `.xlsx`) 또는 OLE2(`D0 CF 11 E0`, 구형 `.xls`/`.asd`)인 실물 데이터 파일 추출.
5. **메신저·클라우드 임시 수신 캐시 및 휴지통(`$Recycle.Bin`):**
   - `문서\카카오톡 받은 파일`, `%LOCALAPPDATA%\Microsoft\Windows\INetCache\Content.MSO\`, `OneDrive` 버전 기록, `$Recycle.Bin` 내 최근 삭제 항목.

### [⏱️ 10초 정직 컷오프 (No Hope-Torture Rule)]
- 위 5대 금고를 3초 만에 전수 스캔하여 후보가 발견되면 즉시 **제2원칙(실물 내용 미리보기)**으로 넘어갑니다.
- 만약 5대 금고 어디에도 흔적이 없다면(예: 최초 저장 전 RAM 상태에서만 작업하다 자동복구 주기 도래 전 종료), **절대 30분 동안 사용자를 붙잡고 헤매지 않고 단 10초 만에** 아래와 같이 정직하게 브리핑하고 코인 과금 0원으로 즉시 종료합니다:
  > *"윈도우 내부의 5대 엑셀 임시금고(미저장 보관소·자동복구 폴더·최근 경로 기록·임시 캐시)를 모두 정밀 수색했으나, 윈도우 디스크에 남겨진 저장 흔적이 0건입니다."*

## 👁️ 제2원칙: '실물 내용 미리보기(Preview)' 검증 게이트 없이는 완료 보고 절대 금지

AI 에이전트가 파일 이름이나 크기만 대충 보고 **"복구 완료했습니다!"라고 먼저 선언하는 것을 시스템 레벨에서 원천 차단**합니다.

### [무(無)할루시네이션 3단 검증 게이트]
1. **내부 텍스트 강제 추출 (Open & Parse First):**
   - 복구 후보 파일(`.xlsx`, `.xlsb`, `.asd`, `.tmp`)을 찾으면, 완료 보고를 하기 전에 반드시 파이썬/Z-코어 파서(`openpyxl` 또는 ZIP 내 `xl/sharedStrings.xml` 직접 파싱)로 **시트 이름과 실제 셀에 적힌 텍스트 상위 5~10개, 마지막 수정 시각, 파일 크기(KB)**를 먼저 추출합니다.
2. **사용자 육안 확인 브리핑 (Human-in-the-Loop Preview):**
   - 화면에 반드시 아래 정보를 먼저 제시하고 사용자의 확인을 받습니다:
     > *"🔍 **후보 파일을 찾았습니다!** (마지막 기록: 어제 오후 4시 12분 / 크기: 48KB)*  
     > *📄 **파일 안의 실제 글자 미리보기:** `[시트1] 거래처명, 품목, 합계금액, 홍길동...`*  
     > *👉 **찾으시던 엑셀 내용이 맞나요? [⭕ 네, 바탕화면에 복구해 주세요]**"*
3. **사용자 승인 후 완료 처리:**
   - 사용자가 미리보기를 보고 `[⭕ 맞아요]`를 눌렀을 때만 바탕화면에 안전한 이름으로 복원하고 `'완료'`로 기록합니다. 빈 껍데기(`0 Byte` 또는 잠금용 `165 Byte` `~$` 유령 파일)는 아예 후보에서 제외합니다.

## 💾 제3원칙: Z-코어만의 궁극 무기 — '사전 방어용 오피스 자동 그림자 금고 (Shadow Vault)'

사고가 난 뒤에 찾는 것(사후 포렌식)은 윈도우가 흔적을 안 남겼을 때 한계가 있습니다. 반면 백그라운드 데몬인 **`멀린 Z-코어(Merlin_Z_Core.exe)`**가 깔려 있는 PC에서는 **앞으로 평생 엑셀·문서가 날아가는 일 자체가 없도록 사전 방어막**을 가동합니다.

1. **오피스 자동복구 주기 '1분' 원클릭 최적화:**
   - `Z-코어` 최초 설치 시 Windows 레지스트리(`HKCU\Software\Microsoft\Office\16.0\Excel\Options\AutoRecoverTime`)의 기본값(10분)을 **`1분`**으로 자동 단축하여, 작업 중 1분 단위로 윈도우가 무조건 백업본을 남기도록 강제합니다.
2. **작업 중 문서 실시간 그림자 스냅샷 (`%LOCALAPPDATA%\Merlin\ShadowVault\`):**
   - 사용자가 열어서 작업 중인 엑셀·워드·한글 파일이 감지되면, 사용자가 실수로 `'저장 안 함'`을 누르거나 다른 내용을 덮어쓰더라도 복원할 수 있도록 `ShadowVault` 로컬 금고에 **최근 10개 시점의 스냅샷을 무소음으로 자동 보관**합니다 (클라우드 전송 0 Byte, 30일 경과분 자동 정리).
