# test_photos — 테스트 사진 폴더 (D-11)

이 폴더에 **테스트용 가족사진 200~300장**을 넣어 주세요. 하위 폴더도 인식합니다.

- 지원 형식: JPG, PNG, WEBP, AVIF, GIF, BMP
- HEIC는 Chrome/Edge에서 디코딩되지 않아 **건너뜁니다** (Safari에서는 동작). 아이폰 사진이면 JPG로 내보내기를 권장합니다.
- 🔒 이 폴더 내용은 `.gitignore`로 저장소에서 제외됩니다. PoC는 사진을 외부로 전송하지 않습니다.
- 다양성 권장: 해변/야외, 아이, 반려동물, 음식, 단체 사진, 야간/어두운 사진, **스크린샷·영수증·흔들린 사진**(정리대기함 판별 테스트용)
